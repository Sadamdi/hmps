## Summary

Patch lanjutan untuk dua bug yang masih reproducible setelah v4.23.3:

1. **Section header hilang (Berita)**: walaupun `useRevealAnimation` sudah punya fallback 800 ms + 2500 ms, ada skenario (mis. section di-mount jauh di luar viewport, rootMargin default tidak cukup, observer somehow tidak fire, atau ada race antara multiple mount cycles) di mana hook masih gagal set `isVisible = true` tepat waktu. Akibatnya `PublicSectionHeader` tetap `opacity-0` dan user lihat header kosong. Patch ini menambah safety net **di level komponen `PublicSectionHeader`** yang memaksa reveal lokal setelah 500 ms tanpa peduli posisi viewport atau status hook.

2. **Upload AVIF gagal**: `looksLikeHeic()` di `server/image-processor.ts` match `mif1` dan `msf1` brand untuk HEIF, tapi brand yang sama juga muncul di file AVIF sebagai `compatible brands`. Akibatnya AVIF ikut di-route ke `heic-convert` yang hanya support HEVC, decode gagal, lalu `processImage()` throw error walaupun `sharp` sebenarnya sudah support AVIF native di prebuilt binaries. Patch exclude major brand `avif` secara eksplisit.

Kontrak API tidak berubah.

## Highlights

## Features (detail)

### Feature / Change A — PublicSectionHeader safety net 500 ms

- **Masalah / tujuan:** v4.23.1 tambah fallback 800 ms + 2500 ms di `useRevealAnimation`. Tapi karena hook dipakai lintas banyak section (Berita, Library, Visi&Misi, About, Prodi, Toko, Youtube, Instagram) dan ada banyak cara observer tidak fire (viewport check miss, rootMargin terlalu kecil, tab inactive, race React 18 mount cycles, dependency array `[threshold, isVisible]` causing re-cleanup), patch ini tambah safety net ketiga **di level komponen** sebagai pengaman terakhir.
- **Perilaku baru:**
  - `PublicSectionHeader` sekarang track `forcedVisible` lokal.
  - Effect mount: kalau prop `visible === false` setelah 500 ms, `setForcedVisible(true)`.
  - `show = visible || forcedVisible` → render `reveal-heading` class (animasi `text-reveal-up` 0.65 s).
  - Saat fallback fire, animasi CSS tetap jalan dari opacity 0 → 1 (class `opacity-0` ditukar ke `reveal-heading`), jadi tidak ada flicker.
  - Cleanup saat unmount: clear timeout 500 ms.
- **Siapa terdampak:** semua section yang pakai `PublicSectionHeader` di home, terutama `berita.tsx` yang paling sering kena.
- **Permission:** N/A (UI only).
- **Tenant-aware:** Yes (komponen dipakai di main + tenant home).
- **Source:** `client/src/components/public/section-header.tsx`.

### Feature / Change B — Exclude AVIF dari heic-convert route

- **Masalah / tujuan:** setelah v4.23.2 nambah `heic-convert` decoder, `looksLikeHeic()` terlalu permisif: dia cek brand `mif1` dan `msf1` (HEIF container), tapi AVIF juga mencantumkan brand `mif1` di section `compatible brands` di ISOBMFF `ftyp` box. Hasilnya: upload AVIF (`.avif`) di-route ke `heic-convert` → gagal decode → `processImage()` throw "Gagal decode HEIC/HEIF" walaupun sebenarnya `sharp` sudah support AVIF di prebuilt binaries.
- **Perilaku baru:**
  - `looksLikeHeic()` sekarang cek major brand `avif` **secara eksplisit** dan return `false` kalau major brand = `avif`. AVIF tidak akan pernah masuk jalur `heic-convert`.
  - HEIC/HEIF major brand (`heic/heix/hevc/hevx/heim/heis/heics/heicm/mif1/msf1`) tetap di-route ke `heic-convert`.
  - File ISOBMFF tanpa `ftyp` atau major brand tidak dikenal tetap return `false` dan masuk pipeline sharp biasa.
- **Siapa terdampak:** upload gambar AVIF dari `/api/upload`, `/api/upload/berita-image`, `/api/upload/event-content-image`, dan endpoint lain yang pakai `processImage`.
- **Permission:** sama seperti upload existing.
- **Tenant-aware:** Yes.
- **Source:** `server/image-processor.ts::looksLikeHeic()`.

## Fixed

- **Bug:** Section header Berita/Events/Library/Visi&Tujuan/Tentang/Prodi/Toko/Youtube/Instagram kadang stuck `opacity-0` walaupun `useRevealAnimation` sudah punya fallback. **Gejala:** "pill BERITA + judul Berita terbaru + garis cyan + Kabar terkini dari ..." tidak muncul di home saat user scroll ke section Berita. **Root cause:** hook `useRevealAnimation` gagal trigger IntersectionObserver atau timeouts karena race / tab inactive / rootMargin issue; tidak ada fallback di level komponen. **Fix:** safety net 500 ms di `PublicSectionHeader` paksa reveal lokal tanpa peduli hook.
- **Bug:** Upload AVIF gagal dengan error "Gagal decode HEIC/HEIF". **Gejala:** upload file `.avif` (atau AVIF yang dikirim sebagai `application/octet-stream`) di `/api/upload` throw error walaupun mimetype valid. **Root cause:** `looksLikeHeic()` match brand `mif1` (yang juga muncul di AVIF sebagai compatible brand), route ke `heic-convert` yang hanya support HEVC. **Fix:** exclude major brand `avif` secara eksplisit di `looksLikeHeic()`; AVIF lewat pipeline sharp native.
