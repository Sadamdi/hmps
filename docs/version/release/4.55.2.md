## Summary

Tindak lanjut laporan kerentanan upload SVG. Audit menemukan jalur nyata stored XSS dan jejak percobaan serangan di komunitas ONTAKI (SVG berisi payload XXE `file:///etc/passwd` dan file `.jpg.phar` ikut tersimpan).

## Security

- `server/lib/upload-safety.ts` (baru): `isBlockedUploadName`, `bufferLooksActive`, `hasImageMagic`, `guardMulter`, `activeContentServeGuard`.
- `uploadMiddleware` (`server/upload.ts`) kini fasad yang membungkus multer dengan `guardMulter` untuk `single/array/fields/any` sehingga 25 rute upload staf terlindungi sekaligus. Respons penolakan: `400 { success:false, error:{code:'UNSAFE_FILE_TYPE'} }`.
- `/api/chat/message` (anonim): `fileFilter` menolak nama/MIME berbahaya, limit 10 MB, cek magic bytes, dan penghapusan file sementara pada `res.close` (jalur gagal, mis. `chatId` tidak valid, sebelumnya meninggalkan file).
- `server/index.ts`: `activeContentServeGuard` di depan `/uploads` dan `/attached_assets`.
- `server/utils/input-sanitize.ts`: `stripUnsafeHtml` menelusuri atribut per tag (buang atribut `on*` termasuk yang dipisah `/`, netralkan URL `javascript:`/`vbscript:`/`data:` selain gambar, setelah dekode entity dan buang spasi/kontrol).
- Docs: bagian "Upload File Safety" di SOP 12.

## Verification

- `npm run check` lolos.
- E2E (server uji): 15/15. Chat anonim menolak `.svg`, `.html`, `.php.jpg`, HTML bernama `.png`, SVG bernama `.jpg` (400); PNG valid tetap diproses; tidak ada file tertinggal pada jalur sukses maupun gagal; >10 MB ditolak; file SVG/HTML yang sudah ada disajikan sebagai unduhan + CSP sandbox; `.phar` octet-stream; PNG normal tidak terpengaruh.
- Wrapper `guardMulter` pada aplikasi Express mini: 12 kasus sesuai (PDF, DOCX, PSD, JPG, TXT lolos; SVG, HTML, `.phar`, `.exe`, HTML bernama `.txt` ditolak; `laporan.himatif.com.pdf` tidak salah blokir).
- Sanitizer: 12 vektor serangan terblokir, 8 konten sah tetap utuh.

## Notes / Known gaps

- Upload SVG sengaja tidak lagi diizinkan (tidak ada fitur yang memakainya). Jika kelak perlu, gunakan sanitizer SVG khusus.
- Sanitizer HTML masih berbasis regex per tag; disarankan migrasi ke pustaka allowlist (mis. `sanitize-html`) pada rilis terpisah setelah diuji terhadap konten TinyMCE yang ada.
- File uji berbahaya yang sudah tersimpan di `uploads/community/ontakiuinmalang/` (SVG XXE, `.phar`) kini tidak lagi dieksekusi saat dibuka, tetapi sebaiknya dihapus dari server.
- `npm audit` melaporkan 47 temuan (1 critical `proxy-addr`, banyak high di express/mongoose/nodemailer/sharp/ws/undici); belum diperbarui pada rilis ini.
- Upload melalui rute tenant dan Google Drive tidak diuji ulang satu per satu; semuanya melewati `uploadMiddleware` yang sama.
