# Release v4.22.12 — Skip read-retry saat news copy lengkap

## Ringkasan

Patch lanjutan v4.22.11. Setelah v4.22.11 push ke server, live test masih menunjukkan AI malah jawab dengan berita PBAK-F 2026 (news copy lengkap di user prompt tetap di-match sebagai "cari data"). Masalah: `shouldForceReadToolRetry` masih trigger karena panjang > 240 char → model di-retry dengan instruksi `search_berita` → model cari berita lain → jawab list berita.

Fix: `shouldForceReadToolRetry` sekarang cek apakah user sudah kirim news copy lengkap → jika ya, return false (lewati retry baca; biarkan write-retry jalan).

## Yang Berubah

### Server
