## Summary

Kurikulum prodi sekarang menyimpan entri per `level` (`s1` | `s2`) + tahun akademik. Sync mengambil kurikulum undergraduate dan master; S2 2022 dari halaman resmi, S2 2024 memakai buku OBE PDF karena halaman HTML masih 404. UI publik dan dashboard punya switcher S1/S2.

## Highlights

- Schema `curriculumByYear[].level`
- Sync S2 2022 (table parser) + S2 2024 (PDF guidebook)
- Public `/prodi` + dashboard: pilih S1/S2 lalu tahun
- API publik menambah `curriculumByLevel` + `curriculumMeta.levels`

## Features (detail)

### Kurikulum multi-level
- **Masalah:** hanya S1; magister tidak tersimpan terpisah
- **Perilaku baru:** upsert keyed by `(level, year)`; legacy `content.curriculum` tetap S1 terbaru
- **Source:** `db/mongodb.ts`, `server/mongo-storage.ts`, `server/services/prodi-sync.ts`, `client/src/pages/prodi.tsx`, dashboard prodi
