## Summary

Feedback mobile setelah 4.16.0: berita sudah dirancang 2×2 compact di kode, tetapi galeri (library) masih memakai grid `sm:grid-cols-2` sehingga di layar <640px tetap 1 kolom kartu besar. Toko section home juga sama. Teks tentang kami di home dan intro profil masih terlalu panjang sebelum tombol expand. Patch ini menyelaraskan galeri & toko ke `grid-cols-2` compact, memendekkan clamp teks di mobile, dan memastikan build production dapat di-deploy.

## Highlights

- Galeri home + halaman library: grid 2 kolom mobile, kartu compact (judul + tanggal)
- Toko section home: grid 2 kolom, 4 produk awal di mobile
- Tentang kami & profil: clamp lebih pendek di mobile + gradient fade lebih kecil
- Build lokal lulus; siap auto-deploy production

## Features (detail)

### Galeri mobile 2×2 compact
- **Masalah / tujuan:** kartu galeri full-width tinggi di mobile.
- **Perilaku baru:** `grid-cols-2 lg:grid-cols-3`, aspect 4:3, body mobile minimal.
- **Siapa terdampak:** public / tenant
- **Permission:** public
- **Tenant-aware:** Yes
- **Source:** `client/src/components/public/library.tsx`

### Toko section mobile 2×2
- **Masalah / tujuan:** produk toko home 1 kolom di mobile.
- **Perilaku baru:** grid 2 kolom, 4 item awal.
- **Siapa terdampak:** public / tenant (jika toko aktif)
- **Source:** `client/src/components/public/toko-section.tsx`

### Tentang & profil lebih ringkas
- **Masalah / tujuan:** wall of text sebelum expand.
- **Perilaku baru:** `max-h` lebih kecil di mobile, `line-clamp` pada paragraf.
- **Source:** `client/src/components/public/about.tsx`, `client/src/pages/profil.tsx`

## User-facing impact
