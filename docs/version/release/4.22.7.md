## Summary

Enco AI kadang berhenti setelah menyatakan niat ("saya akan cek …") tanpa memanggil tool yang sebenarnya, terutama saat user meminta aksi tulis (mis. "buatkan berita X") di Dashboard. Patch ini memperkuat agent loop dengan dua lapis retry + instruksi hard prompt, sehingga Enco benar-benar memanggil tool tulis/list sebelum menjawab final. Selain itu, endpoint `POST /api/chat/message` sekarang streaming progress setiap tool yang dijalankan via Server-Sent Events (`text/event-stream`), sehingga FE menampilkan label aktivitas ("Membuat draft", "Mencari referensi", dst.) real-time. Default order model OpenAI diubah agar `minimax-m3` dicoba sebelum `glm-5.3`, sesuai preferensi tim.

## Highlights

- Hard-force tool calls: jika Enco over-explaining tanpa tool dan user meminta aksi tulis, server otomatis retry dengan instruksi "WAJIB panggil tool tulis PADA TURN INI".
- SSE streaming progress: setiap tool call mengirim event `step` ke FE; FE merender daftar langkah seperti agent loop pada umumnya.
- Default OpenAI = `phantom/vibecode/minimax-m3` (fallback `phantom/vibecode/glm-5.3`, lalu `auto`).
- Retry call di OpenAI & Gemini loop sekarang meneruskan callback `onStep`, sehingga progress konsisten antar provider.
- `chat-origin-gate` menerima `Accept: text/event-stream` (atau `*/*`) selain `application/json` agar FE tidak ditolak saat streaming.

## Features (detail)

### Feature / Change A — Hard-force tool call (write + web)
- **Masalah / tujuan:** Setelah v4.22.6, user masih melihat Enco menjawab niat/over-explaining tanpa memanggil `create_berita_draft` / `create_event` / `create_library_item` walaupun permission & path Dashboard sudah benar.
- **Perilaku baru:** `ChatService.shouldHardForceWriteTool()` mendeteksi (a) respons panjang tanpa tool, (b) kalimat stall ("sebentar ya", "tunggu"), atau (c) kalimat generic ("ada yang bisa saya bantu"). Jika user intent cocok (mis. "buatkan berita …"), server otomatis retry dengan prompt `INSTRUKSI TAMBAHAN WAJIB: … WAJIB panggil tool tulis PADA TURN INI`. Berlaku untuk OpenAI dan Gemini loop.
- **Siapa terdampak:** admin/editor yang punya permission tulis di Dashboard; agent loop OpenAI & Gemini.
- **Permission:** tidak ada perubahan; hanya enforced ketika tool tulis tersedia untuk permission.
- **Tenant-aware:** Conditional — ikuti `getToolsForPermissions()` (sama dengan flow existing).
- **Source:** `server/services/chat-service.ts`, `server/config/gemini-config.ts` (10b diluaskan dengan anti-over-explaining), `server/services/openai-service.ts`.

### Feature / Change B — SSE streaming agent steps
- **Masalah / tujuan:** Saat Enco memproses permintaan multi-step (search → buat draft), user hanya melihat loading spinner tanpa tahu apa yang sedang terjadi.
- **Perilaku baru:** `POST /api/chat/message` sekarang mengirim `Content-Type: text/event-stream`. Setiap tool call memancarkan event `step` berlabel aman (whitelisted mapping: "Membuat draft", "Mencari referensi yang relevan", dll.). Event `done` membawa chat object lengkap. Event `error` membawa pesan error. Heartbeat 15 detik agar proxy/browser tidak memutus.
- **Siapa terdampak:** user chat publik + dashboard.
- **Permission:** tidak ada perubahan.
- **Tenant-aware:** Conditional (tetap jalan di main + tenant).
- **Source:** `server/routes/chat.ts`, `server/services/chat-service.ts`, `server/services/openai-service.ts`, `server/services/ai-agent-progress.ts` (mapping), `server/middleware/chat-origin-gate.ts` (Accept header), `client/src/components/public/ai-chat.tsx` (panel UI).

### Feature / Change C — Default OpenAI model order
- **Masalah / tujuan:** Default fallback hanya `auto`; tidak ada preferensi eksplisit untuk model utama.
- **Perilaku baru:** `DEFAULT_OPENAI_MODELS = ['phantom/vibecode/minimax-m3', 'phantom/vibecode/glm-5.3', 'auto']`. Cache model kerja (`openai-working.json`) tetap diprioritaskan di depan.
- **Siapa terdampak:** semua user chat (main + tenant) yang tidak set `OPENAI_MODELS` di env.
- **Permission:** N/A.
- **Tenant-aware:** N/A.
- **Source:** `server/services/openai-service.ts`.

### Feature / Change D — System prompt anti-over-explaining
- **Masalah / tujuan:** Prompt system hanya melarang kalimat niat, tapi tidak melarang over-explaining generic.
- **Perilaku baru:** Bagian `10b` di system prompt diperjelas dengan aturan "JANGAN over-explaining" dan pola langkah eksplisit untuk aksi tulis.
- **Source:** `server/config/gemini-config.ts`.

## User-facing impact

- Halaman/route yang berubah: `/chat` (publik & dashboard).
- Perubahan UX: panel progress Enco sekarang menampilkan daftar langkah berlabel (planning → running → done/error) menggantikan 3-dot loader saat ada tool yang sedang berjalan.
- Yang perlu di-smoke test manual:
  1. Di Dashboard Berita dengan permission `berita.write`, minta "buatkan draft berita tentang X" → harus benar-benar membuat draft (muncul di list).
  2. Minta pertanyaan informasi biasa → loading spinner normal, jawab final dikirim.
  3. Test pada komunitas tenant (`/{slug}/dashboard/...`) → tool tulis tetap tunduk permission lokal.
