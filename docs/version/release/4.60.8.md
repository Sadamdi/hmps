## Summary

Halaman berita publik menampilkan event terkait draft untuk user yang login, dan endpoint related tidak memeriksa status base berita. Kini `GET /api/berita/slug/:slug/events` selalu hanya event published; `GET /api/berita/:id/events?public=1` sama (tanpa query tetap untuk editor dashboard). `GET /api/berita/:id/related` dan `/slug/:slug/related` mengembalikan 404 bila berita dasar draft dan pemanggil belum login. Preview galeri dan event pada daftar berita sudah memfilter `published` (tidak diubah).

## Changed

- `server/routes.ts`: filter published event, `authenticateOptional` + cek draft pada endpoint related.
- `client/src/pages/berita/[id].tsx`: fallback id memakai `?public=1`.
