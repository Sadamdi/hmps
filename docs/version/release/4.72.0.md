## Summary

Sebelumnya langganan web push hanya mengenal akun pengurus atau tamu: mahasiswa dan pembeli Encoder Store tidak bisa menerima notifikasi pribadi (pembeli hanya email), dan topik terbatas pada berita, event, balasan. Rilis ini menautkan satu langganan per perangkat ke semua akun yang login di perangkat itu, menambah topik untuk pesanan, karya, dan info kampus, serta menyatukan pengaturannya.

## Alur

1. Pengguna menyalakan notifikasi (lonceng / pop-up "Nyalakan"). `POST /api/notifications/webpush/subscribe` menyimpan perangkat + `userId` (pengurus) + `studentId` (sesi Ruang Mahasiswa) + `customerId` (sesi pembeli) yang ada di cookie.
2. Login belakangan? Ruang Mahasiswa dan akun Encoder Store memanggil `useLinkPushIdentity` sekali per sesi tab: bila izin sudah diberikan, perangkat ditautkan ulang tanpa mengubah pilihan topik.
3. Preferensi topik baru disimpan **per perangkat** (`WebPushSubscription.preferences.<topik>.webPush`); topik lama untuk pengurus tetap di `NotifPreference`. Modal menampilkan keduanya dalam satu daftar berkelompok.

## Pemicu

| Topik | Pemicu | Penerima |
|-------|--------|----------|
| `storeOrder` (`store_order_buyer`) | setiap kabar email pembeli (pesanan dibuat, bukti bayar, verifikasi, status, pengingat, batal) — dikirim walau pesanan tanpa email; mengikuti `notifyPrefs` akun | perangkat akun pembeli |
| `karyaStatus` (`karya_status`) | review disetujui / revisi / disembunyikan | perangkat akun mahasiswa pemilik |
| `karyaNew` (`karya_published`) | karya pertama kali tayang (review manual atau otomatis) | broadcast |
| `scholarship` / `internship` / `announcement` | item baru feed pengumuman saat sinkron prodi (`server/services/info-notifications.ts`) | broadcast |

Default: semua aktif kecuali `announcement` (pengumuman umum, bisa banyak) dan `bugReply` untuk tamu.

## Security

- Preferensi dari klien disaring ke daftar kunci yang diizinkan dan ditulis per kunci (`preferences.<k>.webPush`) — kunci asing (mis. `isActive`, `$set`) diabaikan (diuji).
- Identitas mahasiswa/pembeli diambil dari sesi server (cookie), bukan dari body.
- Notifikasi pesanan hanya ke perangkat yang tertaut ke akun pembeli pemilik pesanan; tidak ada data pesanan selain nomor pesanan di isi notifikasi.
