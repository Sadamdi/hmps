## Summary

Fitur "Import dari PDF" di Kepengurusan (`organization-structure-auto-fill`) hanya memakai slot kunci Gemini pertama; bila kuota/izin slot itu habis, seluruh import gagal meskipun ada 7 slot kunci aktif. Kini setiap slot dicoba berurutan (per slot semua model fallback).

## Highlights

- Rotasi semua slot `GEMINI_API_KEY_n` untuk ekstraksi PDF/gambar/Word kepengurusan.

## Features (detail)

### Change A — Rotasi kunci
- **Masalah / tujuan:** satu kunci habis = import gagal.
- **Perilaku baru:** `callGeminiWithModelFallback` mencoba slot × model.
- **Siapa terdampak:** pengguna dashboard dengan akses kepengurusan.
- **Permission:** tidak berubah.
- **Tenant-aware:** Yes
- **Source:** `server/services/organization-structure-auto-fill.ts`

## User-facing impact
