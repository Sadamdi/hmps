## Summary

Cron 00:00 WIB tanggal 26 dan 27 Sep berhasil untuk YouTube, tetapi Instagram gagal dengan 429 di langkah pertama instagrapi: lookup username→ID lewat `web_profile_info`. Selain itu dua komunitas (uinux-malang, ontakiuinmalang) yang belum pernah mengatur Media Sosial ikut memakai config bawaan: menampilkan YouTube Himatif dan menembak Instagram @himatif.encoder tiap malam (3× request ke akun yang sama). Rilis ini menyimpan ID akun Instagram (default situs utama `3058764066`, bisa diubah di dashboard, juga dipelajari dari sync) agar lookup web dilewati, mengambil profil via API mobile dengan cadangan dari data feed, dan menonaktifkan social feed komunitas sampai komunitas menyimpan pengaturannya sendiri.

## Highlights

- ID akun IG tersimpan → langkah `web_profile_info` (429) dilewati.
- Profil IG: `user_info_v1`, cadangan foto/nama/verified dari feed; statistik lama tidak tertimpa kosong.
- Komunitas tanpa pengaturan Media Sosial: YouTube & Instagram nonaktif (tidak tampil, tidak di-sync).
- Dashboard: kolom "ID akun Instagram" + ID yang terdeteksi saat sync.

## Features (detail)

### Change A — ID akun Instagram
- **Masalah / tujuan:** 429 pada lookup username→ID menggagalkan seluruh sync IG.
- **Perilaku baru:** `ig_feed.py <username> <limit> [user_id]`; Node mengirim `config.instagram.userId` (bila `userIdUsername` cocok dengan URL) atau `cache.profiles.instagram.userId` (bila username cocok). Output memuat `userId`, disimpan di profil cache.
- **Siapa terdampak:** admin/ops, public (feed IG).
- **Permission:** `social_feed.edit` untuk mengubah ID.
- **Tenant-aware:** Yes (per storage; default ID hanya untuk @himatif.encoder).
- **Source:** `ops/instagram/ig_feed.py`, `server/services/instagram-instagrapi.ts`, `server/services/social-feed.ts`, `shared/social-feed.ts`, `client/src/components/dashboard/social-feed-settings-panel.tsx`

### Change B — Default tenant nonaktif
- **Masalah / tujuan:** komunitas mewarisi kanal Himatif dan menambah beban rate limit.
- **Perilaku baru:** `resolveSocialFeedConfig(raw, isTenant)` — platform yang belum punya pengaturan tersimpan di storage komunitas dianggap nonaktif; dipakai route publik, manage, sync, dan cron.
- **Siapa terdampak:** public komunitas, admin komunitas.
- **Permission:** —
- **Tenant-aware:** Yes
- **Source:** `shared/social-feed.ts`, `server/routes/social-feed.ts`, `server/index.ts`
