## Summary

Pengurus kini bisa masuk dengan akun Google tanpa password, selama email Google-nya sama dengan email user yang sudah terdaftar (misalnya owner). Client memakai Firebase Auth (popup pilih akun) hanya untuk mendapatkan ID token Google; server memverifikasi token itu sendiri (tanda tangan Google, project, email terverifikasi, provider google.com, waktu login baru), mencocokkan email persis, lalu membuat sesi yang sama dengan login password. Tidak ada akun baru yang dibuat otomatis. Konteks main/komunitas mengikuti aturan login yang sudah ada.

## Highlights

- Tombol "Masuk dengan Google" bergaya standar Google di halaman login utama & komunitas.
- Verifikasi ID token di server (jose + JWKS securetoken Google), `auth_time` ≤ 10 menit.
- Hanya email terdaftar; 403 `GOOGLE_EMAIL_NOT_REGISTERED` untuk email lain.
- Config Firebase dari env server lewat `/api/auth/firebase-config` (ubah env cukup restart).
- Helmet COOP `same-origin-allow-popups` + CSP untuk popup Google.

## Features (detail)

### Feature A — Masuk dengan Google
- **Masalah / tujuan:** login tanpa mengetik password bagi pengurus yang emailnya Google.
- **Perilaku baru:** klik tombol → popup Google → token → `POST /api/auth/login/google` → sesi. Konteks: halaman komunitas → user komunitas; `loginTarget` → konteks tersebut; auto-detect → 409 pilih tujuan bila lebih dari satu.
- **Siapa terdampak:** auth (pengurus main & komunitas).
- **Permission:** tidak berubah; peran/izin tetap dari user yang cocok.
- **Tenant-aware:** Yes
- **Source:** `server/services/google-login.ts`, `server/routes.ts`, `server/security.ts`, `client/src/lib/google-signin.ts`, `client/src/components/auth/google-sign-in-button.tsx`, `client/src/components/auth/login-form.tsx`, `client/src/lib/auth.tsx`, `client/src/lib/tenant-auth.tsx`

## User-facing impact

- `/login` & `/:slug/login`: tombol Google di atas form + pemisah "atau" + catatan email terdaftar.
- Smoke test: login Google dengan email owner → dashboard; email tak terdaftar → pesan jelas; batal popup → tidak ada error.
