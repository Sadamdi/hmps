## Summary

Di produksi (dicek 2026-09-25), feed hanya menampilkan maks 5 YouTube / 4 Instagram, **tanpa tanggal terbit**, dan konten IG terakhir tertanggal 1 Juni 2026 — sync IG diam-diam gagal karena Instagram kini memblokir daftar post tanpa login (429 / `require_login`) dan sistem terus memakai cache lama. Selain itu tenant komunitas tidak pernah sync otomatis, tidak ada log fetch, dan kanal tanpa tab Shorts membuat video biasa (mis. 708 dtk) berlabel Shorts.

Rilis ini menulis ulang pipeline: YouTube disimpan per kategori (video 10 / shorts 10 / live 5) dengan tanggal pasti dari halaman watch; Instagram memakai rantai sumber gratis (sesi akun dummy opsional → scrape → link manual → cache) dengan enrich dari halaman embed publik dan tanggal dari shortcode. Beranda mendapat tab kategori, "Lebih banyak", dan "Lihat semua" ke halaman arsip baru; Instagram tampil seperti profil aplikasi IG di HP. Dashboard mendapat status, Fetch sekarang, jadwal, pengelola link manual, dan log. Fetch otomatis sekali sehari 02:30 WIB untuk situs utama dan semua komunitas aktif.

Risiko utama: Instagram tetap tidak bisa menemukan post baru secara otomatis tanpa sesi akun dummy — ini dibatasi oleh Instagram, bukan kode; jalur link manual dan status "diblokir" di dashboard membuatnya transparan.

## Highlights

- **YouTube per kategori** + tanggal terbit akurat + koreksi kategori (live dari `isLiveContent`, Shorts > 3 menit → video).
- **Instagram gratis tanpa token**: enrich via embed publik (gambar, caption, carousel/reel), tanggal dari shortcode, link manual, status blokir jujur.
- **Beranda**: tab Semua/Video/Shorts/Live; IG gaya profil HP (grid 3 kolom, Post 4:5 / Reels 9:16); 8 → 16 → Lihat semua (IG 9 → 18).
- **Halaman baru** `/media/youtube`, `/media/instagram` (main & `/:slug/media/*`) dengan kerangka arsip 4.24.
- **Dashboard**: Fetch sekarang per platform/semua, last fetch, jadwal berikutnya, log 20 terakhir; akses owner, admin, ketua, wakil, Medinfo.
- **Berita**: tab topik berganti acak (berbobot) tiap refresh.

## Features (detail)

### Change A — Sinkronisasi YouTube v2
- **Masalah / tujuan:** maks 5 item campur, tanpa tanggal; video biasa berlabel Shorts.
- **Perilaku baru:** InnerTube → scrape tab (`/@handle` atau `/channel/UC…`) → RSS; satu video satu kategori (live > short > video); `fetchYoutubeWatchMeta` untuk item baru saja; batas simpan per kategori; thumbnail lokal dipakai ulang.
- **Siapa terdampak:** public, admin/tenant
- **Permission:** sync `social_feed.sync`
- **Tenant-aware:** Yes
- **Source:** `server/services/social-feed.ts` (`syncYoutubeFeed`, `fetchYoutubeWatchMeta`, `scrapeYoutubeTabHtml`)

### Change B — Sinkronisasi Instagram v2
- **Masalah / tujuan:** IG tidak update; judul generik; story/live tidak diinginkan.
- **Perilaku baru:** rantai `web_profile_info` (sesi dummy opsional) → HTML → link manual (maks 200) → cache; `parseInstagramEmbed` (fungsi murni) + `fetchInstagramEmbed` (UA sederhana wajib); `instagramShortcodeToDate`; hanya post & reel; `blocked` + peringatan di status/log.
- **Siapa terdampak:** public, admin/tenant
- **Permission:** edit link `social_feed.edit`, sync `social_feed.sync`
- **Tenant-aware:** Yes
- **Source:** `server/services/social-feed.ts`, `shared/social-feed.ts`

### Change C — API, log, cron
- **Perilaku baru:** `GET /api/social-feed/items` (paginasi publik), `GET /api/social-feed/manage/logs`, `POST /sync {platform?}` dengan cooldown 60 dtk, validasi Zod; log 50 terakhir di `Settings.socialFeedLogs`; cron `30 2 * * *` Asia/Jakarta untuk main + tenant aktif.
- **Siapa terdampak:** public, admin, ops
- **Permission:** lihat tabel API
- **Tenant-aware:** Yes
- **Source:** `server/routes/social-feed.ts`, `server/index.ts`, `db/mongodb.ts`, `server/routes.ts`

### Change D — Tampilan publik & halaman arsip
- **Perilaku baru:** `social-feed-sections.tsx` (YouTube tab + unggulan + lebih banyak; Instagram profil HP), `social/social-cards.tsx`, `social/social-archive-page.tsx`, `pages/media/{youtube,instagram}.tsx`, route main + komunitas, slug `media` dicadangkan.
- **Siapa terdampak:** public (main & tenant)
- **Permission:** —
- **Tenant-aware:** Yes (wouter `Router base`)
- **Source:** file di atas, `client/src/App.tsx`, `client/src/pages/community/index.tsx`, `shared/tenant-paths.ts`

### Change E — Dashboard
- **Perilaku baru:** panel baru (status, Fetch sekarang, jadwal, pengaturan v2, link manual IG, log).
- **Siapa terdampak:** owner/admin/ketua/wakil/Medinfo (main), owner/BPH/Medinfo (tenant)
- **Permission:** `social_feed.view/edit/sync`
- **Tenant-aware:** Yes
- **Source:** `client/src/components/dashboard/social-feed-settings-panel.tsx`

### Change F — Roles & izin
- **Perilaku baru:** backfill startup `social_feed.*` → `admin`, `chair`, `vice_chair`, `medinfo`; migrasi sekali `social-feed-roles-v2` (cabut dari `bph`/`division_head`, buat role `medinfo` bila belum ada); grant divisi Medinfo (`server/division-permissions.ts`) di main & tenant; `canManageRole` mengenal `medinfo`.
- **Siapa terdampak:** auth/admin
- **Permission:** `social_feed.*`
- **Tenant-aware:** Yes (grant divisi)
- **Source:** `server/mongo-storage.ts`, `server/tenant-storage.ts`, `server/division-permissions.ts`, `server/auth.ts`

### Change G — Tab topik berita dinamis
- **Perilaku baru:** 8 tag dipilih acak berbobot frekuensi (Efraimidis–Spirakis, seed per load); tag aktif selalu tampil.
- **Siapa terdampak:** public
- **Source:** `client/src/pages/berita/index.tsx`

## Fixed

- **Instagram tidak update (~sejak Juni 2026):** kegagalan daftar post tertelan dan cache lama dipakai diam-diam → kini status `blocked` + jalur link manual/sesi dummy + enrich embed.
- **Video biasa berlabel Shorts:** URL `/shorts` pada kanal tanpa tab Shorts dialihkan ke beranda kanal, lalu `contentId` video biasa ikut terambil → tab Shorts hanya menerima `/shorts/ID` + koreksi durasi.
- **Tanpa tanggal terbit:** kini diisi dari halaman watch (YT) dan shortcode (IG).
- **Tenant tidak pernah auto-sync.**

## Security

- Cookie sesi IG hanya di env server; klien hanya menerima boolean.
- Validasi Zod pada endpoint baru/berubah; cooldown sync manual; allowlist host thumbnail tetap.
- `GET/PUT /api/settings` juga menyaring `socialFeedLogs`.
- Pengetatan akses social feed ke daftar role yang diminta owner.

## Ops / Tooling

- Cron harian 02:30 WIB; log tersimpan di Settings (bukan file).
