## Summary

`dedupeTrailingUserMessage` membuang pesan user terbaru dari riwayat (karena sudah tersimpan di `chat.messages`), lalu pemanggil tidak menambahkannya lagi. Model hanya melihat pesan lama, sehingga menjawab sekenanya dan menulis draft berita dari contoh atau karangan sendiri. Pesan terbaru sekarang tetap ada di riwayat dan tidak dobel.

## Fixed

- Model AI (semua jalur: OpenAI-compatible dan Gemini) kini menerima pesan user terbaru.
- Draft berita dari naskah user kembali berisi naskah user (v4.38.1 sudah menambah penjaga dan contoh gaya tanpa fakta).
