## Summary

API read-only `/api/monitor/v1` untuk melihat spesifikasi dan kondisi server secara live, dipakai pihak ketiga dengan API key.

1. **Metrik**: system, cpu (total/per-core, iowait, steal, PSI, load), memory+swap, disk+inode, disk I/O (MB/s, IOPS, busy%), network per interface, koneksi TCP/UDP, GPU NVIDIA bila ada, latensi (TCP/DNS), runtime aplikasi (heap, event-loop lag), health + alert; scope `full`: proses ala Task Manager, layanan systemd + PM2, MongoDB, fail2ban/reboot tertunda, IP interface, port listen.
2. **Live**: polling `/metrics` dan streaming SSE `/stream?interval=1..60`; riwayat 1 jam `/history`.
3. **Benchmark** sesuai permintaan `POST /bench` (CPU single/multi-thread via worker, memori, disk fsync, unduh opsional), dibatasi cooldown.
4. **Keamanan**: key `hmon_<id>_<secret>`, hanya hash SHA-256 tersimpan, `timingSafeEqual`, scope `basic`/`full`, rate limit per key, blokir 10 gagal/10 menit per IP, maks 3 stream per key, kedaluwarsa dan pencabutan; skrip admin `ops/monitor-key.ts`.
