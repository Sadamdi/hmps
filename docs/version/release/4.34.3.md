## Summary

Uji sinkron pertama ke Google Sheet produksi menulis pesanan dengan benar, tetapi kolom Jumlah/Subtotal/Total (Pesanan) dan Subtotal/Produk (Varian)/Status/Tanggal (Item) menjadi `#ERROR!`. Penyebab: sinkron menulis ulang rumus dengan pemisah `,`, sedangkan sheet ber-locale `id_ID` memakai `;`. Sinkron kini hanya menulis kolom data (Pesanan A–G, J–K, M–Q; Item A–E); rumus template tidak disentuh. Kolom Link Invoice berisi URL biasa (otomatis menjadi link). Baris yang sudah rusak diperbaiki dengan menyalin rumus dari baris template (PASTE_FORMULA).
