## Summary

Menyalakan kembali tombol "Akun pembeli" untuk pengurus (dinonaktifkan di 4.46.2) dengan model yang aman, dan melonggarkan ulasan agar tidak perlu login.

## Added

- `/api/buyer/link-staff/otp`, `/api/buyer/link-staff/verify`; `/api/buyer/from-staff` memakai tautan.
- `resolveLinkedStaff`, `unlinkStaffUser`, `staffScopeFromReq` di `unified-login.ts`; pelepasan tautan saat email pengurus diubah.
- `LinkStaffDialog`, tombol "Beri ulasan produk" di halaman pesanan.

## Changed

- Ulasan: kepemilikan lewat `findOwnedOrder` (akun / cookie perangkat / `?inv=`); `StoreReview.buyerId` opsional; GET viewer menandai ulasan milik pengunjung.

## Verification

- `npm run check` lolos.
- E2E tautan **30/30**, hardening 17/17 (satu kasus disesuaikan: akun pengurus tertaut memang bisa masuk lewat Google sebagai pembeli), pindah peran 18/18, ulasan 49/49 setelah penyesuaian 401→404.

## Notes / Known gaps

- Deteksi pencurian sesi, batas sesi pengurus 24 jam/diam 8 jam, dan aturan konfirmasi aksi tulis AI belum dikerjakan (ditunda ke rilis tersendiri).
- Tampilan dialog OTP tertaut belum diperiksa di browser (alur API diuji penuh).
