## Summary

Situs resmi TI menghapus halaman `/accreditation-certificate-for-master-s2/` (404). Sumber hidup untuk status akreditasi Magister (Baik Sekali, LAM INFOKOM 2025) ada di `/master-study-s2/`. Index kurikulum S1 memakai kartu `href="#"` sehingga sync hanya menyentuh 2020; seed URL 2024 ditambahkan. Item akreditasi digabung (merge by URL) agar riwayat sertifikat lama tidak hilang saat parse halaman profil S2 yang lebih ringkas.

## Highlights

- Akreditasi S2: source URL diganti ke Master Study profile
- Merge item akreditasi lama + baru (by `downloadUrl`)
- Kurikulum S1: seed `curriculum/` (2020) + `curriculum-2024-dan-rps/` (2024)
- Docs feature sync URL map diperbarui

## Features (detail)

### Change A — Accreditation S2 source
- **Masalah / tujuan:** sync S2 gagal HTTP 404; data stale dengan `lastError`
- **Perilaku baru:** crawl `/master-study-s2/`, filter PDF relevan, merge dengan item historis
- **Siapa terdampak:** public Prodi accreditation + admin sync
- **Permission:** `prodi.sync` (tidak berubah)
- **Tenant-aware:** No
- **Source:** `server/services/prodi-sync.ts`

### Change B — Curriculum index discovery
- **Masalah / tujuan:** kartu index resmi `Lihat Kurikulum` → `#`, tahun 2024 tidak ter-discover
- **Perilaku baru:** seed URL resmi + scan heading `Curriculum YYYY`
- **Siapa terdampak:** public kurikulum + sync overwrite
- **Source:** `server/services/prodi-sync.ts`
