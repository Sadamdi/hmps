## Summary

Owner melaporkan AI "rada-rada": diminta membuat draft berita malah menampilkan daftar berita, dan naskah lengkap yang dikirim berikutnya tidak dibuatkan draft. Analisis menemukan cabang retry yang tertukar (niat tulis diberi instruksi baca), deteksi niat berbasis regex khusus satu acara, prompt yang menyuruh list dulu, serta semua instruksi sistem dikirim sebagai pesan `user` (melemahkan pertahanan prompt injection). Rilis ini mengganti deteksi niat dengan klasifikasi yang membaca pesan sebelumnya, menyatukan keputusan retry, memakai role `system`, menyanitasi konteks halaman dari browser, dan menandai hasil tool sebagai data. Izin tetap diverifikasi server saat tool dieksekusi.

## Highlights

- "Buatin berita" tanpa isi → AI minta judul & isi (tidak menampilkan daftar).
- Naskah setelah permintaan → langsung `create_berita_draft`.
- Instruksi sistem sebagai role `system` (digabung satu pesan untuk provider OpenAI-compatible).
- `pageData` disanitasi (allowlist); hasil tool diberi label DATA; aturan keamanan agent.

## Features (detail)

### Change A — Klasifikasi niat & retry
- **Masalah / tujuan:** AI salah memilih tool saat diminta membuat konten.
- **Perilaku baru:** `classifyWriteIntent`, `pickRetryInstruction` (tulis → web → baca), hint sistem pra-eksekusi.
- **Siapa terdampak:** pengguna dashboard dengan izin konten.
- **Permission:** tidak berubah (server).
- **Tenant-aware:** Yes
- **Source:** `server/services/chat-service.ts`, `server/config/gemini-config.ts`

### Change B — Pengerasan prompt injection
- **Masalah / tujuan:** konteks browser & isi konten bisa meniru instruksi.
- **Perilaku baru:** role `system`; `sanitizePageData` di `routes/chat.ts`; `AI_SECURITY_RULES`; `serializeToolResult` membungkus `{ _note, result }`.
- **Source:** `server/routes/chat.ts`, `server/services/openai-service.ts`, `server/config/gemini-config.ts`

## User-facing impact
