## Summary

Kategori karya kini dibaca dari bahasa repo: tiga bahasa terbanyak (porsi byte ≥ 5%) masing-masing menyumbang kategorinya. Peta berisi ±240 bahasa GitHub Linguist. Bahasa khas (Dart, Kotlin, Swift, HTML/CSS/TS, Jupyter, Solidity, GDScript, VHDL, Dockerfile, TeX, dll.) langsung menetapkan kategori; bahasa serbaguna (Python, Java, Go, C, C#, Rust, Shell) hanya menambah bobot dan perlu bukti lain (file root, framework, topik, README). Karya lama ikut diklasifikasi ulang bertahap. Halaman publik Karya memakai bilah filter yang sama dengan Berita.

## Changes

- `shared/karya-languages.ts` (baru): peta bahasa → tag + kategori + kekuatan bukti.
- `shared/karya-tags.ts`: `inferKaryaStack` memakai 3 bahasa teratas + `languageShares`; kategori dari bahasa khas selalu masuk.
- `server/services/karya-repo.ts`: simpan porsi byte tiap bahasa; ikuti redirect API untuk repo yang di-rename/dipindah (hanya origin yang sama).
- `server/services/karya-classify.ts` (baru): `classifyProject`, `classifyStaleProjects` (gabung tanpa menghapus pilihan pemilik, buang "lainnya" bila ada deteksi nyata).
- `server/models/karya.ts`: field `autoClassifiedAt`.
- `server/routes/karya.ts`: `POST /api/karya/admin/projects/reclassify` (`limit`, `force`), jadwal 2 menit setelah start lalu tiap 3 jam (15 karya/putaran, ulang tiap 30 hari).
- `client/src/pages/karya/index.tsx`: `ArchiveFilterBar` (tombol Filter, kategori/angkatan/tag, urutan, chip aktif) + tab topik.
