## Summary

Owner ingin Ruang Mahasiswa menjadi wadah fitur mahasiswa TI di luar Karya (ruang belajar, kelompok, dsb.), dengan breadcrumb "Beranda / Ruang Mahasiswa / Dashboard". Semua halaman Karya dan dashboard mahasiswa dipindah ke `/ruang-mahasiswa/*`. Rilis ini juga menambah kontributor karya (manual + dari contributor repo GitHub), profil publik dua tab, tampilan kartu di dashboard mahasiswa dan admin, TinyMCE yang terbaca di mode gelap, dan hasil audit keamanan.

## Highlights

- `/ruang-mahasiswa/karya`, `/ruang-mahasiswa/mahasiswa/:username`, `/ruang-mahasiswa/dashboard` (+301 dari alamat lama)
- Kontributor otomatis dari repo GitHub + tautan ke akun Karya TI → karya muncul di profil semua pembuat
- Profil: Ringkasan & Portofolio
- Dashboard mahasiswa & admin berkartu; admin meninjau deskripsi ter-render
- Hardening: DNS rebinding, injeksi CSP, validasi key kontributor, mongoose & ag-psd

## Data / migrasi

- Tidak ada migrasi skema wajib: `contributors`, `contributorsSyncedAt` opsional; karya lama disinkron bertahap (scheduler 6 jam, 15 karya/putaran) atau sekaligus lewat `POST /api/karya/admin/contributors/sync {"limit":100,"force":true}`.
- URL lama (Google, WhatsApp, email terdahulu) dialihkan 301 ke alamat baru; sitemap memakai alamat baru.

## Security

| Temuan | Risiko | Perbaikan |
|--------|--------|-----------|
| DNS rebinding pada analisis embed (cek DNS lalu fetch = dua resolusi) | SSRF ke jaringan internal server | Validasi IP publik di `lookup` agent undici saat koneksi |
| `embedAllowedHosts` disisipkan apa adanya ke header CSP | Admin/akun admin yang dibobol bisa menambah directive (mis. `script-src *`) | Regex hostname ketat di `dynamicFrameSrc` dan `PUT /api/settings` |
| Key kontributor `gh:<apa saja>` dari klien | Entri sampah/URL avatar aneh | Validasi format login GitHub |
| mongoose < 8.24.7, ag-psd ≤ 31 | Advisory high (prototype pollution/DoS; PSD DoS) | Upgrade; `npm audit --omit=dev` = 0 |

Diperiksa tanpa temuan: open redirect `next` (hanya `/ruang-mahasiswa…` same-origin), redirect 301 (prefix tetap), IDOR kontribusi/edit (diuji), email (semua input di-escape), resolve kontributor (rate-limit + input divalidasi), detail publik tidak membocorkan email/ID akun.
