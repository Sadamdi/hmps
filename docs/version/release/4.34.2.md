## Summary

Project Google Cloud lama (`gen-lang-client-0095636115`) tidak diketahui pemiliknya sehingga Google Sheets API tidak bisa diaktifkan. Owner membuat project baru `himatif-encoder-web` dengan akun layanan `web-hima@himatif-encoder-web.iam.gserviceaccount.com` (Drive API + Sheets API). Kunci disimpan sebagai `server/google-service-account.json` (di-gitignore, `chmod 600` di server); kode Drive & Sheets membaca path itu (tetap bisa di-override `GOOGLE_APPLICATION_CREDENTIALS`). Logika sinkron ulang sheet dijadikan fungsi `resyncStoreSheetForSite` agar bisa dipanggil dari skrip ops.
