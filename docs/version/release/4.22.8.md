# Release v4.22.8 — Enco Agent: Langsung Tool Tulis, Jangan Over-Search

## Ringkasan

Patch release untuk memperbaiki perilaku agent Enco pada mode Dashboard. Sebelumnya, ketika user meminta pembuatan konten (draft berita, event, galeri) dan sudah menyertakan info lengkap di pesan, agent terlalu sering:

- memanggil tool pencarian (search_berita, search_events, get_dashboard_*, get_library_items, get_organization_structure) berulang kali;
- berakhir menjawab dengan ringkasan data dashboard, **tanpa** memanggil tool tulis yang relevan (`create_berita_draft`, `create_event`, `create_library_item`).

Setelah patch ini, agent dipaksa untuk langsung memanggil tool tulis sesuai perintah, hanya melakukan lookup jika user eksplisit minta referensi, dan tetap mempertahankan semua info dari pesan user (judul, paragraf pembuka, isi lengkap, kutipan, dll.).

## Yang Berubah

### Server

- `server/services/chat-service.ts`
  - Tambah helper `isWriteToolName()` dan `isReadToolName()` untuk klasifikasi tool tulis vs baca.
  - `shouldForceWriteToolRetry()`: berhenti return false setelah tool baca dipakai (model harus lanjut ke tulis); hanya return false bila tool tulis sudah terpanggil.
  - `shouldHardForceWriteTool()`: pakai `looksLikeUserWantsWriteAction()` lebih awal; return false begitu tool tulis terpanggil; tambah parameter `content` user.
  - Pesan retry ke model sekarang eksplisit: JANGAN panggil search/list/get_dashboard_*, LANGSUNG panggil tool tulis, PERTahankan semua info dari pesan user.
- `server/config/gemini-config.ts`
  - Tambah aturan pada `10b. ATURAN AGENT` bahwa jika user SUDAH menyertakan info lengkap di pesannya, LANGSUNG panggil tool tulis tanpa lookup.
  - Tegaskan JANGAN memotong isi pesan user; pertahankan paragraf, nama tokoh, kutipan, tanggal, dll.
  - Untuk `create_berita_draft` dari pesan user: title dari judul, excerpt dari kalimat pembuka, content HTML dari seluruh isi pesan.

## Verifikasi

- Live test SSE `POST /api/chat/message` (medinfo, path `/dashboard/berita`) dengan pesan lengkap Pra-STATIK 2026 BNI Visit — agent langsung membuat draft via `create_berita_draft` (1 tool call), tidak looping di `search_berita`.
- Skenario tambahan: user hanya menyertakan judul (tanpa isi lengkap) — agent tetap boleh panggil search dulu untuk referensi gaya, lalu create_berita_draft pada turn yang sama.
- `npm run check` lulus (tsc).

## Dampak / Catatan

- Perilaku lebih deterministik: pesan tulis akan selalu menghasilkan tool tulis (bukan ringkasan data).
- Untuk pertanyaan publik ("cari berita X"), alur lama tetap berlaku (search_berita langsung jawab).
- Bug user-facing yang dilaporkan: "kok ga lengkap ya??? yg saya ini kan udh lengkap segini" — teratasi.
