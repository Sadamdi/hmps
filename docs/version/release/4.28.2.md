## Summary

Setelah deploy 4.28.1, sync pembuka cursor gagal di halaman pertama (rate limit sisa percobaan sebelumnya), sehingga cursor tidak pernah tercipta dan job per jam (yang hanya jalan bila cursor ada) tidak pernah mulai. Rilis ini menjalankan job per jam selama backfill IG belum tuntas (cursor ada **atau** `backfilledAt.instagram` kosong), dan membatasi setiap run backfill — termasuk yang mulai dari halaman pertama — maksimal 3 halaman.

## Highlights

- Job `17 * * * *` jalan sampai backfill tuntas, tidak bergantung cursor pertama.
- Semua run backfill IG maks 3 halaman.

## Features (detail)

### Change A — Kondisi job & batas halaman
- **Masalah / tujuan:** backfill macet bila percobaan pertama gagal.
- **Perilaku baru:** job lanjut bila `backfillCursor.instagram` ada atau `backfilledAt.instagram` kosong; `maxPages: 3` untuk semua run `full`.
- **Siapa terdampak:** ops, public (arsip IG).
- **Permission:** —
- **Tenant-aware:** No (situs utama)
- **Source:** `server/index.ts`, `server/services/social-feed.ts`
