## Summary

**Auth, org structure, settings & editor.** Unit kerja ini mencakup 12 commit (MINOR: Core CMS/auth/org areas landed after bootstrap).  
Ringkasan historis disusun ulang dari git history (subjects + file impact). Untuk kontrak API/behavior **saat ini**, selalu verifikasi `docs/api/endpoints.md`, `docs/openapi.json`, dan feature docs terkait — beberapa detail di bawah bersifat retrospektif.

- Improve the appearance and navigation of main website sections
