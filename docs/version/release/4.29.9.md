## Summary

`server/index.ts` memanggil `dotenv.config()` di body modul, padahal import ESM dievaluasi lebih dulu. Modul yang membaca env saat load (`server/auth.ts`) melihat `JWT_SECRET` kosong: sebelum 4.29.5 memakai kunci bawaan, sejak 4.29.5 guard produksi membuat app crash. Deploy lalu me-restore dist lama dan tetap menandai HEAD sebagai "built", sehingga 4.29.5–4.29.8 tidak pernah benar-benar berjalan dan kunci JWT baru belum aktif. Rilis ini memuat env via `import 'dotenv/config'` sebagai import pertama (juga di `auth.ts`), dan deploy tidak lagi menandai build yang gagal start (marker `.deploy-failed-head` mencegah loop rebuild).

## Highlights

- `import 'dotenv/config'` paling awal → `JWT_SECRET` dari `.env` benar-benar dipakai.
- Build gagal start → exit 1, tidak ditandai built, dicatat jelas; auto-deploy tidak loop untuk commit yang sama.
- 4.29.5–4.29.8 (JWT, email bersama, kepengurusan AI, PDF, reload toko) aktif setelah rilis ini.
