## Summary

Dashboard overview sekarang menampilkan analytics visitor publik (grafik 1d/3d/7d/30d, top pages, device/geo/referrer, realtime, heatmap, berita leaderboard), system health (CPU/RAM/disk), security monitor, login attempts, dan content performance. Kunjungan halaman publik dicatat server-side (TTL 30 hari) dan digabung cron tiap 15 menit. Permission granular `overview.*` di-backfill ke role eligible setiap startup.

## Highlights

- Middleware tracking visitor publik + agregasi hourly/daily
- 8 widget dashboard di atas overview, masing-masing gated permission
- 13 permission `overview.*` + matrix role (owner/admin/chair/medinfo/PR/dll.)
- Hook `logSecurityEvent` (DDoS/SQLi) dan `logLoginAttempt` (auth)
- Fix ESM `require()` yang mencegah insert `page_visits` di production

## Features (detail)

### Visitor tracking & aggregation
- **Masalah / tujuan:** tidak ada metrik kunjungan publik untuk overview
- **Perilaku baru:** GET halaman publik (non-bot, non-static) menulis `page_visits`; cron `*/15` mengisi agregat
- **Permission:** `overview.visitor_graph`, `overview.top_pages`, `overview.referrer_sources`, `overview.device_breakdown`, `overview.geo_breakdown`, `overview.realtime_visitors`, `overview.heatmap`
- **Tenant-aware:** main site tracking (middleware global)
- **Source:** `server/models/page-visit.ts`, `server/models/visitor-stats.ts`, `server/routes.ts`, `server/index.ts`

### Dashboard overview widgets
- **Perilaku baru:** widget di top `client/src/pages/dashboard/index.tsx` via Suspense/lazy
- **Siapa terdampak:** user dengan permission overview relevan
- **Source:** `client/src/pages/dashboard/widgets/*`

### System / security / content endpoints
- `GET /api/dashboard/visitor-stats`, `active-visitors`, `engagement-heatmap`, `berita-leaderboard`, `system-health`, `security-monitor`, `login-attempts`, `content-performance`
- Auth + permission middleware seperti endpoint dashboard lain

## User-facing impact

- Halaman: `/dashboard` (overview) — widget baru di atas konten existing
- Smoke test: login sebagai owner/admin → widget muncul; medinfo tanpa system/security; hit `/` lalu cek visitor graph

- Models: `page_visits`, `visitor_stats`, `security_events`, `login_attempts`

## Fixed

- Backfill overview ke role existing (sebelumnya hanya di path create-roles yang early-return)
- `maskIp` / geoip / disk usage memakai ESM-safe imports (`require` gagal diam-diam di ESM)

## Security

- IP visitor di-hash (sha256 truncated); TTL raw 30d / security events 7d
- Security events dari DDoS tier block + SQL/NoSQL/XSS block
- Login success/fail tercatat untuk widget login attempts
