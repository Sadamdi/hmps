## Summary

Preview WhatsApp untuk berita baru (mis. Expo) sering tanpa thumbnail meskipun Facebook Debugger sudah scrape, karena cache WhatsApp terpisah dan cover berita masih WebP mentah. Unit kerja ini menambahkan JPEG share-cache untuk cover berita lokal (`/api/og/berita/:hash`) pada SSR, serta satu pintu `notifyPublicContent` yang memanggil IndexNow dan (opsional) Facebook Graph scrape untuk berita, galeri, event, plus hub pages dengan debounce. Tanpa token Facebook, publish tetap aman (no-op). Ranking Google untuk keyword kompetitif tidak dijamin.

## Highlights

- Cover berita lokal memakai `og:image` JPEG share-safe saat SSR.
- Publish konten publik → IndexNow + Facebook scrape (env-gated) lewat satu service.
- Hub pages (`/`, `/berita`, `/events`, `/library`, `/profil`, `/kelembagaan`, `/prodi`, `/toko`) ikut di-ping dengan debounce.
- Endpoint baru publik `GET /api/og/berita/:hash`.
- Ops terpisah: tanggal/views Expo berita+galeri+event diselaraskan ke 3 Okt 2026 15:00 WIB di production.

## Features (detail)

### Change A — OG JPEG berita
- **Masalah / tujuan:** WhatsApp kadang gagal menampilkan WebP cover berita; galeri sudah punya jalur JPEG.
- **Perilaku baru:** SSR resolve cover `/uploads/berita/...` ke `/api/og/berita/{hash}.jpg` (resize ≤1200, JPEG q80, cache disk 7 hari). Konten halaman tetap WebP.
- **Siapa terdampak:** public crawler / share embed
- **Permission:** publik
- **Tenant-aware:** Conditional (tenant berita SSR juga mencoba resolve yang sama)
- **Source:** `server/services/og-meta.ts`, `server/index.ts`

### Change B — Notify publik terpadu
- **Masalah / tujuan:** IndexNow hanya dipanggil langsung; belum ada Facebook scrape; hub pages jarang di-notify.
- **Perilaku baru:** `notifyPublicContent` menggantikan panggilan IndexNow di create/update berita, library, event. Menambah scrape Graph bila `FACEBOOK_SCRAPE_ENABLED` + token.
- **Siapa terdampak:** ops / SEO / Meta preview
- **Permission:** server-side only
- **Tenant-aware:** No (host IndexNow utama)
- **Source:** `server/services/public-content-notify.ts`, `server/services/facebook-scrape.ts`, `server/services/indexnow.ts`, `server/routes.ts`
