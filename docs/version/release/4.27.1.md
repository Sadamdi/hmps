## Summary

Backfill produksi pertama v4.27.0 berhasil untuk YouTube (119 item) tetapi Instagram terkena `PleaseWaitFewMinutes` (rate limit akun dummy). Dua kelemahan terlihat: rate limit di tengah paginasi membuang semua halaman yang sudah terambil, dan error rate limit (turunan `ClientError`) ikut memicu login ulang dengan password — berisiko membuat akun dummy dicurigai. Rilis ini menyimpan hasil parsial, tidak menandai backfill selesai bila terpotong, dan hanya login ulang untuk `LoginRequired`.

## Highlights

- Backfill IG terpotong rate limit → item yang sudah terambil tetap disimpan, backfill dilanjutkan pada fetch berikutnya.
- Rate limit tidak lagi memicu login ulang password.
- Jeda antar halaman backfill 4–8 dtk.

## Features (detail)

### Change A — Hasil parsial & penanda backfill
- **Masalah / tujuan:** progres backfill hilang saat rate limit.
- **Perilaku baru:** `fetch_feed` mengembalikan `(items, partial)`; Node memperlakukan backfill parsial sebagai merge biasa (arsip tidak dibuang), `backfilledAt` tidak diisi, status memuat peringatan `+backfill(parsial)`.
- **Siapa terdampak:** admin/ops.
- **Permission:** —
- **Tenant-aware:** Yes
- **Source:** `ops/instagram/ig_feed.py`, `server/services/instagram-instagrapi.ts`, `server/services/social-feed.ts`

### Change B — Login ulang hanya untuk sesi mati
- **Perilaku baru:** `except LoginRequired` saja; `PleaseWaitFewMinutes` → keluar dengan error jelas (sesi disimpan).
- **Source:** `ops/instagram/ig_feed.py`
