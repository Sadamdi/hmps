## Summary

Saat merekam tutorial, menambah "Link Download" ke `https://github.com/Sadamdi/smart/releases` gagal: editor menganggap semua URL di github.com/gitlab/bitbucket/codeberg sebagai repo dan menyuruh memakai kolom repo. Selain itu, link berjenis repo dibuang saat karya dibuka ulang di editor sehingga hilang pada penyimpanan berikutnya.

## Fixed

- `REPO_ROOT_RE`: hanya `https://host/user/repo` (tanpa label) diarahkan ke kolom repo; halaman lain (Releases, file, wiki) menjadi tautan berlabel.
- Hydrate editor mempertahankan link berjenis repo yang berlabel atau bukan akar repo.
- **Source:** `client/src/pages/karya/editor.tsx`

## API / OpenAPI impact

Tidak ada (server sudah menerima link berjenis repo).
