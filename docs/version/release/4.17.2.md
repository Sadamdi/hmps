## Summary

Endpoint `/api/dashboard/system-health` selalu 500 di production (`Dynamic require of "child_process" is not supported`) saat menghitung storage, sehingga widget menampilkan 0. Storage digeser ke helper ESM di `system-health.ts`. Poll UI dari 2s → 10s, tanpa full-card spinner saat refresh.

## Fixed

- ESM-safe disk/storage via `import { exec }` + `getStorageBreakdown()`
- Widget keep previous data; skeleton hanya first load; chart tanpa re-animate

## Ops note

WebSocket tidak dipakai: polling 10s ringan, tidak butuh koneksi persistent. Rate-limit sebelumnya lebih parah karena gagal 500 + poll 2s.
