## Summary

Setelah skrip kloning input dihapus (4.60.7), kolom dialog Insert/Edit Link bisa diketik tetapi tombol Cancel/Save tidak bisa diklik. Modal Radix memasang `pointer-events: none` di `<body>`; dialog/menu/popup TinyMCE dirender di luar modal dan mewarisinya. Skrip lama sebelumnya menutupi ini dengan memaksa `pointer-events: auto` lewat JS. Kini cukup CSS: `pointer-events: auto !important` untuk `.tox-tinymce-aux`, `.tox-dialog-wrap`, `.tox-silver-sink` dan turunannya.
