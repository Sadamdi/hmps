# Release v4.22.13 — Broader announce patterns + lower long-without-tool threshold

## Ringkasan

Patch lanjutan v4.22.12. Setelah v4.22.12 push, live test masih menunjukkan AI menjawab dengan English generic "I'll help you with information about Himatif Encoder. What would you like to know? Just tell me what you need — for example: ..." (panjang 350 char, tidak ada tool call).

Tambahan v4.22.13:
1. Tambah `announcePatterns` sangat luas untuk tangkap English welcome generic: 'silakan sebutkan', 'anda ingin', 'anda bisa', 'anda dapat', 'anda sedang', 'anda berada', 'misalnya:', 'for example', 'what would you like', 'just tell me', 'i will help', 'ada yang', 'mari kita', 'biasanya', 'apakah ada', 'ada lagi', 'silakan pilih', 'pilih topik', 'topik yang', 'kebutuhan spesifik'.
2. Turunkan threshold `longWithoutTool` 200 → 150 char di `shouldHardForceWriteTool`.

## Yang Berubah

### Server

- `server/services/chat-service.ts`
  - Perluas `announcePatterns` di `shouldForceWriteToolRetry`.
  - Turunkan `longWithoutTool` di `shouldHardForceWriteTool` ke 150 char.
