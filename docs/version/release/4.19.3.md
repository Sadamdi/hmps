## Summary

Setelah deploy `4.19.2` terverifikasi jalan di production (dicek via SSH ke VPS + `pm2 list` menunjukkan `hmps-app` versi `4.19.2` online), verifikasi lanjutan langsung di DOM live site menunjukkan regresi: **semua** iframe Google Drive di artikel berhenti total memuat — `iframeCount: 0`, `spinnerCount: 7` bahkan setelah scroll ke tengah halaman dan menunggu. Root cause: `useEffect` yang memasang `IntersectionObserver` di `4.19.2` punya dependency array `[driveIframeInView]` — saat `MediaDisplay` mount pertama kali, `mediaState.loading` masih `true` sehingga komponen early-return sebuah spinner generik (bukan div ber-`ref`); `useEffect` itu tetap jalan sekali di titik ini, mendapati `driveIframeContainerRef.current === null`, dan langsung `return` tanpa memasang observer apa pun. Karena dependency array hanya berisi `driveIframeInView` (yang tidak pernah berubah karena observer tidak pernah terpasang), effect itu **tidak pernah berjalan lagi** — deadlock permanen, lebih parah dari bug `4.19.2` yang coba diperbaiki (dulu sebagian video macet karena rebutan network; sekarang **semua** video macet karena observer tidak pernah aktif).

Fix: tambahkan `mediaState.loading` ke dependency array, sehingga effect re-run begitu loading selesai dan div ber-`ref` benar-benar ter-render — observer berhasil attach ke elemen yang sesungguhnya.

## Features (detail)

### Fix — Perbaiki dependency array IntersectionObserver
- **Masalah / tujuan:** Effect pemasang `IntersectionObserver` (ditambahkan di `4.19.2`) tidak pernah berhasil attach karena ref target belum ter-render saat effect pertama kali jalan, dan tidak ada re-trigger setelah itu.
- **Perilaku baru:** Dependency array effect ditambah `mediaState.loading`, sehingga effect re-run begitu state loading MediaDisplay selesai dan elemen ber-`ref` (kontainer iframe Drive) benar-benar mount — observer berhasil terpasang dan lazy-load bekerja sesuai desain `4.19.2`.
- **Siapa terdampak:** publik — semua halaman yang merender video Google Drive lewat `MediaDisplay`
- **Permission:** N/A
- **Tenant-aware:** N/A
- **Source:** `client/src/components/MediaDisplay.tsx`
