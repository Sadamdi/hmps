## Summary

Pengguna melaporkan (1) tabel di deskripsi karya tampil "maksa" di HP — kolom pertama dipatahkan per huruf dan ada backtick di sekitar kode; (2) "Ambil info repo" tidak memperbarui deskripsi yang sudah terisi tanpa memberi tahu, padahal tag tetap ditambahkan.

## Fixed

- CSS global `.prose`/`.rich-fit` di `client/src/index.css`: tabel `display:block; width:max-content; overflow-x:auto`, sel `min-width 8rem`, `overflow-wrap:normal`; `overflow-wrap:anywhere` hanya untuk paragraf/list/link. Menggantikan kelas utilitas di `RichHtmlWithEmbeds` yang mematahkan sel.
- Backtick dekoratif Typography dihapus; inline code bergaya chip.
- `markdownToHtml` (server) & `RichHtmlWithEmbeds` (klien): `` `teks` `` di luar `<pre>` → `<code>`.
- TinyMCE `content_style`: tabel bergulir, sel berbingkai, margin & ukuran huruf di layar ≤640px.

## Added

- Dialog konfirmasi (AlertDialog yang sudah ada) saat README repo bisa menggantikan deskripsi (dan ringkasan) yang sudah terisi; tag/link/gambar tetap hanya ditambahkan.
- Konfirmasi saat unggah README.md menimpa README profil yang sudah berisi.
