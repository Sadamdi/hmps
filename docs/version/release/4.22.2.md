# Release v4.22.2 — Fix Enco GLB 404 on nginx /assets path

| Version | `4.22.2` | PATCH | 2026-09-02 |

## Summary

Nginx serves `/assets/*` from `dist/public/assets/`, but `enco.glb` was only in repo `public/` (not copied by Vite). This caused 404 on the mascot GLB and React ErrorBoundary showed site-wide Error 500 when Three.js failed. GLB now in `client/public/assets/mascot/` for build; mascot wrapped in local error boundary.

## Fixed

- `enco.glb` included in Vite build output
- Mascot WebGL errors no longer crash entire page
