## Summary

Tiga halaman list publik sebelumnya tidak konsisten satu sama lain: `/berita` punya hero editorial sendiri, `/library` memakai header rata tengah dari beranda tanpa pagination (`limit=100` tampil sekaligus), dan `/events*` hanya `<h1>` polos dengan container sempit tanpa search/filter/pagination. Rilis ini memberi ketiganya satu kerangka identitas ("Encoder Archive") yang memakai bahasa visual beranda — pill eyebrow + garis cyan `PublicSectionHeader`, token `primary`, kartu `rounded-xl` + `border-border/70` + hover border primary — ditambah lapisan metadata monospace dan nomor indeks arsip. Tata letak isi dibedakan per jenis konten: Berita jadi newsroom (lead story + kolom Terbaru + tab topik), Event jadi linimasa per bulan, Galeri tetap grid dengan nomor indeks. Semua endpoint, query, dan halaman detail tidak berubah. Risiko utama ada di paritas filter berita (`?tag=` dari URL, reset halaman) — sudah diverifikasi manual.

## Highlights

- **Header seragam `ArchiveHeader`** di Berita, Event, Galeri: breadcrumb → pill eyebrow → judul → garis cyan → deskripsi → baris statistik mono dengan count-up singkat.
- **`ArchiveFilterBar` bersama**: search + panel filter + chip filter aktif yang bisa dihapus satu-satu; menempel di bawah navbar saat scroll (IntersectionObserver, bukan listener scroll).
- **Berita newsroom**: lead story besar + 4 judul "Terbaru" bernomor + tab topik (8 tag terpopuler). Lead hanya muncul tanpa filter/search, dan grid memaginasi sisanya — tidak ada artikel tampil dua kali.
- **Event linimasa**: label bulan sticky, rail yang "menggambar" saat terlihat, node berwarna sesuai status; kini ada search, filter status, dan pagination.
- **Galeri** kini berpagination 9/6 dan bernomor indeks; kartu, carousel, Dialog "Cepat lihat", dan Drive embed tidak berubah logikanya.

## Features (detail)

### Change A — Komponen arsip bersama
- **Masalah / tujuan:** tiga halaman punya tiga header dan dua salinan kode filter yang hampir identik.
- **Perilaku baru:** `ArchiveHeader`, `ArchiveFilterBar`, `ArchiveIndex`/`ArchiveGridItem`, hook `useArchiveFilters` (search judul/deskripsi case-insensitive, tag = OR, tahun = tunggal — semantik sama dengan filter lama).
- **Siapa terdampak:** public
- **Permission:** N/A (halaman publik)
- **Tenant-aware:** Conditional — tetap memakai `useTenant`/fetch relatif seperti sebelumnya, route community (`pages/community/index.tsx`) memuat halaman yang sama.
- **Source:** `client/src/components/public/archive/*`, `client/src/hooks/use-archive-filters.ts`

### Change B — `/berita` newsroom
- **Masalah / tujuan:** 71 artikel tampil rata tanpa hierarki; tag tersembunyi di Collapsible.
- **Perilaku baru:** `BeritaLead` (1 utama + 4 terbaru) di halaman 1 tanpa filter; tab topik horizontal (scrollable di mobile); kartu grid dengan nomor indeks global, tanggal mono, penulis & jumlah pembaca di footer kartu; loading jadi skeleton; empty state punya tombol "Reset pencarian". `AOS.init` lokal (duration 500, bentrok dengan init global 420 di `App.tsx`) dihapus.
- **Siapa terdampak:** public
- **Permission:** N/A
- **Tenant-aware:** Conditional (sama seperti sebelumnya)
- **Source:** `client/src/pages/berita/index.tsx`, `client/src/components/public/berita/berita-lead.tsx`

### Change C — `/events`, `/events/:year`, `/events/all` linimasa
- **Masalah / tujuan:** halaman event tanpa search/filter/pagination, container `max-w-4xl`, dan kartu berisi `<a>` di dalam `<a>` (badge berita terkait di dalam link kartu).
- **Perilaku baru:** `EventTimeline` + `useEventArchiveFilters` (search + status, filter status hanya tampil bila ada >1 status), pagination 12 desktop / 6 mobile, container `max-w-7xl`. Kartu memakai stretched link — seluruh kartu tetap bisa diklik, badge berita terkait tetap menuju artikelnya, tanpa anchor bersarang. `/events` menampilkan jumlah kegiatan per tahun (dari `/api/events/published`, query key sama dengan `/events/all`) dan state error dengan tombol "Coba Lagi".
- **Siapa terdampak:** public
- **Permission:** N/A
- **Tenant-aware:** Conditional
- **Source:** `client/src/pages/events/index.tsx`, `client/src/pages/events/[year].tsx`, `client/src/pages/events/all.tsx`, `client/src/components/public/events/event-timeline.tsx`

## Notes / Known gaps

- **Animasi exit sengaja tidak dipakai** pada grid dan chip filter: saat tab tidak di-paint, exit framer-motion bisa tertahan sehingga kartu halaman lama ikut tampil bersama halaman baru (terlihat saat pengujian). Kartu yang tersisa tetap bergeser halus lewat `layout`.
- Filter status event baru muncul bila data punya lebih dari satu status (mis. saat ada event berlangsung/akan datang).
- Tidak ada WebGL/3D di halaman list (keputusan desain: bobot aset maskot 4,8 MB dan audiens mobile). Maskot 3D tetap di AI Chat.
- Beranda belum dimigrasikan ke token arsip: masih ada beberapa variasi radius/hover/container antar section. Kandidat unit kerja lanjutan.
- `components/public/library.tsx` masih menyimpan cabang `variant === 'page'` yang kini tidak dipakai route mana pun; dibiarkan untuk kompatibilitas, bisa dibersihkan kemudian.
