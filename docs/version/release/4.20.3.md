## Summary

Widget Berita Leaderboard di Overview ditambah toggle **Views | Comments**: mode comments meranking berita dengan jumlah komentar terbanyak (termasuk reply) dan menampilkan preview komentar terbaru. Global range Overview mendapat opsi **All** (semua data stats yang masih retained). Raw `page_visits` TTL dinaikkan dari 30 hari ke **90 hari**; komentar konten tidak ikut dibersihkan.

## Highlights

- Toggle Views / Comments di satu widget leaderboard
- Range All di header Overview
- Retention visit stats 90 hari

## Features (detail)

### Feature — Berita leaderboard by comments
- **Masalah / tujuan:** Admin ingin tahu berita paling aktif dikomentari, bukan hanya views
- **Perilaku baru:** `metric=comments` aggregate Comment `targetType=berita`; top 10; preview author+body
- **Siapa terdampak:** role dengan `overview.berita_leaderboard`
- **Permission:** `overview.berita_leaderboard` (tidak berubah)
- **Tenant-aware:** No (main dashboard)
- **Source:** `server/routes.ts`, `berita-leaderboard.tsx`

### Feature — Overview range All
- **Masalah / tujuan:** Lihat statistik sepanjang data retained, bukan hanya 30d max di UI
- **Perilaku baru:** `RangeKey` + `RANGE_OPTIONS` include `all` (days=90); visitor-stats / content-performance / heatmap / security / login menerima window hingga 90d
- **Source:** `overview-range-context.tsx`, dashboard overview endpoints

### Change — PageVisit TTL 90d
- **Masalah / tujuan:** User ingin stats bertahan ~3 bulan tanpa menggelembungkan DB selamanya
- **Perilaku baru:** TTL index `page_visits_ttl` expireAfterSeconds=90d; boot `ensurePageVisitTtlIndex()` drop legacy 30d index
- **Siapa terdampak:** ops / analytics storage
- **Source:** `server/models/page-visit.ts`, `server/index.ts`
