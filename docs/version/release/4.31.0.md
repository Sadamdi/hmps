## Summary

Owner melaporkan tombol "Tambah admin" di dashboard tidak berfungsi: admin baru dibuat dengan nomor kosong lalu langsung dibuang oleh normalisasi daftar di parent, sehingga baris edit hilang. Editor kini menahan admin baru secara lokal sampai disimpan. Sesuai permintaan owner, toko ditambah **Chat penjual** (seperti marketplace: tanya produk di web, admin membalas dari dashboard, bisa lanjut ke WhatsApp admin) dan **Favorit** (disimpan di browser tanpa login, seperti keranjang). Audit alur stok menemukan pesanan yang dibatalkan tidak mengembalikan stok; kini stok berkurang saat checkout (seperti marketplace) dan dikembalikan saat pesanan dibatalkan/ditolak atau dihapus. Server dev (`tsx`) juga gagal memuat model toko karena `require` di modul ESM; diganti import statis.

## Highlights

- Perbaikan tombol "Tambah admin" (global & override produk).
- Chat penjual: panel chat di halaman produk, inbox "Chat" di Dashboard → Toko, polling otomatis, tombol "Lanjut ke WhatsApp".
- Favorit ❤ di kartu & detail produk, filter "Favorit (n)" di katalog.
- Stok kembali saat pesanan dibatalkan/dihapus; dibuka lagi → stok diambil lagi (ditolak bila tidak cukup).
- `require` → import statis di `server/routes/store.ts` & `server/routes.ts` (mode dev).

### Change B — Chat penjual
- **Perilaku baru:** model `StoreChat` (main + tenant); satu utas per produk per sesi tamu (cookie toko). Endpoint publik `GET/POST /api/store/chats`, `GET /api/store/chats/:id`, `POST /api/store/chats/:id/whatsapp`; admin `GET /api/store/admin/chats`, `GET /api/store/admin/chats/:id`, `POST /api/store/admin/chats/:id/messages`, `PATCH /api/store/admin/chats/:id`. Pesan ≤1000 karakter, ≤300 pesan/utas, rate limit checkout. Hash sesi tidak dikirim ke admin; sesi lain tidak bisa membaca utas.
- **Permission:** admin memakai `requireStoreDashboard`.
- **Tenant-aware:** Yes
- **Source:** `server/routes/store.ts`, `db/mongodb.ts`, `db/tenant.ts`, `client/src/components/toko/store-chat-panel.tsx`, `client/src/components/dashboard/store-chat-inbox.tsx`

### Change C — Favorit
- **Perilaku baru:** `useStoreFavorites` (localStorage per situs/komunitas, sinkron antar tab); `GET /api/store/public/products?ids=…`.
- **Source:** `client/src/hooks/use-store-favorites.ts`, `client/src/components/toko/store-favorite-button.tsx`, `client/src/components/public/store-product-card.tsx`, `client/src/pages/toko/index.tsx`

### Change D — Stok
- **Perilaku baru:** `StoreOrder.stockDecrements`, `stockRestoredAt`, `whatsappAdminName`; `PATCH /admin/orders/:orderNo` status `cancelled` mengembalikan stok sekali; status aktif lagi mengambil stok lagi; `DELETE` pesanan aktif mengembalikan stok.
- **Source:** `server/routes/store.ts`, `db/mongodb.ts`
