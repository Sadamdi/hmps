## Summary

Admin toko melaporkan file Export Excel menampilkan kartu Ringkasan kosong (angka tidak muncul). exceljs menulis rumus tanpa hasil tersimpan, dan Excel desktop tidak menghitung ulang otomatis. Workbook kini menandai `fullCalcOnLoad`, sehingga Excel menghitung semua rumus saat file dibuka (setelah "Enable Editing" bila file dibuka dalam Protected View).

## Highlights

- `calcPr fullCalcOnLoad="1"` di workbook export.
