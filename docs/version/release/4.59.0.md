## Summary

Halaman prodi mendapat tab Beasiswa: daftar program (internal UIN dan eksternal, filter S1/S2) yang tautan infonya bisa diubah admin, ditambah kabar beasiswa terbaru yang di-crawl otomatis dari Kemahasiswaan UIN Malang, portal Beasiswa Kemdiktisaintek, dan Beasiswa Kemenag (BIB).

## Findings

- Tidak ada fitur beasiswa di hub mahasiswa. Sumber internal terbaik: `kemahasiswaan.uin-malang.ac.id` (RSS pencarian "beasiswa", terbaru 19 Okt 2026). Feed kategori beasiswa situs TI hanya berisi satu entri dari 2019.
- Sinkronisasi prodi sehat; URL dosen yang dipakai kode sudah benar (`/lecturer-staff/`). Sisa rujukan lama `/lecturer-and-staff/` (404) ada di konfigurasi Gemini dan default skema; diperbaiki.
- Data dosen di DB (35, mode override manual) vs situs (37): belum ada Dr. Ir. Supriyono dan Shoffin Nahwa Utama, M.T. Laboratorium pengajaran: situs memang tidak mencantumkan (0 di keduanya).
- Crawl Instagram (data produksi): sejak 15 Okt diblokir Instagram (butuh login), dan 20 Okt gagal `spawn ENOMEM`. Cache terakhir berisi 97 item, terbaru 21 Sep 2026.

## Changed

- `shared/prodi-student-hub.ts`: tipe `ProdiScholarship`, `DEFAULT_SCHOLARSHIPS` (8 program), `sanitizeScholarshipHub` (hanya tautan http/https), `scholarshipHub` pada hub.
- `server/services/prodi-student-resources.ts`: feed Kemahasiswaan, Kemdiktisaintek, Kemenag; kategori `beasiswa` diperluas (KIP Kuliah, LPDP, Cendekia, dll).
- `client/src/components/prodi/student-hub-sections.tsx`: `BeasiswaSection`; `client/src/pages/prodi.tsx` tab Beasiswa; `client/src/pages/dashboard/prodi.tsx` tab dan `ScholarshipEditor` (simpan = override, tidak ditimpa sync).
- `server/config/gemini-config.ts`, `db/mongodb.ts`: URL dosen diperbarui.

## Verification

- `npm run check` lolos. Sinkronisasi pengumuman tanpa menyimpan: 136 item, 46 berkategori beasiswa (Kemahasiswaan 43, Kemdiktisaintek 1, Kemenag 2).

## Notes / Known gaps

- Daftar program awal dibuat dari situs resmi masing-masing; syarat dan jadwal tidak disalin, pengunjung diarahkan ke tautan resmi.
- Dua dosen baru belum masuk karena bagian dosen diset manual; perlu ditambahkan dari dashboard atau override dimatikan.
- Instagram: butuh sesi akun (INSTAGRAM_SESSION_ID atau akun dummy) di server dan memori cukup untuk memunculkan Python.
- Perbandingan RPS UIN lain tidak dimasukkan (di luar fokus TI UIN Malang; situs UIN lain berbeda-beda dan sebagian tidak terjangkau).
