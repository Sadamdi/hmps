## Summary

Laporan owner: setelah membuat akun (mahasiswa atau pembeli) halaman berpindah ke `/login` dan meminta masuk lagi walau sesi sudah dibuat. Penyebabnya cache "belum login" yang sedang dimuat ulang dianggap final oleh `useStudent`/`useBuyer`; kini diperbaiki dan cache diisi langsung dari respons. Rilis ini juga menambah isi otomatis pintar dari README repo (ringkasan, deskripsi rich text, gambar, video), sinkron profil dari GitHub (dan foto Google), pratinjau profil sendiri, serta penjelasan dan tombol pratinjau untuk shortlink.

## Highlights

- Fix: daftar/masuk tidak lagi dilempar ke `/login`
- README pintar: ringkasan, deskripsi, gambar (dipilih, tanpa kuota), video YouTube & lampiran video GitHub
- Impor profil GitHub + foto GitHub/Google
- Pratinjau profil sendiri
- Shortlink: penjelasan cara kerja, "Pratinjau tujuan", "Uji shortlink"

## Features (detail)

### Change A — Fix redirect setelah daftar/masuk
- **Masalah / tujuan:** setelah daftar sukses, `/karya/saya` atau akun toko membaca cache `null` lama → redirect ke login.
- **Perilaku baru:** `loading` = memuat awal ATAU sedang memuat ulang tanpa data; `setStudentCache()` dari respons login/daftar/Google/reset.
- **Siapa terdampak:** mahasiswa, pembeli
- **Source:** `client/src/hooks/use-karya.ts`, `client/src/hooks/use-buyer.ts`, `client/src/pages/karya/masuk.tsx`

### Change B — README pintar
- **Perilaku baru:** `fetchReadmeInsights()` (GitHub API raw / GitLab raw / Codeberg raw) → `marked` → disanitasi `sanitizeCmsHtml`; gambar host diizinkan saja; `externalMedia` di create/update karya → media `external: true`, ukuran 0, tidak memakan kuota, penghapusan tidak menyentuh disk; link `kind: 'video'` untuk file video langsung/lampiran GitHub; CSP `media-src` + github.com, *.githubusercontent.com.
- **Source:** `server/services/karya-readme.ts`, `server/routes/karya.ts`, `client/src/pages/karya/editor.tsx`, `server/security.ts`, `shared/karya.ts`, `server/models/karya.ts`

### Change C — Sinkron profil
- **Perilaku baru:** `POST /api/karya/me/profile/import-github` (data publik GitHub, tidak menyimpan otomatis); `PATCH /me/profile` menerima `avatarUrl` dari GitHub/Google; Google login memasang foto Google bila belum ada.
- **Source:** `server/routes/karya.ts`, `server/services/google-login.ts`, `client/src/pages/karya/saya.tsx`

### Change D — Pratinjau profil & shortlink
- **Perilaku baru:** `/karya/saya/pratinjau-profil` (komponen `StudentProfileView` dipakai bersama halaman publik); tab Shortlink berisi penjelasan dan tombol pratinjau/uji.
- **Source:** `client/src/pages/karya/pratinjau-profil.tsx`, `client/src/pages/karya/mahasiswa/[username].tsx`, `client/src/pages/karya/saya.tsx`
