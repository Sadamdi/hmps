## Summary

File rekap toko (Export Excel & template Google Sheet) ditambah sheet **Bulanan** (pilih tahun lewat dropdown; pesanan, lunas, batal, omzet, barang terjual, rata-rata per bulan, total, bulan terbaik) dan **Tahunan** (rekap per tahun + pertumbuhan omzet berwarna). Sheet Item mendapat kolom Tanggal Pesanan untuk rekap barang terjual per periode. Tanggal kini ditulis dalam jam WIB (sebelumnya UTC, sehingga pesanan 00:00–06:59 WIB di tanggal 1 terhitung di bulan sebelumnya). Kapasitas baris berumus dapat diatur (`extraRows`, template sinkron 3.000 baris).

## Highlights

- Sheet Bulanan & Tahunan berbasis rumus (ikut berubah saat data bertambah).
- Kolom Tanggal Pesanan di Item.
- Tanggal WIB.
