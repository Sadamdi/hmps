## Summary

Mesin pencari sebelumnya hanya mendapat daftar URL di sitemap tanpa petunjuk cover/foto/video. Unit kerja ini menambahkan ekstensi Google image/video ke `/sitemap.xml`, memperkaya JSON-LD (ImageObject, VideoObject, Organization/WebSite), memotong `<title>` agar sesuai SERP (~60 karakter), dan membuka path media di `robots.txt`. Ini meningkatkan peluang konten muncul di pencarian web **dan** Images/Video; ranking teratas tetap bergantung pada otoritas konten dan waktu crawl, bukan hanya teknis SEO.

## Highlights

- Sitemap dinamis dengan `xmlns:image` / `xmlns:video` untuk berita, event, galeri, toko
- SSR: NewsArticle + ImageObject; galeri multi-image + VideoObject YouTube/mp4
- Title dokumen dipotong untuk Bing/Google SERP
- Homepage Organization + WebSite JSON-LD; `/toko` listing meta
- Docs ops: langkah resubmit sitemap setelah deploy

## Features (detail)

### Dynamic media sitemap
- **Masalah / tujuan:** Crawler tidak tahu URL cover/thumbnail/video dari halaman HTML saja
- **Perilaku baru:** Setiap URL published menyertakan `<image:image>`; galeri YouTube/mp4 menambah `<video:video>`
- **Siapa terdampak:** public crawlers (Google, Bing, Yandex)
- **Permission:** public
- **Tenant-aware:** No (main site sitemap)
- **Source:** `server/index.ts`, `server/services/seo-sitemap.ts`

### Richer SSR schema & titles
- **Masalah / tujuan:** Title terlalu panjang (peringatan Bing); schema gambar/video lemah
- **Perilaku baru:** `seoDocumentTitle`; `og:image:alt`; ImageGallery multi-image; VideoObject
- **Siapa terdampak:** public SSR pages
- **Permission:** public
- **Tenant-aware:** No
- **Source:** `server/index.ts`
