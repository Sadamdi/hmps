## Summary

Setelah push 4.14.5, auto-deploy menjalankan `npm install` dengan `NODE_ENV=production`. `vite` (devDependency) terhapus, `npm run build` gagal (`vite: not found`), trap me-restart PM2, tetapi `dist/index.js` tetap meng-import `vite` sehingga proses “online” tanpa listen `:5000` → Cloudflare 502. Perbaikan: install selalu `--include=dev`, skip stop/build untuk commit non-runtime, healthcheck localhost:5000, dan media commit memakai identity Adam (bukan Auto-Deploy Bot).

## Features (detail)

### Deploy skip + healthcheck
- **Masalah / tujuan:** Setiap push (termasuk docs) stop app 5–15 menit; gagal build meninggalkan 502
- **Perilaku baru:** Rebuild hanya jika `client/` `server/` `shared/` `db/` `public/` / lockfile / vite-config berubah, atau vite hilang dari `node_modules`
- **Siapa terdampak:** ops / public uptime
- **Permission:** N/A
- **Tenant-aware:** No
- **Source:** `ops/deploy-server.sh`

### npm --include=dev
- **Masalah / tujuan:** `NODE_ENV=production` + `npm install` memangkas vite; bundle esbuild `--packages=external` tetap `import 'vite'`
- **Perilaku baru:** `NPM_CONFIG_PRODUCTION=false` + `--include=dev`
- **Siapa terdampak:** production runtime
- **Permission:** N/A
- **Tenant-aware:** No
- **Source:** `ops/deploy-server.sh`, `/root/auto-deploy.js` (`docs/ops/_auto-deploy.js`)
