## Summary

Owner sebelumnya tidak bisa mengembalikan gaya "bubble" navigasi mobile lama (sebelum commit `db05f17`, yang memindahkan menu ke header kanan-atas) — sekarang tersedia sebagai switch di Dashboard Settings, tanpa menghapus perilaku default yang berjalan sekarang. Selain itu, ditemukan dan diperbaiki: (1) tombol Table of Contents mobile di halaman detail berita bertabrakan visual dengan tombol AI chat karena keduanya `fixed` di pojok kanan-bawah, (2) iframe video Google Drive inline kehilangan permission `fullscreen` di atribut `allow` (berbeda dari versi modal fullscreen-nya) yang berpotensi menyebabkan video Drive gagal diputar/fullscreen di mobile WebKit, dan (3) dua error TypeScript lama (`server/index.ts`, `server/lib/system-health.ts`) yang lolos dari `npm run check` sebelumnya.

## Highlights

- Setting baru "Menu Mobile: Bubble Mengambang" di Dashboard → Settings → Appearance
- Mobile TOC di halaman berita dipindah ke pojok kiri-bawah agar tidak tabrakan dengan tombol AI chat (kanan-bawah)
- Iframe video Google Drive inline (non-modal) sekarang punya `allow="autoplay; encrypted-media; fullscreen"`, konsisten dengan versi fullscreen modal
- 2 error `npm run check` lama (lean() query typing, Map iteration) diperbaiki

## Features (detail)

### Feature — Mobile navbar style setting (top-right vs bubble)
- **Masalah / tujuan:** Owner ingin bisa memilih ulang gaya lama (bubble mengambang di tepi kanan, vertically centered — sesuai commit `f2b5c31`) tanpa kehilangan gaya default saat ini (menu header kanan-atas, sejak `db05f17`).
- **Perilaku baru:** Field `mobileNavBubbleEnabled` (boolean, default `false`) di Settings. Saat `true`, navbar publik menampilkan bubble bulat gradient yang mengambang di `fixed right-3 top-1/2 -translate-y-1/2`; saat `false`/default, perilaku identik dengan sebelumnya (tombol menu di header kanan-atas + panel `fixed right-3 top-[4.5rem]`). Logic render item navigasi (`allItems.map`, divider, login/user icon) diekstrak jadi satu `mobileNavItemsList` yang dipakai bersama oleh kedua gaya, tanpa duplikasi.
- **Siapa terdampak:** publik (tampilan navbar mobile), owner/admin (kontrol setting)
- **Permission:** `settings.animations` (reuse permission existing, tidak ada permission baru)
- **Tenant-aware:** Mengikuti pola `Settings` existing (belum per-tenant; sama seperti `eventsAutoScrollEnabled`)
- **Source:** `client/src/components/public/navbar.tsx`, `client/src/pages/dashboard/settings.tsx`, `shared/schema.ts`, `db/mongodb.ts`

## Fixed

- Bug: tombol TOC mobile (`fixed bottom-4 right-4 z-50`) menumpuk tombol AI chat (`fixed bottom-6 right-3 sm:right-6 z-40`) di halaman detail berita — root cause: kedua elemen `fixed` di pojok kanan-bawah dengan offset hampir sama, TOC punya z-index lebih tinggi sehingga menutupi tombol chat. Fix: TOC dipindah ke pojok kiri-bawah.
- Bug: iframe video Google Drive inline di artikel berita berpotensi gagal fullscreen/play di mobile — root cause: atribut `allow` hanya `"autoplay; encrypted-media"`, hilang `fullscreen` (berbeda dari iframe versi modal fullscreen yang sudah punya `fullscreen`). Fix: disamakan jadi `"autoplay; encrypted-media; fullscreen"`.
- Bug: `npm run check` error `TS2339` di `server/index.ts` (properti `excerpt`/`siteDescription`/`image`/`logoUrl`/`siteName`/`siteTagline` tidak dikenal pada hasil `.lean()` dari `Model<any>`) — root cause: `const item`/`const settings` tanpa anotasi tipe membuat TS gagal infer lewat generic `any` Mongoose. Fix: anotasi eksplisit `: any` (pola yang sudah dipakai di blok lain pada file yang sama).
- Bug: `npm run check` error `TS2802` di `server/lib/system-health.ts` (iterasi `Map` butuh `--downlevelIteration` atau target ES2015+) — root cause: `tsconfig.json` tidak set `target` eksplisit (default lama). Fix: dua `for...of` atas `Map` diganti `.forEach()` (scoped ke pemanggilan itu saja, tidak mengubah `tsconfig.json` global).
