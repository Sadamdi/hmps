## Summary

Chrome DevTools audit menemukan 21+ elemen `[data-aos]` stuck `opacity: 0` di mobile — penyebab struktur organisasi, galeri, event, dan gambar berita detail “hilang”. AOS sempat dimatikan di mobile tanpa refresh untuk lazy sections. Patch ini aktifkan AOS kembali, safety CSS, refresh berkala, perbaiki navbar ke kanan-atas (sebelah theme), kembalikan galeri melayang tentang kami, dan samakan kartu berita (layout sama, ukuran lebih kecil di grid 2×2).

## Highlights

- Fix root cause: section public tidak invisible lagi setelah loading/back/reload
- Menu mobile: trigger di header kanan (☰ + theme), panel turun ke bawah
- Tentang kami: foto melayang kembali di mobile; clamp teks lebih wajar
- Berita: kartu unified (excerpt + CTA), bukan layout terpisah mobile/desktop
