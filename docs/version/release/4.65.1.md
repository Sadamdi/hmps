## Summary

Di 4.65.0, blok beranda "Karya Mahasiswa TI" untuk konfigurasi lama disisipkan sebelum footer (setelah galeri, YouTube, Instagram), sedangkan item navbar "Karya TI" sudah berada setelah Toko. Akibatnya urutan beranda tidak sejalan dengan navbar, dan di Settings → Beranda item navbar "Karya TI" tampil di paling bawah daftar. Kini satu helper `withKaryaDefault` menaruh `karya` tepat setelah `toko` (sebelum grup Media: Event, Berita, Galeri, YouTube, Instagram) di beranda publik, navbar, dan Settings. Urutan yang sudah disimpan admin tidak diubah dan tetap bisa digeser.

## Highlights

- Beranda: Karya TI tampil setelah Toko, sebelum section-section Media
- Settings → Beranda: blok dan item navbar Karya TI muncul di posisi yang sama dengan situs publik
- Urutan tersimpan admin tetap dihormati

## Features (detail)

### Change A — Posisi default `karya`
- **Masalah / tujuan:** urutan default beranda berbeda dari navbar.
- **Perilaku baru:** `withKaryaDefault(items, make)` menyisipkan `karya` setelah `toko`; tanpa `toko` → sebelum `footer`; tanpa keduanya → di akhir. Tidak melakukan apa pun bila `karya` sudah ada.
- **Siapa terdampak:** public, admin Settings Beranda
- **Permission:** —
- **Tenant-aware:** No (tenant tidak memiliki `karya`)
- **Source:** `shared/schema.ts`, `client/src/pages/index.tsx`, `client/src/pages/dashboard/settings.tsx`

## User-facing impact

- `/` urutan section; `/dashboard/settings` tab Beranda
- Smoke: beranda menampilkan Karya TI setelah Encoder Store; Settings Beranda menampilkan Karya TI setelah Toko pada kedua daftar

## Added
