## Summary

Laporan owner (screenshot HP): halaman detail karya (KonseselingKampus, Deep Notes) dan profil mahasiswa kadang melebar keluar layar, dan tabel README terpotong. Penyebab: grid halaman tanpa `grid-template-columns` sehingga kolom otomatis mengikuti konten terlebar (gambar pratinjau repo, tabel README). Owner juga meminta kategori lebih banyak dan kategori buatan sendiri.

## Added

- 10 kategori bawaan baru (total 19 termasuk Lainnya).
- Kategori buatan mahasiswa: kolom "+ Kategori" di editor; disimpan huruf kecil, label tampil Title Case; filter publik & editor menampilkan kategori buatan yang sudah dipakai.
- `GET /api/karya/public/categories`.

## Fixed

- Grid `/karya/:slug`, `/karya/mahasiswa/:username`, editor, masuk, dan tab Profil memakai `minmax(0,1fr)`.
- `RichHtmlWithEmbeds`: tabel `overflow-x-auto`, gambar/iframe/video `max-width:100%`, kata panjang dipatahkan.
