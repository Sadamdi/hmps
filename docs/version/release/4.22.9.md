# Release v4.22.9 — Enco Agent: Stricter Retry + Inline Reminder

## Ringkasan

Patch lanjutan v4.22.8. Setelah v4.22.8 di-push ke server, live test masih menunjukkan AI melakukan 4× `search_berita` alih-alih `create_berita_draft` saat user meminta draft berita dengan info lengkap.

Tambahan v4.22.9:
1. **Inline reminder di history** — pengingat tipis di awal history (konteks sistem, bukan pesan user) bahwa kalau user sudah sediakan info lengkap, LANGSUNG panggil tool tulis.
2. **Stall pattern lebih ketat** — tambahkan `'langsung ya'`, `'berikutnya'`, `'akan saya kerjakan'`, `'mari saya'`, `'saya tidak yakin'`, `'biasanya'`, `'mohon maaf'`, `'untuk saat ini'`, `'kurang tepat'`.
3. **Long-without-tool threshold** turun dari 320 ke 200 karakter.
4. **Generic pattern lebih ketat** untuk menangkap excuse/penundaan halus dari model.

## Yang Berubah

### Server

- `server/services/chat-service.ts`
  - Tambah inline reminder di awal history (setelah system prompt) tentang perilaku agent.
  - Perluas `announcePatterns` & `genericPatterns` di `shouldForceWriteToolRetry` & `shouldHardForceWriteTool`.
  - Turunkan threshold `longWithoutTool` 320 → 200.

## Catatan

- Ini model agresif: trigger retry akan lebih sering. Trade-off: kalau model sebenarnya sedang valid, bisa kepaksa retry. Namun dengan v4.22.8 sudah lebih baik, v4.22.9 hanya rapikan pola deteksi.
- Inline reminder di history akan membuat context window lebih panjang ~200 token. Tetap jauh di bawah budget model.
