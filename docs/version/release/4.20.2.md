## Summary

Provider OpenAI-compatible (`server/services/openai-service.ts`) sebelumnya hanya memakai satu `OPENAI_API_KEY` dan memutar model dari `OPENAI_MODELS`. Patch ini menambahkan multi-key slots (`OPENAI_API_KEY_1…N`) dengan cooldown setelah quota/auth error, lalu mencoba tiap model × tiap key yang tersedia. Cache `openai-working.json` sekarang menyimpan model **dan** key slot yang terakhir sukses. Nilai secret hanya di `.env` lokal/server — tidak di-commit.

## Highlights

- Rotate API key otomatis saat limit / auth / quota
- Rotate model otomatis menurut urutan `OPENAI_MODELS`
- README env contoh diperbarui untuk slot numbered

## Features (detail)

### Change — OpenAI key + model auto-rotate
- **Masalah / tujuan:** Satu proxy key mudah kena limit; daftar model lama perlu diganti dan diuji berurutan.
- **Perilaku baru:** Outer loop model (urutan env + prefer cache), inner loop key slots; cooldown per slot setelah error yang mirip quota/auth; legacy `OPENAI_API_KEY` hanya dipakai jika tidak ada `OPENAI_API_KEY_n`.
- **Siapa terdampak:** AI chat, error-monitor AI, text completion yang memakai `runOpenAiChat`
- **Permission:** tidak berubah
- **Tenant-aware:** No
- **Source:** `server/services/openai-service.ts`

## User-facing impact

- Halaman/route: chat AI / fitur yang pakai OpenAI fallback
- UX: lebih resilient saat satu key/model gagal (fallback diam ke kombinasi berikutnya)
- Smoke: kirim 1 pesan chat; cek log `[AI][OpenAI] OK model=… keySlot=…`
