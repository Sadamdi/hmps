## Summary

Owner kini bisa melihat proses apa saja yang memakan resource server langsung dari dashboard, seperti Task Manager Windows. Widget lebar penuh tepat di bawah kartu System Health: tabel di PC, kartu ringkas di HP.

## Highlights

- Kolom: Service/Proses (nama app PM2 dikenali), PID, User, CPU %, RAM (MB + % dari total), Disk baca/tulis (B/s) dan porsi disk %, Koneksi (socket), Thread, Lama berjalan.
- Ringkasan total: CPU, RAM, disk R/W, jaringan ↓/↑.
- Urut per kolom (klik header atau dropdown), tombol Terbanyak/Tersedikit, cari proses, 10/20/50/100 baris (default 20), jeda; auto-refresh 3 detik.
- Warna "heat" per sel seperti Task Manager.

## Features (detail)

### Change A — Sampler /proc
- **Source:** `server/lib/process-monitor.ts`
- **Behavior:** baca `/proc/<pid>/{stat,status,io,cmdline,fd}`, `/proc/net/dev`; CPU dan disk rate dari selisih dua sampel. Nama PM2 dari `~/.pm2/pids`. Isi env proses tidak dibaca. Non-Linux → `supported:false`.

### Change B — Endpoint
- **Source:** `server/routes.ts` — `GET /api/dashboard/processes?sort&dir&limit`
- **Behavior:** permission `overview.process_monitor`; request tenant → 404 (data server bukan milik komunitas); `Cache-Control: no-store`.

### Change C — Permission
- **Source:** `server/mongo-storage.ts` — permission baru kategori overview; role Owner otomatis dapat (sinkron semua permission); tidak masuk seed Admin maupun backfill overview role lain. Owner bisa memberikannya ke role lain lewat editor role bila perlu.

### Change D — Widget
- **Source:** `client/src/pages/dashboard/widgets/process-monitor.tsx`, `client/src/pages/dashboard/index.tsx`

## Notes / Known gaps

- Linux tidak mencatat trafik jaringan per proses tanpa eBPF/nethogs → per proses ditampilkan jumlah socket; laju jaringan hanya total.
- Disk % = porsi proses dari total I/O saat itu, bukan "active time" disk seperti Windows.
- Sampel CPU dibagi antar viewer (satu state di memori); dengan beberapa viewer sekaligus intervalnya lebih pendek tetapi tetap akurat.
