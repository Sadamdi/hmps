## Summary

1. **Link YouTube live "diblokir"**: URL `youtube.com/live/<id>` tidak dikenali sebagai video, sehingga di-iframe langsung (halaman YouTube menolak framing). Kini `/live/`, `/v/`, `/embed/`, `/shorts/`, `/watch` pada `youtube.com`, `m.youtube.com`, `music.youtube.com`, `youtu.be`, `youtube-nocookie.com` diubah ke embed `youtube-nocookie.com`; playlist (`/playlist?list=`) memakai `embed/videoseries`; kanal/halaman YouTube lain tampil sebagai tautan (bukan iframe kosong).
2. **Allowlist bawaan** (`shared/embed-default-hosts.ts`) diperluas dan menjadi satu-satunya sumber untuk CSP `frame-src` dan klien: YouTube (semua varian), Google (Drive, Docs, Forms, Kalender, Looker Studio, Maps), Vimeo, Spotify, Canva, Instagram, TikTok, Photopea. Host yang halamannya menolak framing (Spotify, Instagram, TikTok, Canva, Vimeo, Kalender, Forms, Looker) hanya di-iframe bila URL berupa embed/player; selain itu tampil sebagai tautan.
3. **Sorotan berita**: kata "Utama" dihapus (juga "Detail Event Utama" → "Detail Event"); item kolom kanan menampilkan jumlah pembaca; berita pertama menampilkan tag (sampai 4) di layar sm ke atas.
