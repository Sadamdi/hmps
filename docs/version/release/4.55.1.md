## Summary

Tindak lanjut laporan: banyak gambar tampak bertumpuk/terpotong di Encoder Store versi mobile, dan pertanyaan apakah pilihan varian (ukuran/desain) sudah masuk ke semua jalur pesanan.

## Fixed

- `client/src/pages/toko/[slug].tsx`: grid dua kolom tanpa `grid-cols-1` membuat kolom tunggal di mobile ikut selebar konten strip thumbnail (`min-w-max`, 700px). Foto utama jadi 698px di layar 375px sehingga terpotong dan tombol panah kanan keluar layar. Kini `grid-cols-1`, kolom `min-w-0`, strip `w-max` di dalam pembungkus `overflow-x-auto max-w-full`.
- `store-quick-view.tsx`: `grid-cols-1` ditambahkan agar perilaku sama.
- Pesanan bundling: helper baru `orderLineVariantText` (`shared/store-variants.ts`) mengembalikan label varian produk, atau isi paket bundling beserta varian tiap komponen. Dipakai pada teks WhatsApp checkout (baris `Isi:`), deskripsi notifikasi dashboard, `sheetOrderFrom`, ekspor Excel, `store-order-admin`, `store-preorder-panel`, dan riwayat pembeli (`/toko/orders`). Email dan halaman invoice sudah memuatnya sebelumnya.

## Verification

- `npm run check` lolos.
- Dicek di browser mode mobile (375px) pada data uji dengan 10 foto galeri: foto utama 342px, strip thumbnail scroll internal (876px dalam 343px), tidak ada elemen di luar viewport.
- Situs publik diperiksa read-only untuk mereproduksi masalah pada produk keychain dengan gambar per varian.
- Unit check `orderLineVariantText`: varian produk, isi bundling, dan kosong.

## Notes / Known gaps

- Alur E2E checkout bundling dengan varian belum diulang penuh; perubahan hanya pada penyusunan teks.
- Halaman keranjang, akun, dan invoice di mobile belum diprobe ulang di browser pada rilis ini.
