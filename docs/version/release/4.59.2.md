## Summary

Bagian dosen yang diset manual (override) tidak pernah menerima dosen baru dari situs resmi. Kini sinkronisasi menambahkan dosen yang belum ada tanpa mengubah entri yang sudah diedit. Tab pengumuman kategori Beasiswa kosong setelah rilis 4.59.0 karena interval harian belum jatuh tempo; cron kini mengambil ulang bila sumber beasiswa belum ada.

## Changed

- `server/services/prodi-sync.ts`: `mergeMissingLecturers` (hanya menambah, idempoten; kunci nama tiga kata pertama) dipakai saat sinkronisasi dosen.
- `server/index.ts`: cron student hub memaksa refresh (maks sekali per jam) bila pengumuman belum memuat sumber Kemahasiswaan/Kemdiktisaintek/Kemenag.

## Verification

- `npm run check` lolos. Uji terhadap data produksi (baca-saja): 37 menjadi 38, tambahan Dr. Ir. Supriyono; dijalankan dua kali tidak menambah lagi.
- Operasional produksi: dosen tersebut ditambahkan (cadangan di `.local-backups/`); `rotate-default-passwords` (9 akun) dan `cleanup-xss-comments` (384 komentar) diterapkan.
