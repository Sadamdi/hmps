## Summary

Setelah v4.26.0 feed Instagram jalan, tetapi halaman "Lihat semua" masih di `/media/*` (tidak konsisten dengan Berita/Event/Galeri), sync membuang item di atas batas simpan, urutan murni tanggal (post pinned malah di bawah), header profil IG masih ikon generik, navbar YouTube/Instagram tidak punya "Lihat semua" dan URL kanal hardcode, serta scroll dari navbar ke section beranda sering berhenti di tengah. Rilis ini memindahkan route ke `/youtube` & `/instagram`, menyimpan **seluruh** isi akun (backfill pertama + merge harian), menampilkan urutan asli IG (pinned dulu) dengan badge Pinned/Baru, header profil asli (avatar, bio, statistik), navbar mengikuti config dashboard, cron pindah ke 00:00 WIB, dan scroll beranda yang mengoreksi diri saat layout bergeser. Risiko: backfill IG ±1.200 post memakai API privat (akun dummy) dan menambah ±30 MB thumbnail WebP di `uploads/`.

## Highlights

- Route `/youtube` & `/instagram` (main + `/:slug/…`), `/media/*` → redirect.
- Arsip penuh: IG ±1.208 post, YouTube 119 item (uji lokal); harian hanya cek N terbaru lalu merge.
- Urutan asli IG: pinned (urutan pin) → terbaru; badge **Pinned** & **Baru** (≤7 hari).
- Header profil IG asli: avatar, nama, bio, post/pengikut/mengikuti, verified.
- Navbar YouTube/Instagram: Di beranda / Lihat semua / Buka di … (URL dari dashboard), ikut grup merge "Media".
- Scroll navbar → section beranda tidak lagi berhenti di posisi basi; cron 00:00 WIB.

## Features (detail)

### Feature / Change A — Route top-level
- **Masalah / tujuan:** `/media/*` tidak konsisten; tidak ada halaman `/media`.
- **Perilaku baru:** `/youtube`, `/instagram` (dan versi tenant). `/media/youtube|instagram` → `<Redirect replace>` dengan query. Slug `youtube`/`instagram` dicadangkan di `RESERVED_FIRST_SEGMENTS`; ditambahkan ke sitemap dan `staticPrefixes`.
- **Siapa terdampak:** public, tenant.
- **Permission:** —
- **Tenant-aware:** Yes
- **Source:** `client/src/App.tsx`, `client/src/pages/community/index.tsx`, `client/src/pages/media/legacy-redirect.tsx`, `shared/tenant-paths.ts`, `server/index.ts`

### Feature / Change B — Arsip penuh & backfill
- **Masalah / tujuan:** item di atas `fetchLimits` dibuang; owner ingin semua post/reel/video tersimpan.
- **Perilaku baru:** backfill otomatis bila `cache.backfilledAt[platform]` kosong atau tombol "Ambil ulang semua isi akun" (`POST /sync {full:true}` → 202, background, 409 bila masih jalan). IG: paginasi `feed/user` sampai habis; YT: continuation tab videos/shorts/streams (maks 80 halaman). Harian: cek N terbaru (`fetchLimits`, label "Cek …") lalu merge dengan arsip. Backfill penuh membuang item yang sudah dihapus di sumber (kecuali link manual IG). Thumbnail IG baru disimpan WebP 480 px.
- **Siapa terdampak:** public, admin.
- **Permission:** `social_feed.sync` (tidak berubah).
- **Tenant-aware:** Yes (per storage).
- **Source:** `server/services/social-feed.ts`, `server/routes/social-feed.ts`, `ops/instagram/ig_feed.py`, `client/src/components/dashboard/social-feed-settings-panel.tsx`

### Feature / Change C — Urutan pinned, badge, profil
- **Masalah / tujuan:** urutan harus sama dengan profil IG; butuh penanda konten baru.
- **Perilaku baru:** `pinned`/`pinnedRank` dari `timeline_pinned_user_ids`; `sortSocialItems` = live → pinned → terbaru. `isNewSocialItem` (7 hari) → badge Baru (IG & YT); badge Pinned di tile IG. Grid IG seragam 3:4. `cache.profiles.instagram` (avatar lokal `_avatar.webp`) dipakai `InstagramProfileHeader` di beranda & halaman arsip.
- **Siapa terdampak:** public.
- **Permission:** —
- **Tenant-aware:** Yes
- **Source:** `shared/social-feed.ts`, `client/src/components/public/social/social-cards.tsx`, `client/src/components/public/social-feed-sections.tsx`, `client/src/components/public/social/social-archive-page.tsx`

### Feature / Change D — Navbar & scroll
- **Masalah / tujuan:** navbar YT/IG hardcode & tanpa "Lihat semua"; scroll dari navbar ke section berhenti di tengah karena section lazy menambah tinggi halaman saat animasi (terukur 9.704 → 11.809 px).
- **Perilaku baru:** children YT/IG = Di beranda / Lihat semua / Buka di … (URL dari `socialFeed.config`, item disembunyikan bila platform nonaktif); grup `homeConfig.navbarGroups` tetap dari dashboard. Helper `client/src/lib/scroll-to-section.ts` mengukur ulang target setelah scroll berhenti (maks 4 koreksi, 2,5 dtk) dan berhenti saat pengguna scroll sendiri. `youtube`/`instagram` masuk `validSections` & deteksi section aktif.
- **Siapa terdampak:** public (desktop & mobile), tenant.
- **Permission:** —
- **Tenant-aware:** Yes
- **Source:** `client/src/components/public/navbar.tsx`, `client/src/pages/index.tsx`, `client/src/lib/scroll-to-section.ts`

### Feature / Change E — Jadwal 00:00 WIB
- **Perilaku baru:** cron `0 0 * * *` Asia/Jakarta; `nextScheduledSync` 17:00 UTC; teks dashboard.
- **Source:** `server/index.ts`, `server/routes/social-feed.ts`
