## Summary

Kontak toko sebelumnya hanya satu nomor WhatsApp + nama (global) dan satu override per produk. Kini admin WA berupa daftar (nama + nomor + saklar on/off) yang bisa ditambah, diedit, dan dihapus di pengaturan toko (global) dan di form produk (override). Nama default "Admin 1", "Admin 2", dst. Saat membeli: 0 admin aktif → "Mohon maaf, toko sedang tutup." dan tombol beli nonaktif; 1 aktif → langsung ke admin itu; >1 aktif → pembeli memilih admin. Pesan WhatsApp diawali "Permisi Kak {nama admin}, ". Nomor admin tidak dikirim ke endpoint publik.

## Highlights

- Editor daftar admin WA (tambah/edit/hapus/on-off) — global & per produk.
- Pemilih admin di dialog "Beli via WhatsApp" dan keranjang.
- Toko tutup otomatis bila semua admin off.
- Sapaan nama admin di awal pesan.
- Data lama (`whatsappPhone`, `whatsappPhoneOverride`) otomatis menjadi Admin 1.

## Features (detail)

### Change A — Model & resolusi
- **Perilaku baru:** `StoreSettings.whatsappAdmins`, `StoreProduct.whatsappAdmins` (override; kosong = global). Helper bersama `shared/store-wa.ts`.
- **Tenant-aware:** Yes (skema tenant memakai skema yang sama).
- **Source:** `shared/store-wa.ts`, `db/mongodb.ts`

### Change B — API
- **Perilaku baru:** `GET /api/store/public/settings` & `GET /api/store/public/products/:slug` menambah `waAdmins` (id + nama aktif) dan `storeOpen`; nomor tidak diekspos. `POST /checkout`, `/direct-checkout`, `/buy-link` menerima `adminId`; membalas 409 `STORE_CLOSED` atau 409 `CHOOSE_ADMIN` (+ `admins`). Pilihan admin diproses sebelum stok dikurangi.
- **Source:** `server/routes/store.ts`

### Change C — UI
- **Source:** `client/src/components/dashboard/store-wa-admins-editor.tsx`, `client/src/components/toko/store-wa-admin-picker.tsx`, `client/src/pages/dashboard/toko.tsx`, `client/src/pages/toko/[slug].tsx`, `client/src/pages/toko/cart.tsx`
