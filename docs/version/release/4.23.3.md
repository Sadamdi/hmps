## Summary

Patch lanjutan v4.23.2. Masalah:

- `/api/upload` (dipakai oleh banyak halaman dashboard: profil himpunan, logo divisi, banner, organization, dll) memanggil `uploadHandler()` di `server/upload.ts`.
- Sebelum patch ini, `uploadHandler()` hanya menyimpan file dengan ekstensi asli (`.heic`, `.avif`, dll). Tidak ada proses image processing.
- Untuk HEIC: file `.heic` mentah tersimpan di disk. Image preview di list langsung blank di Firefox/Chrome tanpa codec HEVC.
- Patch: `uploadHandler()` sekarang mendeteksi gambar via `isProcessableImage()` dan memanggil `processImage()` (sharp + `heic-convert` fallback). Output selalu `.webp`. Non-gambar (video/dokumen) tetap pakai ekstensi asli.

Kontrak API tidak berubah — response `{ url }` masih path yang sama, hanya content/extension-nya konsisten WebP untuk gambar.

## Highlights

- Upload HEIC/HEIF dari `/api/upload` (organization logo, banner, dll) sekarang menghasilkan file `.webp` yang render universal.
- Konsisten dengan handler spesifik `uploadBeritaImage()`, `uploadStoreProductImage()`, dll yang sudah proses ke WebP.
- Tidak ada perubahan kontrak API.
- Lebih cepat: ukuran file `.webp` lebih kecil dari `.heic` mentah.

## Features (detail)

### Feature A — `uploadHandler()` proses gambar ke WebP

- **Masalah / tujuan:** Patch v4.23.2 memperbaiki pipeline `processImage()` tapi handler upload generic (`uploadHandler()` di `server/upload.ts`) tidak memanggil pipeline itu. Untuk endpoint yang pakai handler ini (organization logo, banner, dll), upload HEIC sukses tapi file tersimpan `.heic` mentah yang tidak render universal.
- **Pendilaku baru:**
  - `uploadHandler()` sekarang mendeteksi gambar via `isProcessableImage(file.mimetype, file.originalname)`.
  - Kalau gambar: panggil `processImage()` → output `.webp` (quality 80, max 1920×1080). Ekstensi file output jadi `.webp`. Mimetype tersimpan = `image/webp`.
  - Kalau non-gambar (video, PDF, dll): tetap simpan dengan ekstensi asli.
- **Siapa terdampak:** semua endpoint yang pakai `uploadHandler()` — `/api/upload` (organization/banner/filosofi/dll), handler lain yang delegate ke function ini.
- **Permission:** sama seperti upload existing.
- **Tenant-aware:** Yes — jalur tenant pakai helper yang sama.
- **Source:** `server/upload.ts::uploadHandler()`.
