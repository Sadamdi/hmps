## Summary

Menampilkan bukti sosial produk dengan hitungan yang tidak bisa digelembungkan dengan mudah.

## Added

- Koleksi `StoreFavorite` (unik `kind+targetId+ownerKey`), field `favoriteCount`/`viewCount` pada produk dan bundling (DB utama + tenant).
- `store-stats.ts`, `StoreStatsLine`; `use-store-favorites` memanggil server saat toggle.

## Verification

- `npm run check` lolos; E2E statistik **16/16** (idempoten, dedupe, bot, bundling, muncul di API); seed diuji di DB `hmps_e2e_store` (5 produk + 2 bundling, ulang = 0).

## Notes / Known gaps

- Favorit lama yang hanya ada di localStorage tidak ikut terhitung sampai pemiliknya menekan ikon lagi.
- Penghitung `viewCount` dedupe memakai memori proses (reset saat restart).
- Seed produksi menunggu persetujuan pemilik: `node --env-file=.env ops/seed-store-stats.cjs --dry` untuk pratinjau.
