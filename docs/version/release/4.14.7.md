## Summary

Alur production tetap: media baru di-push, code baru di-pull; rebuild (stop → `npm install --include=dev` → build → restart) hanya jika runtime berubah. Ditambah cadangan `dist` agar build gagal tidak mengosongkan frontend (404). Atas permintaan owner, seluruh author/committer historis di-map ke Sadamdi atau addid-cloud, trailer `Co-authored-by: Cursor` dihapus, lalu force-push `main`.

## Highlights

- Backup `dist` + restore on failed build/health
- Auto: push img → pull code → rebuild hanya runtime
- Contributor GitHub: hanya @Sadamdi dan @addid-cloud setelah rewrite

## Features (detail)

- **Masalah / tujuan:** `vite build` gagal meninggalkan `dist/public` kosong → 404
- **Perilaku baru:** cadangkan `dist/index.js`, `banner-render-service.js`, `dist/public` sebelum build; restore jika gagal
- **Siapa terdampak:** public uptime
- **Source:** `ops/deploy-server.sh`
