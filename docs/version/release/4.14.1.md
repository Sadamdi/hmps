## Summary

User menemukan berita WrecK-IT masih memakai meta Prestasi/Lingkup/Tim, padahal publish Medinfo terbaru memakai 🗓 Tanggal / 🕖 Waktu / 📍 Tempat. Konten production di-rewrite ke template itu. Existing tags di editor sebelumnya dipotong 20 chip (sisa hanya lewat search); sekarang semua tag ditampilkan di area scroll. AI style profile diselaraskan agar selalu memakai Tanggal/Waktu/Tempat.
