## Summary

Fitur ulasan dan rating produk untuk Encoder Store dan toko komunitas.

## Added

- Model `StoreReview` dan `StoreReviewReport` (DB utama + tenant), indeks unik `orderNo + productId`.
- Endpoint publik/pembeli/admin (lihat `docs/features/06-store-toko/13-reviews.md` dan `docs/api/endpoints.md`).
- Upload media ulasan: foto diproses ulang ke WebP, video divalidasi tipe + magic bytes, disimpan lokal `uploads/store/reviews/` dan masuk antrean ClamAV; media terinfeksi disaring dari respons.
- UI: `store-reviews.tsx` (ringkasan, daftar scroll, form, laporan, dialog per pesanan), `store-reviews-panel.tsx` (moderasi), badge rating di judul produk.
- Permission `toko.reviews.manage`.

## Security

- Kepemilikan lewat `buyerId` sesi server; ulasan orang lain 404; pesanan harus `completed`; produk harus ada di pesanan; komentar dibersihkan dari HTML; email/HP/nomor pesanan tidak pernah tampil publik; limiter tulis dan laporan.

## Verification

- `npm run check` lolos.
- E2E API ulasan **47/47** (syarat, validasi media, tulis/edit/hapus, kepemilikan, laporan, moderasi admin, pembersihan file).
- Browser: PC dan HP 375px tanpa overflow, scroll memuat lebih banyak (5→8), form tulis ulasan dikirim lewat UI, panel moderasi tampil.

## Notes / Known gaps

- Durasi video tidak divalidasi (tidak ada ffprobe); dibatasi 30 MB.
- Upload foto/video lewat dialog file belum diuji di browser (API-nya diuji penuh).
- Produk bundle tidak bisa diulas; ulasan per baris produk.
- ClamAV tidak aktif di lokal; pemindaian nyata terjadi di server produksi.
