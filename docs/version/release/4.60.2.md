## Summary

Beranda tidak menampilkan post Instagram terbaru (30 Sep, 3 Okt, 12–14 Okt 2026 ada di akun, cache terbaru 21 Sep) walau dashboard "Berhasil". Backfill penuh belum pernah selesai sehingga tiap run berstatus "lanjutan dari cursor" dan hanya mengambil halaman lama; halaman terbaru tidak pernah diambil lagi.

## Findings

- Dari server (IP datacenter) tanpa login: profil dan `web_profile_info` tidak memberi daftar post (401/shell kosong). Per-post dengan User-Agent crawler preview (`facebookexternalhit`) memberi og:title/description/image (caption dan tanggal) tanpa login. Penemuan post baru tetap butuh sesi login; konten per ID/link bisa tanpa login (sudah ada jalur embed untuk link manual).
- Indikator "N baru" menghitung semua item baru di cache termasuk arsip lama (36 item Sep 2025 dst. pada 21 Okt).

## Changed

- `server/services/social-feed.ts`: saat melanjutkan backfill, tiap run juga mengambil halaman terbaru lalu menggabungkannya (tanpa duplikat); bila lanjutan gagal, cursor lama dipertahankan. "Baru" hanya post yang lebih baru dari item terbaru sebelumnya.

## Verification

- `npm run check` lolos. Pembuktian di produksi: setelah deploy, klik "Fetch sekarang" dan cek post 12–14 Okt masuk.

## Notes / Known gaps

- Dua spawn Python per run saat backfill berjalan (head + lanjutan); RAM dijaga oleh penjaga 200 MB (4.60.0).
