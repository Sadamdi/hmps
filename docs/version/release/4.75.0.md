## Summary

Audit kehalusan scroll (durasi tiap frame + long task) di semua halaman publik dengan klon data produksi. Penyebab tersendat: header berubah tinggi dengan `transition-all` dan mematikan blur saat mulai scroll (reflow seluruh halaman tiap frame selama 300 ms), AOS memeriksa scroll tiap 99 ms dengan MutationObserver yang menghitung ulang posisi semua elemen, React menimpa kelas `aos-animate` saat render ulang sehingga elemen bisa tertinggal tak terlihat, dan peta Google di footer dimuat tepat saat masuk layar.

## Changes

- `client/src/lib/reveal.ts` (baru): animasi masuk berbasis IntersectionObserver, hanya opacity + transform; membaca atribut `data-aos` lama; status di atribut `data-aos-in` (aman dari render ulang React); urutan bertahap untuk elemen yang masuk bersamaan; elemen yang sudah terlewat tampil langsung; jaring pengaman saat scroll berhenti; `prefers-reduced-motion` dihormati.
- `client/src/lib/page-transitions.ts` (baru): transisi antarhalaman dengan View Transitions API (snapshot GPU); header tetap diam; fallback instan di browser yang belum mendukung.
- `client/src/components/ui/card.tsx`: semua `Card` mendapat animasi masuk bawaan (bisa dimatikan `data-aos=""`).
- `client/src/components/public/navbar.tsx`: tinggi header tetap, blur selalu aktif, hanya bayangan/warna yang berganti.
- `client/src/components/public/footer.tsx`: `DeferredMap` — peta dimuat 900 px sebelum terlihat saat browser senggang lalu memudar masuk.
- `client/src/components/public/events-tree.tsx`: hapus animasi ganda (sudah punya animasi masuk sendiri).
- `client/src/App.tsx`, `pages/index.tsx`, `library.tsx`, `use-aos-refresh-on-mount.ts`: pakai `@/lib/reveal`; CSS AOS dihapus.
- `client/src/index.css`: gaya reveal dan view transition.
