## Summary

Permintaan admin toko: (1) memilih varian seperti desain gantungan kunci atau ukuran kaos — dicek di riwayat git, fitur ini belum pernah ada, jadi dibuat baru; (2) rekap pesanan ke spreadsheet. Rilis ini menambah varian produk ala marketplace (foto, harga, stok, judul & deskripsi per varian; memilih varian mengganti foto/harga/stok dan klik foto varian memilih varian), status pesanan **Dikirim/Diambil**, metode & tanggal bayar serta catatan admin, tombol **Export Excel** (filter tanggal & status) dengan format template rekap (dashboard ringkasan, pesanan, item, stok), serta notifikasi in-app/web push ke admin toko untuk pesanan & chat baru dan pengingat harian pesanan "Menunggu" > 24 jam.

## Highlights

- Varian produk: stok per varian, harga opsional, foto opsional, judul/deskripsi pengganti opsional, aktif/nonaktif, urutan.
- Keranjang, checkout, WA, invoice, riwayat, dashboard, dan export menampilkan varian; batal/hapus mengembalikan stok varian.
- Status baru `shipped` (Dikirim/Diambil); `paymentMethod`, `paidAt` (otomatis saat Dibayar), `adminNote` (tidak terlihat pembeli).
- `GET /api/store/admin/orders/export.xlsx?from&to&status` — Excel siap pakai (rumus, dropdown, warna status, data bar).
- Notifikasi `store_order` / `store_chat` ke user ber-permission `toko.manage`; cron 09:00 WIB pengingat pesanan menunggu.

## Features (detail)

### Change A — Varian produk
- **Perilaku baru:** `StoreProduct.variantGroupName`, `variants[]` (`shared/store-variants.ts`: `normalizeVariantsInput`, `findVariant`, `productAsVariant`). Keranjang menyimpan `variantId` (line key `p:<id>:v:<vid>`); checkout mewajibkan varian aktif (`VARIANT_REQUIRED`), harga & stok memakai varian; `takeStock/giveStock` untuk produk/varian; `StoreOrder.items[].variantId/variantLabel`, `stockDecrements[].variantId`.
- **Tenant-aware:** Yes
- **Source:** `shared/store-variants.ts`, `server/routes/store.ts`, `server/routes/store-logic.ts`, `db/mongodb.ts`, `client/src/components/dashboard/store-variants-editor.tsx`, `client/src/pages/toko/[slug].tsx`, `client/src/pages/toko/cart.tsx`

### Change B — Pesanan & pembayaran
- **Perilaku baru:** `PATCH /api/store/admin/orders/:orderNo` menerima `status` (opsional), `paymentMethod` (`transfer|qris|cash|ewallet`), `paidAt`, `adminNote`. Label status terpusat di `shared/store-order-status.ts` (Selesai menggantikan "Diterima").
- **Source:** `server/routes/store.ts`, `client/src/components/dashboard/store-order-admin.tsx`

### Change C — Export Excel
- **Perilaku baru:** `buildStoreRecapWorkbook` (exceljs) — sheet Ringkasan (kartu KPI, per status, per admin, produk terlaris), Pesanan, Item, Stok, Panduan; kolom turunan berupa rumus.
- **Permission:** `toko.manage`
- **Source:** `server/services/store-order-export.ts`

### Change D — Notifikasi admin toko
- **Perilaku baru:** `notifyStoreAdmins` (cache daftar admin 5 menit); chat hanya memicu notifikasi saat admin belum punya pesan belum-dibaca; `remindPendingStoreOrders` via cron `0 9 * * *` WIB (main + komunitas). Dashboard membuka tab dari `?tab=orders|chat`.
- **Source:** `server/routes/store.ts`, `server/index.ts`, `server/services/notification-orchestrator.ts`, `db/mongodb.ts`
