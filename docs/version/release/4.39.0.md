## Summary

Daftar lampiran di editor Berita dan Event sebelumnya hanya bisa dihapus; salah ketik nama atau URL berarti hapus lalu tambah ulang. Sekarang setiap lampiran bisa diedit.

## Added

- Komponen `AttachmentList` (dipakai Berita dan Event): tombol **Edit** per lampiran (nama; URL untuk lampiran link/Google Drive), validasi http/https, folder Drive ditolak. Lampiran file hasil upload hanya bisa diganti namanya (ganti file = hapus lalu unggah ulang).

## Fixed

- Berita disalin ke event (atau sebaliknya) memakai file lampiran yang sama. Menghapus lampiran di salah satu sisi dulu ikut menghapus file dari disk sehingga sisi lain rusak. Sekarang file hanya dihapus bila tidak dirujuk berita/event lain (`isAttachmentUrlUsedElsewhere`).

## Verification

- `npm run check` lolos; tes API baru 12/12 (buat berita dengan file + link, rename nama/URL, salin ke event, hapus dari berita → file tetap ada, edit lampiran event, URL `javascript:` ditolak); editor dicek di browser.

## Notes / Known gaps

- Menghapus seluruh berita/event masih menghapus folder file miliknya; lampiran/gambar yang dibagikan lewat salin bisa ikut hilang. Perlu rencana "salin fisik file saat menyalin" (belum dikerjakan).
- Mengubah URL lampiran tidak memperbarui tautan yang sudah disisipkan inline di isi berita.
- Galeri tidak punya "Lampiran"; link Drive-nya sudah berupa kolom yang bisa diubah.
