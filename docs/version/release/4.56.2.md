## Summary

Tindak lanjut permintaan agar sanitizer "jalan tanpa pengawasan dan aman". Alih-alih menambal regex, dipakai pustaka allowlist matang, dengan daftar izin yang divalidasi terhadap konten nyata dan korpus serangan nyata.

## Security

- `server/utils/cms-html.ts` (baru): `sanitizeCmsHtml`. Tag: formatting, tabel, gambar, tautan, figure, details, video/audio/source/track (src hanya http/https). Atribut global: `class`, `style` (properti dan nilai di-allowlist per regex), `dir`, `lang`, `title`, `align`, `data-*`, `aria-*`, `role`. Skema URL: http, https, mailto, tel; `data:` hanya untuk gambar raster (bukan svg). `target=_blank` otomatis `rel="noopener noreferrer"`. `id`/`name` dibuang (mencegah DOM clobbering). Teks tanpa tag dikembalikan apa adanya (tidak ter-escape ganda).
- `server/utils/input-sanitize.ts`: `CMS_HTML_KEYS` (dipakai bersama `post-body-sanitize`), `sanitizeObjectStrings` memakai `sanitizeCmsHtml` untuk kunci tersebut, `sanitizeRichHtml` memakai `sanitizeCmsHtml`.
- `client/src/lib/safe-html.ts` (baru): `safeHtml` (DOMPurify, profil HTML, tanpa form/svg/iframe, hook membuang `style` ber-`url()`/`expression`, `rel` otomatis). Diterapkan pada 11 titik `dangerouslySetInnerHTML` (berita, event, profil, kelembagaan, prodi, about, deskripsi produk, pratinjau editor, rich-html-with-embeds).
- Dependensi baru: `sanitize-html` 2.18.1, `dompurify` 3.4.17, `@types/sanitize-html` (dev). Tidak ada kerentanan baru pada `npm audit`.

## Verification

- `npm run check` lolos.
- Konten produksi nyata (baca-saja, 560 field HTML dari situs utama dan semua komunitas): 150 field sah dan 384 payload XSS. Server: 0 payload lolos, 0 kebocoran di konten sah; yang terbuang hanya pembungkus `html/head/body` (dokumen utuh hasil tempel), `id` pada `div`, atribut nonstandar `image-index`, dan variabel CSS `--smush-*`. Klien (DOMPurify + jsdom): 0 dari 384 lolos, 0 konten sah menyusut >50%.
- 23 serangan buatan (onerror, svg onload, `javascript:` dengan entity/tab, srcdoc, object data, form action, mXSS, CSS url/expression, svg data URL, protocol-relative, base/meta refresh, DOM clobbering): 0 lolos. 9 kasus konten sah (class/style/data-*, tautan, gambar, tabel, ol start, mailto/tel, teks biasa dengan `&` dan `<`, data URL PNG, figure): semua utuh.
- E2E server (login owner, `PUT /api/settings`): `aboutUs` dan `visionMission` disanitasi sebelum disimpan dan dibaca kembali (6/6).
- Browser (Chrome via Vite): `safeHtml` membuang `onclick`, `onerror`, `<script>`, `javascript:` dan mempertahankan `style`.

## Notes / Known gaps

- Dokumen yang memuat tag non-text tak tertutup (mis. `<svg>` tanpa `</svg>`) akan kehilangan sisa isinya (perilaku fail-safe `nonTextTags`).
- `iframe`/embed tidak diizinkan di HTML tersimpan (sudah demikian sebelumnya); embed dibuat klien dari tautan.
- 384 komentar berisi payload XSS dari 3 Juli 2026 (diposting 15:00–15:05 WIB lewat akun komunitas berpassword bawaan) masih ada di koleksi `comments` situs utama. Tidak berbahaya (dirender sebagai teks, filter ditambahkan 15 Juli 2026), tetapi tampil sebagai sampah di halaman event terkait. Pembersihan memerlukan akses tulis ke DB produksi dan belum dilakukan.
- Field HTML baru wajib ditambahkan ke `CMS_HTML_KEYS` dan dibungkus `safeHtml` (SOP 12).
