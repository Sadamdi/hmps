## Summary

Di 4.69.0, saat domain baru lolos analisis, cache `/api/settings` dibersihkan dan renderer memuat ulang daftar host. Daftar host itu langsung dianggap "diizinkan sejak halaman dimuat", sehingga iframe dirender padahal header CSP `frame-src` halaman masih versi lama: iframe kosong/diblokir. Renderer juga memanggil `invalidateQueries` di dalam render.

## Fixed

- Host dari Settings dikunci pada pemuatan pertama di tab (`hostsAtPageLoad`); host yang baru diizinkan sesudahnya menampilkan kartu "Embed siap ditampilkan — Muat ulang".
- `invalidateQueries` dihapus dari render.
- **Source:** `client/src/components/public/rich-html-with-embeds.tsx`
