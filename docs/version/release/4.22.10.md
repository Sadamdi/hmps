# Release v4.22.10 — Deteksi write intent dari news copy

## Ringkasan

Patch lanjutan v4.22.8/9. Sebelumnya `looksLikeUserWantsWriteAction` hanya cek pola kata kunci eksplisit seperti "buatkan", "tolong buat". Ketika user mengirim **berita lengkap** (konten panjang dengan format "Pra-STATIK 2026: ..." yang dimulai dari judul sampai paragraf berita lengkap), intentPatterns tidak match → retry tidak terpicu → AI masuk ke mode "public read" → manggil `search_berita` berkali-kali.

## Yang Berubah

### Server

- `server/services/chat-service.ts`
  - `looksLikeUserWantsWriteAction()` tambah deteksi:
    - Pola regex `pra-statik\s*\d{4}`, `statik\s*\d{4}` di awal paragraf.
    - Pola news copy lengkap: panjang > 600 char + ada "Malang, DD Month YYYY" (signature paragraf pembuka Medinfo).
  - Return true jika salah satu match.

## Verifikasi

- Live test v4.22.9 masih gagal (4× search_berita, 0× create_berita_draft) karena pesan Pra-STATIK lengkap tidak punya kata "buatkan" / "buat".
