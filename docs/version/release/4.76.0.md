## Summary

Transisi halaman ternyata dibatalkan browser karena timeout: pengecekan "halaman siap" memakai requestAnimationFrame yang ditahan selama view transition. Kini memakai timer, menunggu maks 0,4 dtk, dan kode halaman publik utama di-prefetch saat senggang sehingga transisi menampilkan halaman jadi, bukan spinner. Bila data/kode belum siap, tampil kerangka halaman berkilau + progress bar tipis; konten yang datang belakangan masuk dengan animasi. Komponen tanpa `data-aos` (judul section, item grid, blok konten) kini otomatis beranimasi. Foto besar di-decode async agar tidak memblokir scroll.

## Changes

- `client/src/lib/page-transitions.ts`: tunggu halaman siap via setTimeout (maks 400 ms); cegah transisi tumpang tindih; fallback fade opacity bila browser membatalkan transisi (sebagian HP).
- `client/src/App.tsx`: `RouteLoadingFallback` jadi skeleton + progress bar (`data-route-loading`); prefetch 12 halaman publik saat idle (dilewati bila Save-Data).
- `client/src/lib/reveal.ts`: animasi otomatis untuk judul section, item grid, blok konten (kecuali hero/header/nav/form/tabel/dialog, elemen fixed/sticky, pembungkus lebih tinggi dari layar); MutationObserver memantau atribut `data-aos` yang ditambahkan belakangan; `decoding="async"` untuk gambar tanpa mode decode.
- `client/src/components/MediaDisplay.tsx`: gambar `loading="lazy"` + `decoding="async"`.
- `client/src/index.css`: gaya skeleton, shimmer, progress bar.
