## Summary

Perbaiki penolakan crawler AI di halaman publik, tutup SSRF pada tool AI pembaca halaman web, perluas pengumuman hub mahasiswa dengan LP2M (KKM, penelitian, pengabdian) dan Fakultas Saintek, dan betulkan tautan lama pada konten prodi.

## Findings

- **Crawler:** filter anti-bot menolak (403, dialihkan ke /error) GPTBot, ClaudeBot, PerplexityBot, Applebot, dan OAI-SearchBot di semua halaman publik walau `robots.txt` mengizinkan. Googlebot dan GoogleOther lolos.
- **SSRF:** `fetchAndExtractWebpage` hanya memeriksa awalan nama host dan mengikuti redirect otomatis; metadata cloud (169.254.x), IPv6, dan domain yang menunjuk ke IP privat lolos.
- **Pengumuman:** hanya feed TI dan UIN pusat; `Buku Panduan KKM 2027` (LP2M, 13 Okt 2026) tidak muncul.
- **Tautan prodi (767 URL diperiksa):** 62 tautan SINTA/PDDikti memakai domain kemdikbud yang sudah tidak ada; 2 tautan Drive berakhiran `%20`; 172 tautan Google Docs/Drive RPS minta login (401) dan 14 sudah dihapus (410); 29 Scopus memblokir bot (bukan rusak).

## Changed

- `server/middleware/ddos-protection.ts`: daftar bot yang diizinkan (halaman non-API) ditambah crawler AI/pencarian; `/api` dan `/dashboard` tetap tertutup.
- `server/services/ai-tools.ts`: `assertPublicHost` (cek semua IP hasil DNS), redirect manual maksimal 4 lompatan dengan cek ulang.
- `server/services/prodi-student-resources.ts`: feed LP2M dan FST, kategori `kkm` dan `beasiswa`, loop feed disatukan.
- `client/src/components/prodi/student-hub-sections.tsx`: filter dan label sumber baru.
- `shared/prodi-link-fix.ts` (baru) dipakai `getProdiContentPublic`: domain SINTA/PDDikti diganti ke `kemdiktisaintek.go.id`, sisa `%20` dibuang (data DB tidak diubah).

## Verification

- `npm run check` lolos. Sinkronisasi pengumuman dijalankan tanpa menyimpan: 90 item (TI 43, LP2M 39 kategori KKM, FST 3, UIN 5).
- Uji unit kecil `fixProdiLinks` (Date tetap utuh).

## Notes / Known gaps

- Berkas RPS di Google Drive yang meminta login (401) dan yang dihapus (410) harus dibagikan ulang oleh pemilik foldernya; kode tidak bisa memperbaikinya.
- Tautan 404 lain: `curriculum-for-master`, 2 dokumen akreditasi LPM, repository dosen, dan satu pengumuman kalender akademik.
- Data dosen/laboratorium bersifat manual (override); tidak dibandingkan dengan situs prodi karena halaman dosen situs tidak lagi memuat nama dalam HTML.
