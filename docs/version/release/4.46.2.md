## Summary

Audit menemukan rantai pengambilalihan akun: email pengurus buatan admin (`POST /api/users`, `POST /api/users/:id/email`) tidak diverifikasi, termasuk admin komunitas tenant. Admin bisa membuat pengurus dengan email korban, memakai `/api/buyer/from-staff` untuk masuk ke akun pembeli korban tanpa password, lalu `/api/auth/switch-to-staff` ke akun pengurus korban di web utama.

## Security

- `/api/buyer/from-staff` mengembalikan 503 `TEMP_DISABLED` kecuali `BUYER_FROM_STAFF_ENABLED=1`.
- `syncLinkedBuyerPassword` (sinkron password pengurus→pembeli berdasar email) dimatikan dengan flag yang sama (admin bisa mengganti password pengurus ber-email korban lalu menimpa password pembeli korban).
- `/api/auth/switch-to-staff` tetap aman karena hanya menerima sesi pembeli dengan email terverifikasi OTP/Google.

## Notes / Known gaps

- Penyalaan kembali menunggu verifikasi OTP pada penautan pertama dan pengikatan akun pembeli ke id pengurus tertentu.
- Menu "Akun pembeli" untuk pengurus menampilkan pesan sementara dinonaktifkan.
