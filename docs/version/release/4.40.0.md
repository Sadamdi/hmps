## Summary

Analisis data produksi (571 grup bug otomatis): **493 grup (86%) adalah 404**, hampir semuanya probe bot (`/api/graphql`, `/api/v1/validate/code`, `/api/fs/exec`, `/api/datasources`, `/api/2.0/mlflow/...`, dst) atau 404 "data tidak ada" (artikel `/berita/penuh-haru-da`, produk `/EncoderStore/hoodie`, pesanan lama, komunitas yang tidak ada). Itu bukan bug aplikasi. Monitor sekarang hanya mencatat 404 yang benar-benar bug.

## Added

- Filter **kode error** di dashboard Bug Otomatis: chip `Semua kode`, `Tanpa 404`, dan per kode (`404 (n)`, `500 (n)`, `Client (n)`).
- API: `GET /api/system-errors/list?statusCode=` dan `?excludeStatusCode=`; `GET /count` memuat `byStatusCode`.
- `POST /api/system-errors/cleanup-noise` (owner, `{dryRun:true}` untuk menghitung) + tombol **Bersihkan noise** dengan konfirmasi.
- Catch-all `/api` 404 berformat JSON yang menandai request sebagai "endpoint tidak ada".

## Changed

- 404 dicatat **hanya** bila endpoint `/api` tidak ada sama sekali **dan** dipanggil dari halaman situs sendiri (Referer/Origin sama). Tidak dicatat: probe bot, 404 data tidak ada dari handler, komunitas tidak ada.
- 4xx selain 404 tidak lagi dicatat (409/413/422/dst = perilaku wajar).
- Noise client diabaikan; fingerprint chunk error tidak lagi mengandung hash build.
- 5xx tanpa stack menyimpan `message` dari body response.
- `/assets/*` yang tidak ada di produksi kini 404 (sebelumnya jatuh ke `index.html`).

## Verification

- `npm run check` lolos; tes e2e monitor 12/12 (probe bot tidak tercatat, endpoint hilang dari situs sendiri tercatat, produk/komunitas tidak ada tidak tercatat, ResizeObserver diabaikan, chunk beda hash satu grup, filter kode, facet, dry-run cleanup).
- Tampilan filter dicek di dashboard.

## Notes / Known gaps

- Data lama di produksi tidak dihapus otomatis. Jalankan tombol **Bersihkan noise** (owner) — dry-run menampilkan jumlah dulu.
- Catatan 404 lama yang punya halaman (±25) dibiarkan agar bisa ditinjau/ditandai Selesai.
- Fingerprint belum unik di database: burst error identik yang bersamaan bisa membuat 2 dokumen.
