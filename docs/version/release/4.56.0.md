## Summary

Tindak lanjut penyelidikan file uji upload (SVG XXE dan `.jpg.phar`) di komunitas ONTAKI pada 3 Juli 2026. Selain memperketat upload secara global, penyelidikan menemukan bahwa unggahan itu dilakukan lewat akun `wakil_ketua` yang masih memakai password bawaan `admin123`.

## Security

- `server/lib/upload-policy.ts` (baru): daftar putih ekstensi, pemeriksa magic bytes per jenis, batas ukuran per jenis (`checkUploadFile`). Diterapkan oleh `guardMulter` pada seluruh rute upload staf (25 rute, melalui `uploadMiddleware`). Pesan penolakan menyebut alasan dan jenis yang diizinkan.
- `server/lib/upload-safety.ts`: `activeContentServeGuard` kini juga menjadikan berkas di luar daftar putih (di `/uploads`) sebagai unduhan `application/octet-stream`, dan menolak penyajian `/uploads/_quarantine`.
- `server/services/upload-sweeper.ts` (baru): memindahkan, bukan menghapus, berkas di luar daftar putih ke `uploads/_quarantine/swept/<tanggal>/`; menandai `FileUpload` (`infected`, `policy:blocked-file-type`, engine `upload-sweeper`); dijalankan 45 dtk setelah server mulai dan tiap 24 jam; `UPLOAD_SWEEP_DRY_RUN=1` untuk uji. `uploads/_quarantine/` masuk `.gitignore`.
- `server/lib/weak-passwords.ts` (baru): daftar password umum. `hashPassword` menolaknya (`WeakPasswordError`, status 400) kecuali `allowWeak` (seed dev). `finalizeLogin` menolak login bila password yang dikirim termasuk daftar itu: `403 { error:{ code:'PASSWORD_RESET_REQUIRED' } }`, tanpa cookie sesi.
- `ops/deploy-server.sh`: `disable_clamav_if_requested` menonaktifkan `clamav-daemon` dan `clamav-freshclam` (default aktif; `HMPS_DISABLE_CLAMAV=0` untuk mempertahankan). Kode `file-scanner` tidak diubah; tanpa clamd status file menjadi `skipped`.
- Dokumen: SOP 12 (bagian Upload File Safety).

## Findings

- File uji: 11 rekaman SVG dan 1 `.phar` di `fileuploads`, diunggah 3 Juli 2026 19:29–19:44 WIB lewat akun komunitas `wakil_ketua`. Isinya payload XXE generik (`php://filter` dan `file:///etc/passwd`) dan sebuah JPEG bersih berekstensi `.phar` (uji bypass ekstensi). Tidak berdampak pada server Node.js.
- ClamAV produksi: 391 file `clean`, 14 `skipped`, 0 `infected`; ia tidak menandai file-file itu karena memang bukan malware.
- Akun berpassword `admin123`: ONTAKI 5 akun, UINUX 4 akun; situs utama dan auroradev26 tidak ada.

## Verification

- `npm run check` lolos.
- Kebijakan upload: 34 kasus (jenis sah lolos, SVG/HTML/phar/exe/makro/tanpa ekstensi/isi tidak sesuai/terlalu besar ditolak; `laporan.himatif.com.pdf` tidak salah blokir).
- E2E rute asli dengan sesi login: SVG, SVG XXE, `.jpg.phar`, HTML menyamar `.pdf` ditolak 400; PNG dan TXT sah diterima; login `admin123` 403 tanpa cookie; password kuat login normal (8/8).
- Penyapu dry-run pada 1.398 file: tepat 10 file uji (9 SVG + 1 phar) terdeteksi, tidak ada file sah; penyapu sungguhan di server uji memindahkannya ke karantina.
- Chat anonim dan penyajian file (15/15) dijalankan pada 4.55.2.

## Notes / Known gaps

- Akun komunitas dengan `admin123` tidak bisa login sampai owner komunitas mereset password-nya dari dashboard (email akun-akun itu juga berisi `admin123`, bukan alamat email asli, jadi Lupa Password tidak dapat dipakai untuk mereka).
- Upload SVG sengaja dihilangkan; bila kelak dibutuhkan, gunakan sanitizer SVG khusus, bukan mengizinkan ekstensi.
- File `.pkt` (Packet Tracer) tidak punya magic bytes; hanya dibatasi ukuran 20 MB dan disajikan sebagai unduhan.
- Pemindaian virus tradisional dihentikan; dokumen Office/PDF/arsip tetap hanya diunduh pengguna dan tidak dijalankan server. Risiko residu: dokumen berbahaya bagi pembacanya.
- Salinan ganda `uploads/uploads/...` (bug path terpisah) belum diselidiki.
