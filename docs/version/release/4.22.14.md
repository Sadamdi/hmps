# Release v4.22.14 — Second-pass write retry after read retry

## Ringkasan

Patch lanjutan v4.22.13. Setelah v4.22.13 push, live test menunjukkan AI menjawab dengan ringkasan visi-misi/struktur/profil (tool baca publik dipanggil 6× — get_organization_structure, get_profil_info, get_prodi_info). Mengapa? Karena `shouldForceReadToolRetry` match (generic welcome "Berikut ringkasan data yang tersedia" → generic pattern "beri tahu" → retry baca publik) → model di-retry → model panggil banyak tool baca → jawab ringkasan data, **bukan** create draft.

Fix: tambah **second-pass write retry** setelah read retry. Jika model tetap tidak memanggil tool tulis setelah read retry → retry sekali lagi dengan instruksi tulis.

## Yang Berubah

### Server

- `server/services/chat-service.ts`
  - Tambah branch `else if` kedua setelah read retry: cek lagi `shouldForceWriteToolRetry` + `shouldHardForceWriteTool` → retry paksa ke tool tulis.
