## Summary

Node.js server produksi dinaikkan dari 24.15.0 ke 24.22.1 (rilis keamanan 21 Okt 2026, termasuk perbaikan dekompresi Brotli). Path Node pada skrip ops disesuaikan.

## Changed

- `ops/deploy-server.sh`, `ops/auto-deploy.js`, `ops/install-auto-deploy.sh`: path nvm `v24.15.0` → `v24.22.1`.
- Server: unit systemd `pm2-root` memakai Node 24.22.1; paket apt (openssl, nginx, libc6) diperbarui.

## Verification

- `sharp` dan pm2 berjalan di Node 24.22.1; situs 200 setelah restart.

## Notes / Known gaps

- Layanan `9remote` tetap di Node 24.15.0 (modul native `node-pty` perlu build ulang).
- Saat Node dinaikkan lagi, ubah path di tiga file ops di atas.
