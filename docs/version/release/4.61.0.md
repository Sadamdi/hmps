## Summary

Halaman detail event dan galeri kini punya bagian "Event Terkait" / "Galeri Terkait" di bawah, bergaya sama dengan "Berita Terkait". Backend baru memakai TF-IDF + cosine similarity (judul ×3, tag ×10, deskripsi) dengan ambang kemiripan minimum, hanya item `published`, dan dihitung per request per tenant (tanpa cache global). Event yang tidak punya kecocokan diisi event se-tahun; galeri tanpa kecocokan tidak menampilkan bagian ini.

## Added

- `GET /api/events/:id/related?limit=` dan `GET /api/library/:id/related?limit=` (`server/routes.ts`).
- `server/services/related-content.ts`: `rankRelated`, `makeExcerpt`.
- `client/src/components/public/related-content-section.tsx`; dipakai di `pages/events/[year]/[eventId].tsx` dan `pages/library/detail.tsx`.

## Changed

- `enrichLibraryRelations`: preview berita dan event terkait pada galeri hanya yang `published`.

## Verification

- `npm run check` lolos; uji fungsi ranking (kecocokan dipilih, tanpa kecocokan = kosong).

## Notes / Known gaps

- Berita Terkait masih memakai indeks global `RecommendationService` (situs utama saja); dapat dimigrasikan ke `rankRelated` agar tenant ikut.
