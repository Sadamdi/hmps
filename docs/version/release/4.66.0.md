## Summary

Batch kedua dari permintaan owner. Semua alur OTP di situs (pengurus, pembeli, mahasiswa, backup, komunitas) kini mengirim kode dan link sekali pakai; memakai salah satunya membatalkan yang lain, disimpan sebagai hash, dan email memakai satu template profesional yang memuat tujuan, akun, waktu, asal permintaan, dan masa berlaku. Akun mahasiswa diaktivasi lewat email (Google otomatis), dan karya terkunci privat sampai aktivasi. Ganti password kini wajib dikonfirmasi lewat email. `/login` menjadi pintu tunggal untuk pengurus, mahasiswa, dan pembeli dengan sesi tetap terpisah. Karya mendapat deskripsi rich text, halaman tag, karya terkait otomatis, repo multi-platform (+ Codeberg), sampul otomatis terang/gelap, pratinjau, dan perbaikan profil publik yang sebelumnya 404 bila belum ada karya. Risiko utama ada di alur login & OTP; mitigasi: endpoint login lama tidak diubah, konsumsi OTP atomik, uji end-to-end di DB memori mode dev dan produksi.

## Highlights

- OTP + link sekali pakai di semua alur, template email seragam & profesional
- Aktivasi akun mahasiswa (24 jam) + kunci privat sebelum aktivasi
- Ganti password 2 langkah via kode/link; daftar perangkat lebih rinci
- Login satu pintu `/login` + `/daftar` + menu profil mahasiswa di navbar
- Karya: rich text, tag publik, karya terkait otomatis, repo GitHub/GitLab/Bitbucket/Codeberg, sampul otomatis, pratinjau
- Profil publik tampil walau belum ada karya; username dari nama (bukan NIM) + redirect username lama

## Features (detail)

### A — OTP + link sekali pakai
- **Masalah / tujuan:** pengguna ingin bisa memakai kode atau link; keduanya harus sekali pakai dan kedaluwarsa.
- **Perilaku baru:** `OtpChallenge.linkTokenHash` (HMAC), `secretMatches()` waktu-konstan, konsumsi atomik `findOneAndUpdate`; `/verifikasi` + `GET /api/verify/info`; prefill tab asal untuk form yang butuh isian lain.
- **Siapa terdampak:** semua (public, pembeli, mahasiswa, pengurus, owner)
- **Permission:** sama dengan alur asal masing-masing
- **Tenant-aware:** Conditional (OTP komunitas ikut; link prefill di tab asal)
- **Source:** `server/services/otp.ts`, `server/routes/verify.ts`, `client/src/pages/verifikasi.tsx`, `client/src/lib/otp-link-prefill.ts`

### B — Template email seragam
- **Masalah / tujuan:** email OTP & notifikasi berbeda-beda dan kurang informatif; isi feedback tidak di-escape.
- **Perilaku baru:** `renderEmailLayout()` dipakai OTP, balasan feedback, keputusan feedback, balasan bug; detail akun/tujuan/waktu/asal/masa berlaku; versi teks; semua isi di-escape.
- **Source:** `server/services/email-layout.ts`, `server/services/email.ts`

### C — Aktivasi, kunci privat, ganti password, perangkat
- **Perilaku baru:** daftar → langsung masuk + email aktivasi; belum aktivasi → `EMAIL_NOT_VERIFIED` untuk publik/shortlink; `POST /auth/activation/resend`; ganti password `/auth/password/change` + `/change/confirm`; daftar perangkat browser/OS/IP tersamar.
- **Source:** `server/routes/karya.ts`, `client/src/pages/karya/saya.tsx`

### D — Login satu pintu
- **Perilaku baru:** `/login` menentukan peran dari password (`/api/karya/auth/password-targets`, tanpa sesi) atau Google (`/api/auth/google/identify` + `isStudent`); dialog pilih peran; `/daftar`; menu profil mahasiswa.
- **Permission:** endpoint login pengurus tidak diubah
- **Source:** `client/src/components/auth/login-form.tsx`, `client/src/components/auth/unified-google.tsx`, `client/src/pages/daftar.tsx`, `client/src/components/public/student-nav-menu.tsx`, `server/routes.ts`

### E — Karya batch 2
- **Perilaku baru:** profil publik tanpa syarat karya (noindex bila kosong), username lama 301, pratinjau, rich text, `CONTENT_REQUIRED`, tag chip + halaman tag, karya terkait otomatis, Codeberg + lisensi + og image repo, sampul template PNG, editor TinyMCE ikut tema.
- **Source:** `server/routes/karya.ts`, `server/services/karya-cover.ts`, `server/services/karya-repo.ts`, `client/src/pages/karya/*`, `client/src/components/dashboard/rich-text-editor.tsx`

## Changed

- `POST /api/karya/auth/register`: sebelumnya wajib OTP sebelum masuk → kini langsung masuk (belum aktivasi)
- `POST /api/karya/auth/password/change`: sebelumnya langsung mengganti → kini kirim kode/link dulu
- `GET /api/karya/public/students/:username`: sebelumnya 404 bila belum ada karya tayang → kini tampil (wajib aktivasi), + `redirectTo`, `indexable`
- Endpoint verifikasi OTP pembeli/mahasiswa menerima kode 6 digit atau token link
- `sendOtpEmail` / email feedback & bug memakai layout bersama
- Cache daftar publik Karya 30 dtk → 10 dtk + SWR

## Fixed

## Security

- Token link: 32 byte acak, hanya hash HMAC di DB, waktu-konstan, sekali pakai atomik, ikut limit percobaan
- `/verifikasi` tidak mengeksekusi saat dibuka; info endpoint tidak membocorkan email lengkap
- `password-targets` hanya mengungkap akun yang password-nya benar; throttle per email+IP
- Ganti password: password baru disimpan sementara sebagai bcrypt, bukan teks
- Aktivasi Google mencabut sesi yang dibuat sebelum verifikasi (mencegah pengambilalihan email yang didaftarkan orang lain)
- Sampul karya belum publik tidak bisa diambil publik
- Email: semua isi pengguna di-escape
