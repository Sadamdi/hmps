## Summary

Audit log produksi (`/var/log/hmps-*.log` dan koleksi `systemerrors`, Juli–November 2026) menemukan bahwa sebagian besar "500" adalah kesalahan input klien yang tidak diklasifikasikan: ValidationError/CastError Mongoose (berita, event, library, chat, komentar), JSON rusak, request yang diputus klien (`stream is not readable` di `/api/gdrive/media-url`), dan URIError dari scanner. Handler global juga melempar ulang error setelah membalas. Semuanya kini 4xx dengan pesan jelas, dan hanya error server nyata yang dicatat ke monitor bug. Rilis ini juga mengganti embed "domain apa pun" (4.68.0) dengan allowlist pintar yang menganalisis domain sekali, serta menambah onboarding username, kategori ganda + taksonomi tag, tautan berlabel, direktori profil, video tutorial, dan tombol lihat password.

## Highlights

- Error 500 palsu dari log produksi → 4xx; handler global tidak melempar ulang
- Allowlist embed pintar (analisis sekali + AI), panel di Settings → Domain Embed
- Onboarding username + impor GitHub/GitLab/Bitbucket
- Kategori ganda + deteksi stack repo; ±330 tag dalam 15 grup
- Tautan berlabel, direktori profil, video tutorial, tombol lihat password
