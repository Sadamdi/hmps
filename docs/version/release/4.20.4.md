## Summary

Profil pembuat Spyro AI di `gemini-config.ts` diperluas dengan peran Medinfo Himatif Encoder 2024–2025 dan kepemimpinan GDGoC 2026. Fallback model `gemini-3.1-flash` (404) diganti `gemini-3.1-flash-lite`. Audit statis 37 tool definitions vs handlers dan matrix permission/path (public, dashboard, tenant, toko) lulus.

## Highlights

- Profil developer lengkap di AI context
- Gemini fallback model stabil
- Script audit `ops/audit-ai-tools.ts`

## Features (detail)

### Change — Profil developer Spyro AI
- **Masalah / tujuan:** User menanyakan pembuat AI; konteks harus mencantumkan peran organisasi resmi
- **Perilaku baru:** System prompt section 12 menyebut Medinfo 2024–2025 dan Leader GDGoC 2026
- **Siapa terdampak:** semua pengguna chat Spyro AI
- **Source:** `server/config/gemini-config.ts`

### Fix — Gemini model fallback
- **Masalah / tujuan:** `gemini-3.1-flash` mengembalikan 404 pada generateContent
- **Perilaku baru:** Fallback chain: `gemini-2.5-flash` → `gemini-2.5-flash-lite` → `gemini-3.1-flash-lite`
- **Source:** `server/config/gemini-config.ts`

### Ops — AI tools permission audit script
- **Masalah / tujuan:** Verifikasi kebijakan tool per role/path tanpa manual grep
- **Perilaku baru:** `npx tsx ops/audit-ai-tools.ts` — guest 11 public tools, write hanya di dashboard, toko write hanya di `/dashboard/toko`
- **Source:** `ops/audit-ai-tools.ts`
