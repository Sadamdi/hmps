## Summary

Audit production setelah 4.35.1 menunjukkan tiga galeri (Kajian, Seminar, Upgrading) masih memakai placeholder `data:` sebagai og:image: foldernya hanya berisi subfolder. Satu thumbnail Drive juga berukuran 582 KB, mendekati batas preview WhatsApp.

## Fixed

- `resolveLibraryOgImage` menelusuri subfolder Drive hingga 2 tingkat (maksimal 8 listing).
- Thumbnail proxy memakai lebar 800px.
- `absoluteMediaUrl` mengabaikan `data:`, sehingga fallback jatuh ke logo, bukan URL rusak.
- Tenant tanpa `logoUrl` di pengaturan memakai `Community.logoUrl`.

## File impact (sample)

- `server/services/og-meta.ts`, `server/services/seo-sitemap.ts`, `server/index.ts`

## Verification

- `npm run check` lolos; audit ulang URL sitemap setelah deploy.

## Notes / Known gaps

- Galeri yang hanya berisi video (mis. Raker 2026, Bukber 2026) tetap memakai logo, karena thumbnail video Drive berupa frame hitam.
