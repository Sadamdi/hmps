## Summary

Pengurus baru perlu tahu urutan kerja setelah kegiatan selesai: berita, galeri, event, lalu teks pendek untuk grup dan status WhatsApp. Alur ini sebelumnya hanya ada di kebiasaan tim. SOP 13 menuliskannya lengkap dengan format teks WA dan dua contoh nyata (R.O.A.R 2026 dan Kunjungan Industri Yogyakarta 2026). Tidak ada perubahan kode, endpoint, atau data.

## Highlights

- SOP baru `docs/SOP/13-publikasi-berita-dan-broadcast.md`.
- Format berita acuan: h3 untuk Table of Contents, foto 404x269, tag baku, lampiran Drive.
- Relasi berita, galeri, dan event dicatat (dua arah, `Copy ke Berita` hanya event menjadi draf berita).
- Template teks WA grup dan status.
- AGENTS.md menambahkan SOP 13 ke daftar wajib baca.
