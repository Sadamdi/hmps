## Summary

Portofolio tidak lagi hanya untuk kode: karya desain, game, 3D, animasi, video, riset, atau situs apa pun bisa dimulai dari link — metadata diambil server dengan aman. Rilis ini juga merapikan tag di halaman Karya, mengganti tombol kembali dengan tombol "ke atas", memperbaiki aktivasi notifikasi yang macet, dan menambah riwayat + pembatalan keputusan moderasi embed dengan penamaan Enco.

## Keamanan pratinjau link

- Hanya https; IP tujuan divalidasi publik **saat koneksi** (agent undici bersama dengan analisis embed) — diuji: `https://127.0.0.1/` dan `https://localtest.me/` (DNS → 127.0.0.1) ditolak.
- Redirect manual maks 4 hop, body maks 512 KB, timeout 8 dtk; YouTube/Vimeo lewat oEmbed resmi.
- Gambar pratinjau ditandatangani HMAC (`JWT_SECRET::karya-media`); saat simpan hanya gambar bertanda tangan valid yang diterima (tanda tangan palsu ditolak, diuji).
- Endpoint memakai `repoLimiter` + sesi mahasiswa.
