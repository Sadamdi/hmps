## Summary

Melanjutkan akun pembeli 4.42.0: data belanja yang sering dipakai kini tersimpan di akun, dan admin punya tab khusus untuk melihat serta mengelola pembeli tanpa mencampurnya dengan akun pengurus.

## Added

- **Alamat tersimpan** (`GET/PUT /api/buyer/addresses`): maks 5, tepat satu utama. Alamat utama terisi otomatis di checkout "Diantar", dengan tombol pilih alamat.
- **Favorit di akun** (`GET/PUT /api/buyer/favorites`): favorit perangkat digabung ke akun per toko dan tersimpan lintas perangkat (`use-store-favorites`).
- **Chat penjual ikut akun:** `findBuyerChat` mencari berdasarkan `buyerId` dulu. Chat tamu yang dilanjutkan setelah masuk ikut ditautkan.
- **Dashboard pembeli:** tab Alamat, Favorit & chat, serta kartu Perangkat yang masuk (keluarkan satu/semua).
- **Admin tab "Pelanggan"** di Dashboard Toko:
  - `GET /api/store/admin/customers` (+ `/:id`, `PATCH /:id/status`);
  - per toko (dari `StoreOrder.buyerId`), total belanja, metode login, detail pesanan, blokir/buka blokir.
- **Permission baru** `toko.customers.view` dan `toko.customers.manage` (owner otomatis).
- **OpenAPI:** 7 operasi tambahan via `ops/openapi-add-buyer.cjs`.

## Security

- Tanpa `toko.customers.manage`, email dan HP disamarkan.
- Blokir hanya dari toko utama. Blokir menaikkan `tokenVersion` dan mencabut semua sesi.
- Admin toko hanya bisa melihat dan mengubah pembeli yang pernah memesan di tokonya (selain itu 404).
- Tidak ada data rahasia (hash password, googleSub) di respons admin.
