## Summary

Pengguna di Dashboard dengan permission `berita.create` meminta Enco membuat draft berita, tetapi model berhenti setelah kalimat niat tanpa memanggil `create_berita_draft`. Paket PATCH ini memperkuat agent loop (force-write retry, maxToolIterations dinaikkan, deduplikasi history, prompt anti-niat-tanpa-tool), menambahkan UI thinking/next-moves yang aman (label saja, tidak ada path/server/env yang bocor), menerapkan `chatLimiter` 30/IP+device/menit pada `POST /api/chat/message`, dan menolak mutasi chat tanpa trusted Origin / `Sec-Fetch-Site: same-origin|same-site`. Anti-jailbreak diperkuat di system prompt (10b/10c) + soft heuristic server-side yang prepend instruksi refusal kalau pola jelas.

## Highlights

- Agent loop paksa lanjut tool saat model hanya menulis niat
- `maxToolIterations` OpenAI/Gemini dinaikkan ke 8 untuk chain tulis
- Dedupe history: pesan user yang sama tidak di-append dua kali
- Hardening chat: `chatLimiter` + `requireTrustedChatOrigin` di router chat
- API protection global juga menolak mutasi `/api/chat/*` tanpa same-site origin
- System prompt diperkuat (10b agent rule, 10c anti-jailbreak)
- Soft heuristic server-side prepend refusal untuk pola jailbreak jelas
- `ai-agent-progress.ts`: helper step label aman (tidak bocor tool args/path/key)

## Fixed

- Enco stuck "saya akan cek lalu buatkan…" tanpa function call
- Pesan user muncul dua kali di prompt history (dedupe)
- Akses chat API tanpa FE resmi (curl/Postman tanpa Origin) berhasil tembus

## Security

- `chatLimiter` 30/IP+device/menit dipasang di `POST /api/chat/message`
- `requireTrustedChatOrigin` middleware baru: butuh `Sec-Fetch-Site: same-origin|same-site` ATAU `Origin`/`Referer` host tepercaya
- Backup safety net di `api-protection.ts` untuk mutasi `/api/chat/*` tanpa same-site origin
- Anti-jailbreak prompt 10c + server-side soft heuristic untuk pola jelas
