## Summary

Audit lanjutan menemukan bahwa `POST /orders/:orderNo/reviews` dan `PATCH /reviews/:id` membaca seluruh file (hingga 5 x 30 MB) ke memori sebelum mengecek login, sehingga bisa dipakai menghabiskan RAM.

## Security

- `reviewUploadGuard` berjalan sebelum multer: tolak `Content-Length` > 66 MB (413), wajib pembeli login (401), pesanan/ulasan milik sendiri (404), batas 4 upload bersamaan (429).

## Verification

- `npm run check` lolos; E2E ulasan **49/49** (termasuk 413 dan 401 sebelum body dibaca).

## Notes / Known gaps

- Pembatasan serupa pada upload bukti bayar lama (5 MB per file) tidak diubah.
- Request chunked tanpa Content-Length tetap dibatasi oleh batas multer per file (30 MB x 5).
