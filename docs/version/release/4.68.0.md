## Summary

Laporan owner pada karya SMART: deskripsi README tampil sebagai kotak "Domain belum diizinkan untuk embed" dan teks `" alt="Logo SMART" width="140" />`, deskripsi di editor kosong, dan halaman Edit memberi Error 500. Log `systemerrors` produksi menunjukkan dua penyebab: TinyMCE `Cannot read properties of undefined (reading 'serialize')` dan chunk lama setelah deploy. Keduanya diperbaiki, renderer README dirapikan, dan rilis ini menambah peringatan pengurus, detail mahasiswa untuk admin, serta README profil gaya GitHub.

## Highlights

- Deskripsi README tampil utuh (gambar, tautan, `<p align=center>`), embed dari domain https apa pun
- Fix Edit 500 + reload otomatis saat chunk basi
- Peringatan admin untuk akun & karya (banner + email)
- Detail mahasiswa (semua karya termasuk draf)
- README profil (editor, unggah .md, impor GitHub) di profil publik

## Features (detail)

### Change A — Render README
- **Perilaku baru:** embed hanya untuk tautan telanjang; URL di atribut tidak dipotong; `allowAnyHost` di halaman karya & README profil; host anti-frame → kartu tautan; gambar README https apa pun di deskripsi.
- **Source:** `client/src/components/public/rich-html-with-embeds.tsx`, `server/services/karya-readme.ts` (`markdownToHtml`), `client/src/pages/karya/[slug].tsx`

### Change B — Fix Edit 500
- **Source:** `client/src/components/dashboard/rich-text-editor.tsx`, `client/src/lib/stale-chunk-reload.ts`, `client/src/main.tsx`, `client/src/components/error-boundary.tsx`

### Change C — Peringatan & detail mahasiswa
- **Perilaku baru:** `warnings[]` di akun & karya; `POST /admin/students/:id/warn`, `POST /admin/projects/:id/warn`, `GET /admin/students/:id`, `POST /me/warnings/:id/ack`; email `sendKaryaWarningEmail`.
- **Source:** `server/routes/karya.ts`, `server/models/karya.ts`, `server/services/email.ts`, `client/src/pages/dashboard/karya.tsx`, `client/src/pages/karya/saya.tsx`

### Change D — README profil
- **Perilaku baru:** `profileReadme` (PATCH `/me/profile` `profileReadme` atau `profileReadmeMarkdown`), impor GitHub mengembalikan `profileReadmeHtml`; profil publik: kartu README + statistik.
- **Source:** `server/routes/karya.ts`, `client/src/pages/karya/saya.tsx`, `client/src/pages/karya/mahasiswa/[username].tsx`
