## Summary

Chat Enco menjawab "apa model kamu" dengan nama model di balik layar (label dari gateway). Guard lama hanya berupa kalimat di system prompt (tidak menyebut nama model/vendor), sehingga mudah ditembus. Kini ada dua lapis deterministik di server:

1. **Pintasan pertanyaan identitas**: pesan pendek yang menanyakan model/vendor/pembuat dijawab langsung dengan balasan standar Enco tanpa memanggil model.
2. **Filter balasan**: kalimat balasan yang menyebut nama model/vendor sebagai identitas diri dibuang (`redactModelDisclosure`) sebelum disimpan dan dikirim.
3. Aturan tambahan di `AI_SECURITY_RULES`: dilarang menyebut nama model/vendor bahkan bila dipancing.
