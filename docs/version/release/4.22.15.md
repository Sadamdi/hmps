# Release v4.22.15 — Anti-halu prodi + max iterations 50 + get_prodi_info detail

## Ringkasan

Menaikkan batas iterasi tool dari 8 → 50 (sebelumnya model berhenti terlalu cepat, tidak sampai ke write tool setelah search), menambah section anti-halu untuk pertanyaan prodi/dosen/kurikulum, dan menambah parameter `academicYear` + `semester` ke tool `get_prodi_info` agar bisa return daftar mata kuliah lengkap per semester.

## Yang Berubah

### Server

- `server/services/chat-service.ts`
  - `runGeminiAgenticLoop`: `maxIterations` 8 → 50
  - Semua panggilan `runOpenAiChat()` sekarang pass `maxToolIterations: 50` (6 tempat)

- `server/services/openai-service.ts`
  - `maxIterations` cap 16 → 50; default 8 → 50

- `server/config/gemini-config.ts`
  - Tambah section `5b. ATURAN ANTI-HALU (WAJIB DIIKUTI UNTUK PERTANYAAN SPESIFIK)`:
    - Wajib panggil `get_prodi_info` untuk pertanyaan prodi/dosen/kurikulum/semester/lab/akreditasi
    - Jangan pakai hardcoded fallback di system prompt sebagai jawaban final
    - Jika data kosong, jawab jujur + sarankan fetch dari sumber publik
    - Multi-kurikulum: tanya "tahun berapa?" dulu sebelum detail
    - Konteks halaman TIDAK membatasi pencarian
    - Untuk info publik terbaru, prioritaskan `internet_search` + `fetch_website_content` ke `informatika.uin-malang.ac.id`
    - Langkah akhir: jawab dengan data tool, jangan bilang "tidak tersedia" tanpa panggil tool

- `server/services/ai-tools.ts`
  - Tool `get_prodi_info`: tambah parameter `academicYear` (number) dan `semester` (number)
  - `section='curriculum'` sekarang bisa return:
    - `availablePeriods[]` — list multi-kurikulum
    - `active` — info kurikulum aktif
    - `semestersDetail[]` — **detail per semester + subjects[] lengkap dengan code/name/sks/type/rpsUrl**
    - `optionalSubjects[]`
