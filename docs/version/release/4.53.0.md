## Summary

AI di halaman publik kini bisa mengambil data publik toko dan memahami halaman yang sedang dibuka.

## Added

- `server/services/public-store-ai-tools.ts`, `server/services/public-page-hints.ts`; wiring di `ai-tools.ts` dan `chat-service.ts`; aturan di `gemini-config.ts`.

## Verification

- `npm run check` lolos.
- Tes lapisan tool **36/36** (termasuk produk draft tidak bocor, regex berbahaya aman, tanpa nomor WA/rekening, prefix komunitas).
- Tes percakapan nyata ke Gemini (12 skenario, DB uji): harga katalog, daftar produk, detail produk ("harganya" = produk yang dibuka), pembayaran/admin, bundling, kelembagaan, berita, prodi, beranda, permintaan hapus dari halaman publik ditolak, nomor WA tidak dibocorkan. 11/12 sesuai; satu sisanya (galeri) hanya karena DB uji tidak punya item galeri terbit.
- Dibaca-saja terhadap data produksi: katalog, detail varian, dan info toko (QRIS/SeaBank, admin Fiqah/Faisal, path /EncoderStore) tampil benar.
