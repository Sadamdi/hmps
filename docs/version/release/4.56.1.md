## Summary

Pembaruan dependensi dengan pendekatan konservatif: perbaikan yang kompatibel semver lebih dulu, lalu dua paket runtime berisiko tertinggi yang menyentuh data pengguna (gambar unggahan dan email) dinaikkan satu major dengan uji fungsi.

## Changed

- `package-lock.json`: hasil `npm audit fix`.
- `package.json`: `sharp ^0.35.5`, `nodemailer ^10.1.7`; `@types/nodemailer` dihapus.
- `server/services/email.ts`, `server/services/store-email.ts`: tipe `nodemailer.Transporter` diganti `ReturnType<typeof nodemailer.createTransport>` (nodemailer 10 tidak lagi mengekspor namespace itu). Tidak ada perubahan perilaku.

## Verification

- `npm run check` dan `npm run build` lolos.
- sharp: JPEG, PNG, WebP, GIF, TIFF, AVIF dikonversi ke WebP dengan `rotate().resize()`; dukungan HEIF aktif (libheif 1.23.5).
- nodemailer: pengiriman via transport stream (tanpa SMTP nyata) dengan HTML, teks, lampiran, dan banyak penerima; `service: 'gmail'` tetap memetakan ke smtp.gmail.com:465 secure; `disableFileAccess` menolak `file:///etc/passwd`.
- E2E setelah upgrade: upload anonim/chat 15/15, login + upload staf 8/8.

## Notes / Known gaps

Sisa 16 temuan `npm audit` (0 critical, 10 high, 6 moderate) seluruhnya butuh upgrade MAJOR dan bukan jalur serangan di produksi:

- **Alat build/dev, tidak jalan di produksi:** `vite` (≤6.4.2: path traversal dan bypass `fs.deny` di dev server), `esbuild` (dev server), `tailwindcss` dan turunannya (`braces`, `chokidar`, `fast-glob`, `micromatch`, `postcss-nested`), `@tailwindcss/typography`. Produksi menyajikan hasil build statis; jangan mengekspos dev server ke jaringan umum.
- **Firebase:** hanya `firebase/app` dan `firebase/auth` yang dipakai di klien (Google Sign-in). `@firebase/firestore` dan `@grpc/grpc-js` yang rentan tidak diimpor/dibundel dan tidak ada di server.
- **`exceljs` → `uuid`:** pengecekan batas buffer hanya bila `buf` diberikan; tidak terjangkau dari input pengguna.
- Upgrade MAJOR vite 8, tailwind 4, firebase 9.x/downgrade belum dilakukan karena risiko merusak build dan UI; jadwalkan sebagai pekerjaan terpisah dengan uji visual.
- Skrip instalasi (`sharp`, `esbuild`, `canvas`) diblokir oleh kebijakan npm lokal; sharp berjalan lewat paket biner prebuilt sehingga tidak terpengaruh.
