## Summary

Screenshot live menunjukkan viewport gelap + tombol AI saja. Akar: hero tenant tanpa banner/logo jadi `bg-muted`/`div` kosong full-height, sementara footer tenant seed mengosongkan alamat/email/sosial/tautan sehingga blok footer hampir tidak kelihatan di dark mode. Kebijakan baru: **identitas tetap tenant**, **chrome/copy yang belum diisi fallback ke default Himatif**. Tenant yang sudah isi (ONTAKI about, email, logo) tetap memakai datanya.

## Highlights

- Hero tenant tanpa gambar memakai `DEFAULT_IMAGE_URL` Himatif (bukan layar gelap)
- Footer: email/alamat/maps/sosial/tautan kosong → default Himatif
- About kosong → `aboutUs` / `aboutPageIntro` / HTML default Himatif
- Visi kosong → visi/misi default Himatif
- Tagline kosong → tagline Himatif; `siteName` tetap nama komunitas
