## Summary

Audit Chrome DevTools menunjukkan card berita mobile terlalu tinggi, tentang kami penuh wall of text, FAB navigasi tengah-kanan bertabrakan dengan AI chat, loading sering terasa stuck di ~95%, dan alur kelembagaan terlalu banyak tab/dialog. Unit kerja ini merombak pengalaman public (main + tenant shared components), shell dashboard, loading/motion, serta kelembagaan manual-first dengan import dokumen yang jujur (butuh review). Tidak ada perubahan kontrak backend.

## Highlights

- Berita home/list: grid 2 kolom compact di mobile (4 kartu awal), excerpt/meta disembunyikan di layar kecil
- Tentang kami + profil: teks panjang di-clamp dengan expand, strip foto mobile mengganti floating gallery
- FAB: navigasi mobile ke kiri-bawah; AI chat tetap kanan-bawah — tanpa overlay tengah
- Loading: preload kritis saja, fail-safe 3s, sync hero; AOS dimatikan di mobile/reduced-motion
- Dashboard shell responsif + kelembagaan wizard manual-first; AI = “Import dari dokumen (butuh review)”

## Features (detail)

### Feature / Change A — Public berita compact

- **Masalah / tujuan:** card berita ~full-width tinggi di mobile sulit discroll.
- **Perilaku baru:** `grid-cols-2`, body mobile hanya judul + tanggal; desktop tetap kaya metadata.

- **Tenant-aware:** Yes (shared components)

### Feature / Change B — About / profil readable

- **Siapa terdampak:** public / tenant

### Feature / Change C — Mobile FAB anti-overlap

- **Masalah / tujuan:** nav bubble tengah-kanan menabrak AI chat.
- **Perilaku baru:** nav `left-3 bottom-6` expand ke atas; chat `right-3 bottom-6` + safe-area.

- **Tenant-aware:** Yes

### Feature / Change D — Loading & motion

- **Masalah / tujuan:** progress stuck 95% / animasi berat.
- **Perilaku baru:** preload kritis, timeout 3s, exit lebih pendek di mobile, AOS off <768px / reduced-motion.
- **Siapa terdampak:** semua first paint
- **Permission:** N/A

- **Source:** `use-app-loading.ts`, `LoadingScreen.tsx`, `hero.tsx`, `App.tsx`
