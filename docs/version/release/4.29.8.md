## Summary

Path toko bisa diatur dari dashboard (mis. `/EncoderStore`). Saat reload langsung di path itu, `App.tsx` menganggap segmen pertama yang tidak dikenal sebagai slug komunitas, sehingga query setting toko dinonaktifkan dan halaman jatuh ke 404 komunitas; navigasi lewat klik berhasil karena setting sudah ada di cache. Kini setting toko selalu diambil (URL absolut, tidak di-rewrite ke API tenant) dan router menunggu setting sebelum memutuskan toko vs komunitas. Server menolak path toko yang bentrok dengan route sistem/komunitas, dan registrasi komunitas menolak slug yang sama dengan path toko.

## Highlights

- Reload `/<path-toko>` dan sub-halamannya berfungsi.
- Validasi `navbarPath`: satu segmen, bukan route sistem, bukan slug komunitas (`STORE_PATH_INVALID|RESERVED|TAKEN`).
- Registrasi komunitas menolak slug = path toko.
