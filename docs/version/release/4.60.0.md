## Summary

Dashboard hanya menampilkan "terpasang" untuk sesi Instagram, tanpa tahu valid atau tidak, dan crawl 20 Okt gagal `spawn ENOMEM` (VPS 2 GB). Kini ada kartu "Kesehatan Instagram" (sesi, crawl terakhir, terakhir berhasil, RAM tersedia), sesi bisa dipasang dari dashboard tanpa akses server, dan crawl menunggu RAM cukup sebelum menjalankan Python.

## Changed

- `server/services/instagram-session.ts`: `installInstagramSession` (menerima JSON ekspor cookie browser atau format simpanan; wajib sessionid dan csrftoken; file sesi mode 600).
- `server/services/instagram-instagrapi.ts`: `availableMemoryMb` (MemAvailable) dan penjaga: tunggu hingga 2x30 detik bila RAM < 200 MB, lalu gagal dengan pesan jelas alih-alih ENOMEM.
- `server/routes/social-feed.ts`: `POST /api/social-feed/instagram-session` (izin `social_feed.edit`, hanya situs utama); `GET /manage` menambah `instagramSession` (memory, lastGoodAt, lastRunOk, lastRunIssue).
- `client/src/components/dashboard/social-feed-settings-panel.tsx`: kartu `InstagramSessionCard`.

## Verification

- `npm run check` lolos. Belum diuji terhadap Instagram sungguhan (sesi baru dipasang setelah deploy).
