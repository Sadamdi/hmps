## Summary

Chat penjual diubah ke model marketplace (Tokopedia/Shopee): **satu percakapan per pembeli**. Setiap kali pembeli menekan "Chat penjual" dari suatu produk, pesan **kartu produk** (thumbnail, nama, harga, link) disisipkan ke percakapan yang sama, sehingga satu pembeli bisa menanyakan banyak barang. Admin melihat nama pembeli dan daftar produk yang ditanyakan. Pembeli juga bisa membuka chat dari tombol **Chat** (dengan badge balasan belum dibaca) di header toko. Percakapan **dihapus otomatis 7 hari setelah pesan terakhir** (TTL MongoDB). Rate limit toko ditinjau: chat punya limiter sendiri, keranjang & cek ongkir kini dibatasi, balasan 429 berisi `message`, dan bucket "perangkat" memakai cookie sesi toko sehingga pembeli dengan browser/HP sejenis tidak saling memblokir.

## Highlights

- Kartu produk di chat ("Anda menanyakan produk ini") untuk pembeli & admin.
- Satu percakapan per pembeli; produk berbeda → kartu baru; produk sama tidak digandakan.
- Inbox admin: nama pembeli, thumbnail & jumlah produk ditanyakan.
- Tombol Chat + badge unread di header toko.
- TTL 7 hari (`expireAt`, diperbarui tiap pesan); chat lama diisi otomatis.
- Limiter: chat 10/menit & 80/jam per pembeli (15/120 per IP); keranjang 60/menit; cek ongkir 20/menit.

## Features (detail)

### Change A — Chat marketplace
- **Perilaku baru:** `GET /api/store/chats/mine` (`?markRead=1`), `POST /api/store/chats` (`text` opsional bila `productId` ada; nama wajib untuk pesan pertama), `POST /api/store/chats/mine/whatsapp`. Pesan punya `kind: 'text' | 'product'` + snapshot `product`. Admin: daftar berisi `products[]`; detail berisi `products[]`, `storePath`.
- **Tenant-aware:** Yes
- **Source:** `server/routes/store.ts`, `db/mongodb.ts`, `client/src/components/toko/store-chat-panel.tsx`, `client/src/components/toko/store-chat-product-card.tsx`, `client/src/components/dashboard/store-chat-inbox.tsx`, `client/src/components/public/store-public-header.tsx`, `client/src/pages/toko/[slug].tsx`

### Change B — Auto-hapus 7 hari
- **Perilaku baru:** field `expireAt` + TTL index `{ expireAt: 1 }, expireAfterSeconds: 0`; diperbarui tiap pesan pembeli/admin.

### Change C — Rate limit toko
- **Perilaku baru:** `storeChatRateLimiter`, `storeCartRateLimiter` (semua mutasi keranjang + draft), `storeShippingQuoteRateLimiter`; `send429` menambah `message`; kunci perangkat limiter = hash cookie `hmps_store_session` bila ada.
- **Source:** `server/middleware/public-rate-limit.ts`, `server/routes/store.ts`
