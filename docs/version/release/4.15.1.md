## Summary

Retest Chrome setelah 4.15.0 menemukan sisa bug isolasi: `App.tsx` menunggu `/api/store/public/settings` (web utama) untuk path `/:slug`, sehingga komunitas valid/invalid bisa spinner atau jatuh ke homepage Himatif. `NotFound` default juga auto-redirect ke `/` setelah 5 detik — slug salah (`/kontakiuinmalang`) terdengar seperti “ketuker” ke situs utama. Deploy historis masih gagal `sh: 1: vite: not found` ketika PM2 `NODE_ENV=production` memangkas bin. Unit ini menutup route gate, 404 tanpa dump ke Himatif, dan mengeraskan install/build agar vite selalu ada.

## Highlights

- Path tenant-like tidak menunggu store settings Himatif sebelum `CommunityShell`
- Slug komunitas tidak valid tetap 404, tidak auto-redirect ke beranda Himatif
- Store settings tenant timeout 8s + fallback `/toko` (bukan spinner)
- `vite`, `@vitejs/plugin-react`, `esbuild`, `cross-env` pindah ke `dependencies`
- `deploy-server.sh` cek `node_modules/.bin/vite` executable + `unset NODE_ENV`; FATAL jika bin masih hilang
- Auto-deploy watcher (`docs/ops/_auto-deploy.js`) set `NODE_ENV=development` + `NPM_CONFIG_PRODUCTION=false` saat child npm

## Features (detail)

### Feature / Change A — Tenant route gate

- **Masalah / tujuan:** Hard-reload `/ontakiuinmalang` atau typo `/kontakiuinmalang` tertahan loading karena `App.tsx` menganggap `/:slug` sebagai path toko dinamis dan menunggu settings navbar toko utama.
- **Perilaku baru:** `getTenantSlugFromPathname` menandai path tenant; query store main `enabled: !isTenantPath`; `isLikelyDynamicStorePath` false untuk tenant. CommunityShell langsung mount.
- **Siapa terdampak:** public / tenant
- **Permission:** public
- **Tenant-aware:** Yes
- **Source:** `client/src/App.tsx`

### Feature / Change B — Invalid slug 404 isolation

- **Masalah / tujuan:** `CommunityShell` error (slug tidak ada) merender `NotFound` di luar `Router base`, lalu countdown 5 detik `navigate("/")` membuka beranda Himatif.
- **Perilaku baru:** `NotFound` menerima `redirectTo?: string | null`. Slug komunitas invalid memakai `redirectTo={null}` — pesan 404 tanpa redirect. Tombol “Ke beranda” hanya jika redirect aktif.
- **Siapa terdampak:** public / tenant
- **Permission:** public
- **Tenant-aware:** Yes
- **Source:** `client/src/pages/not-found.tsx`, `client/src/pages/community/index.tsx`

### Feature / Change C — Vite deploy permanen

- **Masalah / tujuan:** Setelah pull/stop/`npm install`/build, `sh: 1: vite: not found` → 502. Akar: `vite` di `devDependencies` + `NODE_ENV=production` dari PM2; cek `vite_missing` dulu hanya lihat `package.json` tanpa bin.
- **Perilaku baru:** Paket build pindah ke `dependencies`. `vite_missing` = `! -x node_modules/.bin/vite`. `npm_install_with_dev` unset `NODE_ENV`, `--include=dev`, force-install vite+esbuild jika bin hilang, FATAL jika masih hilang. Template auto-deploy unset production npm prune.
- **Siapa terdampak:** ops / production
- **Permission:** N/A (deploy)
- **Tenant-aware:** No
- **Source:** `package.json`, `ops/deploy-server.sh`, `docs/ops/_auto-deploy.js`
