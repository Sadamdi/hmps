# Release v4.16.9 — Bidirectional relations and authored image sizing

| Version | `4.16.9` | Bump | PATCH |

## Summary

Perbaikan konsistensi relasi Berita–Galeri–Event pada API publik dan tampilan detail. Relasi lama yang hanya tersimpan di satu sisi kini tetap ditemukan dan diperbaiki saat dibaca. Ukuran gambar yang diatur di rich editor juga kembali dihormati tanpa mengorbankan responsivitas.

## Changed

- `server/routes.ts`
  - Galeri menggabungkan relasi dari kedua sisi (`Library.related*Ids` dan reverse lookup).
  - Record galeri lama yang satu arah diperbaiki otomatis.
  - Detail Galeri berbasis ID maupun slug menjalankan relation enrichment yang sama.
  - Detail Event diperkaya dengan `relatedGalleryPreview`.
- `client/src/pages/events/[year]/[eventId].tsx`
  - Menampilkan bagian **Galeri Terkait**.
- `client/src/index.css`
  - Menghapus pemaksaan `width: auto !important` pada gambar berita.
  - Tetap menggunakan `max-width: 100%` dan `height: auto` agar aman di mobile.

## Relation invariant

Setiap relasi harus bidirectional:

- Berita ↔ Galeri
- Event ↔ Galeri
- Berita ↔ Event (Event menjadi sumber relasi yang sudah ada)

Public API melakukan union dua arah untuk toleransi data lama, sedangkan operasi simpan tetap menyinkronkan kedua record.

## Verification

- Lint/TypeScript diagnostics untuk file yang diubah.
- Public Event detail memuat `relatedGalleryPreview`.
- Public Gallery detail memuat `relatedBeritaPreview` dan `relatedEventsPreview` walaupun data lama hanya tersimpan pada sisi lawan.
- Gambar rich editor dengan width eksplisit tetap sesuai ukuran pada desktop dan mengecil maksimal selebar container pada mobile.
