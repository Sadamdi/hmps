# Release v4.22.11 — Reorder retry branches: write dulu, baru read

## Ringkasan

Patch lanjutan v4.22.10. Setelah v4.22.10 push ke server, live test masih menunjukkan AI menjawab dengan list berita (bukan create draft). Masalah: di `chat-service.ts`, retry branches diurut `web → read → write`. Untuk pesan Pra-STATIK dengan info lengkap, `shouldForceReadToolRetry` lebih dulu match (karena panjang > 240 char) → model di-retry dengan instruksi `search_berita` → model manggil search_berita berkali-kali → jawab list berita.

Fix: re-order branches jadi `web → write → read`. Jadi kalau intent user adalah tulis (terutama news-copy lengkap), write retry jalan dulu.
