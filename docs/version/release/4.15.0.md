## Summary

Audit tenant vs main menemukan isolasi database sudah benar, tapi URL publik, canonical/og, sitemap, SSR, logo navbar, dan beberapa tautan `<a>` mentah masih mengarah ke situs Himatif. Unit kerja ini membuat path publik tenant (`/{slug}/...`) jadi sumber kebenaran untuk canonical, share, sitemap, dan SSR; logo `settings.logoUrl` tampil di navbar/favicon/SEO; copy Himatif hanya fallback di web utama; JWT main tidak lagi dianggap user tenant. Register menolak slug reserved (termasuk `toko`). AI chat sudah tenant-aware dan tidak diubah kontraknya.

## Highlights

- Canonical/og/JSON-LD berita dan halaman publik tenant memakai `/{slug}/...`, bukan `/berita/...` utama
- SSR production untuk `/:slug` dan nested public pages + artikel tenant dari DB tenant
- Sitemap 200 XML (bukan 500) dan memuat landing/berita komunitas aktif
- Navbar + favicon + SEO memakai `logoUrl` / `siteName` tenant
- Auth tenant tidak fallback ke user Himatif; dashboard visi/settings tidak lagi prefill copy Himatif di tenant
- Login/beranda tenant tidak spinner abadi: form tetap tampil, `/auth/me` timeout 8s, tenant skip LoadingScreen Himatif

## Features (detail)

### Feature / Change A — Public path + SEO tenant

- **Masalah / tujuan:** Artikel/halaman tenant terindeks atau di-share sebagai URL Himatif; sitemap production 500; crawler tidak melihat ONTAKI sebagai situs sendiri.
- **Perilaku baru:** `shared/tenant-paths.ts` + `usePublicBrand` membangun path/URL absolut. SSR inject `siteName`/`logoUrl` tenant. Sitemap menambah `/communities`, `/{slug}`, `/{slug}/berita`, `/{slug}/profil`, `/{slug}/kelembagaan`, dan berita published tenant. Error generator tetap 200 XML minimal.
- **Siapa terdampak:** public / crawler / tenant
- **Permission:** public
- **Tenant-aware:** Yes
- **Source:** `shared/tenant-paths.ts`, `client/src/hooks/use-public-brand.ts`, `server/index.ts`

### Feature / Change B — Logo, copy, tautan dashboard

- **Masalah / tujuan:** Navbar teks-only; title/about/visi/footer jatuh ke Himatif; `<a href="/kelembagaan">` buka situs utama.
- **Perilaku baru:** Logo navbar jika `logoUrl` ada. Copy Himatif hanya di main. Tenant kosong = empty-state / `siteName`. Tautan `<a>` di home/structure/dashboard memakai `publicPath` / `basePath`. Dashboard kelembagaan tidak prefill visi Himatif di tenant. Settings tenant tidak memakai placeholder Himatif.
- **Siapa terdampak:** public / admin tenant
- **Permission:** settings/kelembagaan tetap permission existing
- **Tenant-aware:** Yes
- **Source:** `client/src/components/public/navbar.tsx`, `about.tsx`, `vision-mission.tsx`, `footer.tsx`, `hero.tsx`, `pages/dashboard/kelembagaan.tsx`, `pages/dashboard/settings.tsx`

### Feature / Change C — Auth isolation + register reserved slug + `/api/info`

- **Masalah / tujuan:** Cookie JWT Himatif bisa terasa “login” di tenant; slug `toko`/`berita` bentrok route; UI butuh identitas tenant.
- **Perilaku baru:** `authenticate` / `authenticateOptional` menolak JWT main atau tenant mismatch di request tenant. `TenantAuthProvider` tidak fallback `/api/auth/me`. `GET /api/info` → `{ slug, name, isTenant }`. Register server+client menolak reserved slug (`shared/tenant-paths.ts`). `GET /api/prodi` 404 di tenant.
- **Siapa terdampak:** auth / register / tenant
- **Permission:** `/api/info` public; auth tetap cookie JWT
- **Tenant-aware:** Yes
- **Source:** `server/auth.ts`, `client/src/lib/tenant-auth.tsx`, `server/routes.ts`, `client/src/pages/register.tsx`

## Fixed

- Canonical/og berita tenant mengarah ke `/berita/{slug}` Himatif — root: hardcoded origin path
- SSR hanya query DB utama — root: tidak ada handler `/:slug/berita/:article`
- `<a href="/kelembagaan">` mentah — root: bukan wouter Link
- Sitemap 500 — root: fallback `sendFile` gagal
- JWT main resolve sebagai user tenant — root: lookup ID di DB tenant / fallback `/api/auth/me`
- Klik Login di tenant → spinner gelap terus, Back sama — root: LoginForm `if (isLoading)` + `/auth/me` tanpa timeout + LoadingScreen nunggu `/api/home-images/active` (session `app-loaded` tidak pernah tersimpan)

## Security

- Tenant authenticate menolak JWT tanpa `tenant` match / user tidak ada di DB tenant
- `authenticateOptional` tidak mengisi `req.user` dari JWT main di request tenant
- Reserved slug dicegah di register agar tidak menimpa route sistem
- Tidak ada secret baru
