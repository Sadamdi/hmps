## Summary

Audit tampilan Encoder Store di HP (375px) dan PC, khusus bundling. Ditemukan dan diperbaiki beberapa bug tampilan dan satu kekurangan alur.

## Fixed

- **Dialog "Lihat isi" paket meluber di HP:** gambar memakai `MediaDisplay` (tinggi minimum 12rem + lightbox) sehingga foto isi paket sebesar kartu dan layout pecah ke kanan. Diganti `<img>` ringan dengan ukuran tetap, fallback ikon bila gambar gagal, dan dukungan link Google Drive.
- **Header situs (z-55) menimpa semua dialog/popup:** dialog, alert dialog, sheet, select, popover, dropdown, dan tooltip dinaikkan ke z-70 (toast z-100 tetap paling atas).
- **Dropdown produk melebihi lebar layar:** konten Select dibatasi lebar layar dan teks item panjang dibungkus.
- **Tombol "Tambah paket" di dialog:** dialog menutup otomatis setelah berhasil, pilihan ukuran direset; status loading hanya di kartu yang dipakai (sebelumnya semua kartu ikut berputar).
- **Tabel bundling di dashboard (HP):** tombol edit/hapus terpotong. Di layar kecil baris berubah jadi kartu; layar besar tetap tabel.
- **Editor isi paket (HP):** tiap produk jadi kotak sendiri (produk, ukuran, qty, hapus) tanpa saling menyempit; tombol "Baris" menjadi "Tambah produk".
- **Keranjang:** baris bundel/produk kini menampilkan thumbnail dan teks panjang dibungkus.

## Verification

- `npm run check` lolos; tes e2e bundling 24/24.
- Diperiksa langsung di browser (375px dan desktop): katalog, dialog paket, detail produk ("Tersedia dalam paket"), keranjang, invoice, semua tab dashboard toko (tanpa overflow horizontal).

## Notes / Known gaps

- Bubble chat Enco (pojok kanan bawah) tetap melayang di atas konten; ini sifat widget.
- Ukuran isi paket tidak bisa diubah di keranjang; hapus lalu tambah ulang paket.
