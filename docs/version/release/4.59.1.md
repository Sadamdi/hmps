## Summary

Audit rute tanpa middleware auth (50 rute tulis; sebagian besar memang publik dan memeriksa kepemilikan lewat token sesi/pesanan) menemukan dua celah path traversal.

## Findings

- `POST /api/register/upload` (butuh kode registrasi aktif): field `category` dari body langsung masuk ke path folder, sehingga `../` bisa menaruh file di luar folder sementara.
- `deleteFile()` mengurai URL tanpa menolak `..`; `oldFileUrl` dari body rute upload bertoken staf bisa menghapus file di luar folder upload.
- Rute toko (bukti bayar, batal, email, ulasan), feedback `own`, dan chat memeriksa kepemilikan; tidak ditemukan celah.

## Changed

- `server/upload.ts`: `uploadTempOnboarding` menyaring kategori dan memastikan path tetap di dalam `assetsDir`; `deleteFile` menolak URL berisi `..` atau NUL.

## Verification

- `npm run check` lolos. Uji lokal: `/uploads/../x` dan `/uploads/a/../../x` ditolak (file tetap ada); penghapusan normal tetap bekerja.

## Notes / Known gaps

- Rute `/api/gdrive/*` publik hanya menerima URL Google Drive tervalidasi dan dibatasi rate limit; tidak diubah.
- Crawl Instagram produksi masih diblokir Instagram dan gagal `spawn ENOMEM` pada 20 Okt; butuh sesi akun dan memori server.
