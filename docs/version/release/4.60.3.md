## Summary

Backfill arsip Instagram berjalan tiap jam (3 halaman/run, request ber-login) sampai seluruh akun terambil. Itu menambah risiko rate limit dan blokir akun sesi tanpa manfaat bagi beranda. Backfill kini berhenti setelah cache mencapai 160 item; setelah itu hanya run harian yang mengambil post terbaru (satu panggilan ber-login).

## Changed

- `server/services/social-feed.ts`: `BACKFILL_MAX_ITEMS = 160`; bila tercapai, cursor dihapus dan backfill ditandai selesai (`backfilledAt`).

## Verification

- `npm run check` lolos.

## Notes / Known gaps

- Sesi login hanya dipakai untuk menemukan post terbaru; thumbnail diambil dari CDN tanpa login. Isi per post/link manual lewat halaman embed (tanpa login).
- Cloudflare WARP/tunnel tidak ditambahkan (lihat jawaban di sesi): IP Cloudflare sama-sama dikenali sebagai datacenter, dan mengubah jaringan server berisiko memutus akses.
