## Summary

Banyak menu navbar dan tombol memuat ulang seluruh halaman sehingga tidak beranimasi. Kini berpindah di dalam aplikasi, tautan biasa dan tombol kembali/maju ikut beranimasi. Animasi diganti fade through (lama memudar cepat, baru naik halus) tanpa kemiringan 3D, halaman baru mulai dari atas, animasi komponen tidak lagi dobel, dan hero beranda langsung tampil saat dituju dari halaman lain.

## Changes

- `client/src/lib/page-transitions.ts`: `softNavigate()`, penangkap klik tautan internal, transisi pada popstate, gulir ke atas.
- 24 file halaman/komponen publik: `window.location.href` diganti `softNavigate`.
- `client/src/index.css`: animasi fade through.
- `client/src/lib/reveal.ts`: tanpa animasi dobel saat transisi.
- `client/src/components/public/hero.tsx`, `client/src/App.tsx`: hero langsung tampil saat datang dari halaman lain; data gambar di-prefetch.
