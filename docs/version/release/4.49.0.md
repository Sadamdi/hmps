## Summary

Pembeli bisa memilih varian dan membeli langsung dari kartu produk tanpa membuka halaman detail.

## Added

- `store-quick-view.tsx` (`StoreQuickViewDialog`, `useStoreQuickView`, `productNeedsChoice`).
- `GET /public/products` kini menyertakan `variants` dan `variantGroupName`.
- `?beli=1&v=&qty=` di halaman detail membuka dialog beli sekali (URL dibersihkan).

## Verification

- `npm run check` lolos.
- Browser HP 375px dan PC: popup terbuka dari kartu bervarian, pilih varian M lalu Beli sekarang membuka detail dengan varian terpilih dan dialog beli; tanpa overflow horizontal.

## Notes / Known gaps

- Kartu bundling masih memakai dialog bundling sendiri (sudah punya pilihan).
- Harga di popup memakai harga dasar/varian tanpa diskon kampanye (sama seperti kartu di beranda).
- Tombol Keranjang di popup belum diuji sampai item masuk keranjang (alur API yang sama dengan halaman detail).
