## Summary

Skrip debug sekali pakai di `ops/_*` (27 file) ter-commit ke repo publik dan sebagian berisi kredensial SSH server. File dihapus, pola `ops/_*`, `scripts/_*`, `/_*`, `.env.bak*`, `*.bak-*` di-gitignore, dan riwayat git ditulis ulang atas permintaan owner agar kredensial tidak tersisa di commit mana pun. Media sync server juga diperbaiki: lockfile yang berubah karena `npm install` tidak lagi menggagalkan pull, file media tidak dibiarkan ter-stage selama cooldown, dan commit media yang gagal di-push dibatalkan (file tetap di disk) alih-alih ditinggal untuk dibuang deploy.

## Highlights

- 27 file `ops/_*` dihapus + gitignore skrip sekali pakai.
- Riwayat git dibersihkan dari file tersebut (force-push atas permintaan owner).
- `auto-push-media.sh`: kembalikan `package-lock.json`, `--autostash`, batalkan commit bila push gagal, unstage selama cooldown.
- `deploy-server.sh`: unstage sebelum `reset --hard` (media sudah di-backup & restore).
- Versi `package-lock.json` disamakan.
